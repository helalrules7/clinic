Dashboard Overview

The Financial Dashboard provides a real-time snapshot of your daily financial status. It tracks all cash flows, including patient payments, expenses, and balance adjustments, giving you complete visibility into your clinic's financial health.

Opening Balance

The amount of cash available at the start of the shift/day. This is set when you begin your workday.

Total Received

Sum of all incoming payments from patient bookings, follow-ups, consultations, procedures, and other services.

Total Expenses

Total amount paid out for clinic expenses including utilities, medical supplies, salaries, and maintenance.

Current Balance

Real-time cash on hand calculated as: Opening Balance + Total Received - Total Expenses.

Payment Types Summary

Breakdown by payment type: New Booking, Follow-up, Consultation, Procedure, Other, Withdrawals, and Expenses with counts and totals.

Transaction Log

Complete chronological log of all financial transactions with pagination, filtering, and export capabilities.

Managing Daily Balance

The balance management system allows you to track opening cash, add additional funds, and record withdrawals throughout the day.

Adding Balance

Use the "Add Balance" button to input opening cash or add funds during the day. The system supports three types of balance entries:

1
Opening Balance
Set the initial cash amount at the start of the day. This is typically done once per day when opening the clinic.
2
Additional Balance
Add emergency funds or petty cash top-ups during the day. Useful for replenishing cash when needed.
3
Withdrawals
Record cash taken out for bank deposits or other purposes. This reduces the current balance.
Keyboard Shortcut: Press B on your keyboard to quickly open the Add Balance modal from anywhere on the page.

Payment Management

View and manage all patient payments with detailed information, filtering options, and quick actions.

Today's Payments

The payments table displays all payments received today with the following information:

  • Date & Time: When the payment was received
  • Patient: Patient name and phone number
  • Type: Payment type (New Booking, Follow-up, Consultation, Procedure, Other)
  • Method: Payment method (Cash, Card, Transfer, Wallet)
  • Amount: Payment amount in EGP
  • Description: Additional notes or description

Payment Actions:

View Details
View complete payment information

Generate and print payment receipt
Edit Payment
Modify payment amount, type, method, or description
Delete Payment
Remove payment record (with confirmation)

Filtering: Filter payments by type using the quick filter buttons (All, New Booking, Follow-up, Consultation) or use the search box to find specific payments.

Daily Closure

At the end of the shift, perform a "Day Close" to finalize all accounts and generate a comprehensive summary report.

Closing the Day

When you're ready to close the day, click the "Day Close" button. This action:

  • Generates a summary report of the day's performance
  • Calculates total revenue, expenses, and net cash
  • Locks the day's transactions to prevent modifications
  • Creates a permanent record for accounting purposes
Important: Once a day is closed, transactions for that day cannot be modified. Make sure all entries are correct before closing.

Technical Implementation

Technical details about the Financial Management implementation, including API endpoints, database structure, JavaScript functions, and workflow algorithms.

API Endpoints

The Financial Management system uses several API endpoints for operations:

POST /api/daily-balance

Create daily balance entry (opening, additional, or withdrawal)

Parameters:
  • amount - Balance amount (required, decimal)
  • balance_type - Type: opening, additional, withdrawal (required)
  • description - Optional description
  • balance_date - Optional datetime
Returns: Success status with balance ID
POST /api/expenses

Create new expense entry

Parameters:
  • amount - Expense amount (required, decimal)
  • expense_name - Name of expense (required)
  • category - Category: utilities, medical, maintenance, office, salary, other (required)
  • notes - Optional notes
  • expense_date - Optional datetime
GET /api/financial-transactions

Get paginated financial transactions

Parameters:
  • page - Page number (default: 1)
  • limit - Items per page (default: 10)
  • date - Filter by date (YYYY-MM-DD)
  • type - Filter by type: all, payment, expense, balance
Returns: Paginated transactions with running balance
GET /api/financial-transactions/export

Export transactions to Excel/CSV

Parameters: Same as financial-transactions endpoint
Returns: Excel/CSV file download
GET /api/payments/{id}

Get payment details by ID

PUT /api/payments/{id}

Update payment (amount, type, method, description)

DELETE /api/payments/{id}

Delete payment record

GET /api/expenses/{id}

Get expense details by ID

PUT /api/expenses/{id}

Update expense (amount, name, category, notes)

DELETE /api/expenses/{id}

Delete expense record

Transaction Processing

Transaction Aggregation:

The system aggregates transactions from three sources:

  • Payments: From payments table with patient information
  • Expenses: From expenses table
  • Balances: From daily_balances table

Running Balance Calculation:

Transactions are sorted chronologically and a running balance is calculated:

  • Payments and balance additions increase the balance
  • Expenses and withdrawals decrease the balance
  • Each transaction shows the balance after that transaction

Pagination:

  • Default: 10 transactions per page
  • Configurable via limit parameter
  • Pagination controls show current page, total pages, and record counts
