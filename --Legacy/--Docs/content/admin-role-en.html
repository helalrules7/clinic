Administrator Role

Full System Administration and Management Access

System Admin Full Access System Control

Role Overview

The Administrator role provides complete system administration capabilities, including user management, system configuration, backups, and full access to all system features.

Access Level: Full system access with no restrictions
Primary Responsibilities: System administration, user management, system configuration, monitoring
Special Features: View As mode to experience other roles

Key Features & Capabilities

Comprehensive administrative features for managing the entire system.

System Dashboard

Comprehensive system dashboard with health monitoring and system statistics.

  • System-wide statistics

  • View As status indicator
  • Quick access to all modules

User Management

Complete user and role management system with full control over user accounts.

  • Create new users

  • Assign roles (Doctor, Secretary, Admin)
  • Delete users
  • Reset passwords
  • View user activity
  • Manage doctor profiles
Routes 
/admin/users
/admin/users/create
/admin/users/{id}/edit

View As Feature

Special feature allowing administrators to view the system from another role's perspective.

  • View as Doctor role
  • View as Secretary role
  • Experience other roles' interfaces
  • Test functionality from different perspectives
  • Easy exit back to admin mode
Routes 
/admin/view-as
/admin/stop-view-as
Note: While in View As mode, admin-specific functions remain accessible if original role was admin.

User Management Details

Comprehensive guide to managing users in the system.

1

Create New User

Add new users to the system with appropriate roles and permissions.

Required Information:

  • Full name
  • Username (unique)
  • Email address
  • Role (Doctor, Secretary, or Admin)
  • Password (minimum 8 characters)

For Doctor Role:

  • Specialization
  • License number
  • Phone number
Route 
/admin/users/create
POST /admin/users
2

Edit User

Update user information, change roles, or modify user settings.

Route 
/admin/users/{id}/edit
POST /admin/users/update/{id}
3

Delete User

Remove users from the system (with appropriate safeguards).

Warning: Deleting a user may affect associated records. Ensure proper data handling.
Route 
POST /admin/users/delete/{id}

Backup & Restore System

Comprehensive backup and restore functionality for system data protection.

Create Backup

Generate complete system backups including database and configuration files.

API Endpoint 
POST /api/admin/backup/create

Restore Backup

Restore system from previously created backup files.

API Endpoint 
POST /api/admin/backup/restore

List Backups

View all available backup files with details and timestamps.

API Endpoint 
GET /api/admin/backup/list

Security Considerations

Important security notes for administrators.

Security Best Practices:
  • Use strong, unique passwords
  • Regularly review user access
  • Monitor system logs
  • Perform regular backups
  • Keep system updated
  • Limit admin account creation
