Filter System

Filter Types:

  • Category (Pharmacology): Therapeutic classification
  • Company: Manufacturer filter
  • Route: Administration route

Behavior:

  • Can be applied independently or combined
  • Work with or without search term
  • Requires "Apply Filters" button click (not auto-apply)
  • Visual indication when filters are selected

Loading: Options loaded via /api/getFilterOptions on page init

Keyboard Shortcuts

Note: While the UI mentions keyboard shortcuts (F or ب for search, Esc for clear), the actual implementation in drugs.js does not include keyboard event listeners.

The shortcuts are displayed in the UI but would need to be implemented separately if desired.

Error Handling

Client-Side:

  • Loading indicators during API calls
  • "No results" message when search returns empty
  • Error messages logged to console (can be enhanced with toast notifications)

Server-Side:

  • Authentication check first (401 if unauthorized)
  • Input validation (minimum search length, required parameters)
  • Database connection errors caught and returned as 500 errors
  • Transaction rollback on failure
  • Temporary files cleaned up even on errors
