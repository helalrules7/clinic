Project Overview

A comprehensive healthcare management solution designed to streamline clinic operations, enhance patient care, and improve administrative efficiency.

Three Main Roles

  • Doctor: Manage patients, appointments, prescriptions, and examinations
  • Secretary: Handle bookings, payments, and patient registration
  • Admin: System management, users, and reports

Key Features

  • Patient management with medical history
  • Interactive appointment calendar
  • Prescription management (medications & glasses)
  • Financial management & reporting
  • Comprehensive statistics dashboard

Technology Stack

  • Backend: PHP 8.2+ with MVC architecture
  • Database: MySQL 8.0+
  • Frontend: Modern JavaScript & CSS
  • Security: RBAC, CSRF protection

Installation Guide

Follow these steps to install and configure the system on your server.

1

System Requirements

Server Requirements:

  • PHP 8.2 or higher
  • MySQL 8.0 or higher
  • Apache/Nginx with mod_rewrite
  • Composer

PHP Extensions:

  • ext-pdo
  • ext-json
  • ext-mbstring
2

Clone and Install Dependencies

Terminal 
# Clone the repository
git clone <repository-url>
cd clinic

# Install dependencies
composer install
3

Database Setup

Terminal 
# Create database
mysql -u root -p -e "CREATE DATABASE roaya CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# Import schema
mysql -u root -p roaya < sql/schema.sql

# Import seed data
mysql -u root -p roaya < sql/seed.sql
4

Environment Configuration

Create a .env file in the project root:

.env 
# Database Configuration
DB_HOST=localhost
DB_NAME=roaya
DB_USER=root
DB_PASS=your_password

# Application Configuration
APP_ENV=local
APP_KEY=roaya-clinic-system-2024-secret-key-32
TIMEZONE=Africa/Cairo

# Security
SESSION_SECRET=roaya-session-secret-key-2024-32-chars
CSRF_SECRET=roaya-csrf-secret-key-2024-32-chars
5

Set Permissions

Terminal 
# Create required directories
mkdir -p storage/logs storage/uploads storage/exports
chmod -R 755 storage/

# Regenerate autoloader
composer dump-autoload
6

Run the Application

Terminal 
# Using PHP built-in server
php -S localhost:8000 router.php

# Or with Apache/Nginx
# Point document root to project directory
Access URLs:
  • Homepage: http://localhost:8000/
  • Login: http://localhost:8000/public/login

System Architecture

Understanding the project structure and technical architecture.

Directory Structure 
clinic/
├── app/
│   ├── Config/          # Configuration files
│   ├── Controllers/     # Controller classes
│   ├── Lib/            # Core libraries
│   ├── Models/         # Data models
│   └── Views/          # View templates
│       ├── admin/      # Admin interface
│       ├── doctor/     # Doctor interface
│       ├── secretary/  # Secretary interface
│       └── print/      # Print templates
├── public/              # Entry point
├── sql/                 # Database files
├── storage/             # Storage directory
│   ├── logs/           # System logs
│   ├── uploads/        # Uploaded files
│   └── exports/        # Exported reports
├── vendor/              # Composer dependencies
├── .env                 # Environment config
└── router.php           # Custom router

Model

Handles data logic and database interactions. Located in app/Models/

View

Responsible for presentation layer. Templates in app/Views/

Controller

Processes requests and coordinates between Model and View. Located in app/Controllers/

Database: MySQL 8.0+
Character Set: utf8mb4
Collation: utf8mb4_unicode_ci

Main Tables:

  • users - User accounts and authentication
  • patients - Patient information
  • appointments - Appointment scheduling
  • prescriptions - Medical prescriptions
  • payments - Financial transactions
  • consultations - Medical consultations
