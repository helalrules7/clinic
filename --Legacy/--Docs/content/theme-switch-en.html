Top Bar Theme Switch

The quickest way to change themes is through the theme switch located in the Top Bar.

Quick Access:

The theme switch in the Top Bar provides instant access to theme switching. Simply click the toggle to switch between light and dark modes. The change is applied immediately and saved automatically.

Instant Switching

Click the theme switch in the Top Bar to instantly toggle between light and dark modes without page reload.

Visual Feedback

The switch icon changes to reflect the current theme: sun icon for dark mode (click to switch to light) and moon icon for light mode (click to switch to dark).

Automatic Sync

Your theme preference is synchronized across all your devices and browser sessions through the database and local storage.

How It Works

Understanding the theme switching mechanism and preference storage.

Storage Mechanism:
  • Local Storage: For instant theme application, your preference is cached in the browser's local storage (localStorage.getItem('theme')). This allows immediate theme loading without waiting for database queries.
  • Database Storage: Your theme preference is also saved to the user_settings table in the database, ensuring persistence across all devices and sessions.
  • Synchronization: The system intelligently synchronizes between local storage and database, checking local storage first on page load, then falling back to the database if needed.

Instant Application

When you change the theme, it's applied immediately using local storage, providing instant visual feedback without page reload.

Background Save

While the theme is applied instantly, your preference is saved to the database in the background for long-term persistence.

Cross-Device Sync

Your theme preference is linked to your user account, so it syncs across all your devices automatically.
