دور المدير

وصول كامل لإدارة النظام والإدارة

مدير النظام وصول كامل تحكم في النظام

نظرة عامة على الدور

دور المدير يوفر قدرات إدارة نظام كاملة، بما في ذلك إدارة المستخدمين، تكوين النظام، النسخ الاحتياطية، والوصول الكامل لجميع ميزات النظام.

مستوى الوصول: وصول كامل للنظام بدون قيود
المسؤوليات الرئيسية: إدارة النظام، إدارة المستخدمين، تكوين النظام، المراقبة
ميزات خاصة: وضع العرض كدور آخر لتجربة أدوار أخرى

تفاصيل إدارة المستخدمين

دليل شامل لإدارة المستخدمين في النظام.

1

إنشاء مستخدم جديد

إضافة مستخدمين جدد إلى النظام مع الأدوار والصلاحيات المناسبة.

المعلومات المطلوبة:

  • الاسم الكامل
  • اسم المستخدم (فريد)
  • عنوان البريد الإلكتروني
  • الدور (طبيب، سكرتير، أو مدير)
  • كلمة المرور (8 أحرف على الأقل)

للدور الطبيب:

  • التخصص
  • رقم الرخصة
  • رقم الهاتف
المسار 
/admin/users/create
POST /admin/users
2

تحرير المستخدم

تحديث معلومات المستخدم، تغيير الأدوار، أو تعديل إعدادات المستخدم.

المسار 
/admin/users/{id}/edit
POST /admin/users/update/{id}
3

حذف المستخدم

إزالة المستخدمين من النظام (مع ضمانات مناسبة).

تحذير: حذف مستخدم قد يؤثر على السجلات المرتبطة. تأكد من التعامل الصحيح مع البيانات.
المسار 
POST /admin/users/delete/{id}

نظام النسخ الاحتياطي والاستعادة

وظائف نسخ احتياطي واستعادة شاملة لحماية بيانات النظام.

إنشاء نسخة احتياطية

إنشاء نسخ احتياطية كاملة للنظام بما في ذلك قاعدة البيانات وملفات التكوين.

نقطة API 
POST /api/admin/backup/create

استعادة نسخة احتياطية

استعادة النظام من ملفات النسخ الاحتياطية التي تم إنشاؤها مسبقاً.

نقطة API 
POST /api/admin/backup/restore

قائمة النسخ الاحتياطية

عرض جميع ملفات النسخ الاحتياطية المتاحة مع التفاصيل والطوابع الزمنية.

نقطة API 
GET /api/admin/backup/list

الصلاحيات والوصول

مصفوفة وصول كاملة لدور المدير.

الميزة/الوحدة مستوى الوصول ملاحظات
إدارة المستخدمين وصول كامل إنشاء، تحرير، حذف المستخدمين
إعدادات النظام وصول كامل جميع تكوينات النظام
النسخ الاحتياطي والاستعادة وصول كامل إدارة النسخ الاحتياطي الكاملة
إدارة الوسائط وصول كامل جميع ملفات الوسائط
جميع التقارير وصول كامل تقارير النظام العامة
وضع العرض كدور آخر حصري ميزة للمدير فقط
بيانات المرضى وصول كامل جميع سجلات المرضى
البيانات المالية وصول كامل وصول مالي كامل
