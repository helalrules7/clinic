الإدارة المالية

تحكم كامل في ماليات العيادة، المصروفات، والعمليات اليومية مع تتبع فوري وتقارير شاملة.

المدفوعات المصروفات الرصيد

نظرة عامة على لوحة القيادة

توفر اللوحة المالية نظرة آنية على الوضع المالي لليوم. حيث تقوم بتتبع جميع التدفقات النقدية، بما في ذلك مدفوعات المرضى، المصروفات، وتعديلات الرصيد، مما يمنحك رؤية كاملة لصحة العيادة المالية.

الرصيد الافتتاحي

المبلغ النقدي المتوفر عند بداية الدوام/اليوم. يتم تعيينه عند بدء يوم العمل.

إجمالي المقبوضات

مجموع كل المدفوعات الواردة من حجوزات المرضى، المتابعات، الاستشارات، الإجراءات، والخدمات الأخرى.

إجمالي المصروفات

إجمالي المبالغ المدفوعة لمصروفات العيادة بما في ذلك المرافق، المستلزمات الطبية، الرواتب، والصيانة.

الرصيد الحالي

النقد الفعلي المتوفر حاليًا محسوبًا كالتالي: الرصيد الافتتاحي + إجمالي المقبوضات - إجمالي المصروفات.

ملخص أنواع المدفوعات

تفصيل حسب نوع الدفع: حجز جديد، متابعة، استشارة، إجراء، أخرى، مسحوبات، ومصروفات مع العدد والإجمالي.

سجل المعاملات

سجل زمني كامل لجميع المعاملات المالية مع الترقيم والتصفية وإمكانيات التصدير.

إدارة الرصيد اليومي

يسمح نظام إدارة الرصيد بتتبع النقد الافتتاحي، إضافة أموال إضافية، وتسجيل المسحوبات طوال اليوم.

إضافة رصيد

استخدم زر "إضافة رصيد" لإدخال النقد الافتتاحي أو إضافة أموال خلال اليوم. يدعم النظام ثلاثة أنواع من إدخالات الرصيد:

1
الرصيد الافتتاحي
تحديد المبلغ النقدي في بداية اليوم. يتم ذلك عادة مرة واحدة يومياً عند فتح العيادة.
2
رصيد إضافي
إضافة أموال للطوارئ أو زيادة النثرية خلال اليوم. مفيد لتجديد النقد عند الحاجة.
3
المسحوبات
تسجيل النقد الذي تم سحبه للإيداع البنكي أو أغراض أخرى. هذا يقلل الرصيد الحالي.
اختصار لوحة المفاتيح: اضغط على B في لوحة المفاتيح لفتح نافذة إضافة الرصيد بسرعة من أي مكان في الصفحة.

تتبع المصروفات

تتبع كل قرش يتم صرفه مع تصنيف المصروفات. يدعم النظام أنواع المصروفات السريعة والتصنيف التفصيلي لتقارير أفضل.

تسجيل المصروفات

أنواع المصروفات السريعة: اختيار بنقرة واحدة للمصاريف الشائعة:

فاتورة المياه
فاتورة الكهرباء
مستلزمات طبية
مصروفات التنظيف
راتب السكرتير
الصيانة

فئات المصروفات: تجميع المصروفات في فئات منطقية لتقارير أفضل:

  • المرافق: المياه، الكهرباء، الإنترنت، فواتير الهاتف
  • طبية: المستلزمات الطبية، المعدات، الأدوية
  • الصيانة: الإصلاحات، الصيانة، التنظيف
  • المكتب: مستلزمات المكتب، القرطاسية، الطباعة
  • الراتب: رواتب وأجور الموظفين
  • أخرى: مصروفات متنوعة
اختصار لوحة المفاتيح: اضغط على E لإضافة مصروف جديد بسرعة.

سجل المعاملات والبحث

يتم تسجيل كل إجراء مالي تلقائيًا. راجع وابحث وصفي وصدّر سجل معاملاتك الكامل مع خيارات تصفية قوية.

فلاتر قوية

نطاق التاريخ

تصفية المعاملات حسب تواريخ محددة أو نطاقات تاريخية. عرض معاملات اليوم أو البحث في البيانات التاريخية.

نوع المعاملة

عرض المدفوعات فقط، أو المصروفات، أو تعديلات الرصيد. أو عرض جميع المعاملات معاً.

نطاق المبلغ

العثور على معاملات ضمن نطاق قيمة محدد. مفيد لتدقيق المعاملات الكبيرة.

تصدير إلى Excel

تحميل تقريرك المصفى كملف Excel للمحاسبة، إعداد الضرائب، أو حفظ السجلات.

اختصار لوحة المفاتيح: اضغط على S لفتح نافذة البحث بسرعة.

إدارة المدفوعات

عرض وإدارة جميع مدفوعات المرضى مع معلومات تفصيلية وخيارات تصفية وإجراءات سريعة.

مدفوعات اليوم

يعرض جدول المدفوعات جميع المدفوعات المستلمة اليوم مع المعلومات التالية:

  • التاريخ والوقت: وقت استلام الدفع
  • المريض: اسم المريض ورقم الهاتف
  • النوع: نوع الدفع (حجز جديد، متابعة، استشارة، إجراء، أخرى)
  • الطريقة: طريقة الدفع (نقدي، بطاقة، تحويل، محفظة)
  • المبلغ: مبلغ الدفع بالجنيه المصري
  • الوصف: ملاحظات أو وصف إضافي

إجراءات الدفع:

عرض التفاصيل
عرض معلومات الدفع الكاملة
طباعة الإيصال
إنشاء وطباعة إيصال الدفع
تعديل الدفع
تعديل مبلغ الدفع، النوع، الطريقة، أو الوصف
حذف الدفع
إزالة سجل الدفع (مع تأكيد)

التصفية: تصفية المدفوعات حسب النوع باستخدام أزرار التصفية السريعة (الكل، حجز جديد، متابعة، استشارة) أو استخدم صندوق البحث للعثور على مدفوعات محددة.

الإغلاق اليومي

في نهاية الوردية، قم بإجراء "إغلاق اليوم" لإنهاء جميع الحسابات وإنشاء تقرير ملخص شامل.

إنهاء اليوم

عندما تكون مستعداً لإغلاق اليوم، انقر على زر "إغلاق اليوم". يقوم هذا الإجراء بـ:

  • إنشاء تقرير ملخص لأداء اليوم
  • حساب إجمالي الإيرادات والمصروفات وصافي النقد
  • قفل معاملات اليوم لمنع التعديلات
  • إنشاء سجل دائم لأغراض المحاسبة
مهم: بمجرد إغلاق اليوم، لا يمكن تعديل معاملات ذلك اليوم. تأكد من صحة جميع الإدخالات قبل الإغلاق.

التنفيذ التقني

التفاصيل التقنية حول تنفيذ الإدارة المالية، بما في ذلك نقاط نهاية API وبنية قاعدة البيانات ووظائف JavaScript وخوارزميات سير العمل.

نقاط نهاية API

يستخدم نظام الإدارة المالية عدة نقاط نهاية API للعمليات:

POST /api/daily-balance

إنشاء إدخال رصيد يومي (افتتاحي، إضافي، أو سحب)

المعاملات:
  • amount - مبلغ الرصيد (مطلوب، عشري)
  • balance_type - النوع: opening، additional، withdrawal (مطلوب)
  • description - وصف اختياري
  • balance_date - تاريخ ووقت اختياري
الإرجاع: حالة النجاح مع معرف الرصيد
POST /api/expenses

إنشاء إدخال مصروف جديد

المعاملات:
  • amount - مبلغ المصروف (مطلوب، عشري)
  • expense_name - اسم المصروف (مطلوب)
  • category - الفئة: utilities، medical، maintenance، office، salary، other (مطلوب)
  • notes - ملاحظات اختيارية
  • expense_date - تاريخ ووقت اختياري
GET /api/financial-transactions

الحصول على المعاملات المالية المرقمة

المعاملات:
  • page - رقم الصفحة (افتراضي: 1)
  • limit - العناصر لكل صفحة (افتراضي: 10)
  • date - التصفية حسب التاريخ (YYYY-MM-DD)
  • type - التصفية حسب النوع: all، payment، expense، balance
الإرجاع: معاملات مرقمة مع الرصيد الجاري
GET /api/financial-transactions/export

تصدير المعاملات إلى Excel/CSV

المعاملات: نفس معاملات financial-transactions
الإرجاع: تحميل ملف Excel/CSV
GET /api/payments/{id}

الحصول على تفاصيل الدفع حسب المعرف

PUT /api/payments/{id}

تحديث الدفع (المبلغ، النوع، الطريقة، الوصف)

DELETE /api/payments/{id}

حذف سجل الدفع

GET /api/expenses/{id}

الحصول على تفاصيل المصروف حسب المعرف

PUT /api/expenses/{id}

تحديث المصروف (المبلغ، الاسم، الفئة، الملاحظات)

DELETE /api/expenses/{id}

حذف سجل المصروف

معالجة المعاملات

تجميع المعاملات:

يجمع النظام المعاملات من ثلاثة مصادر:

  • المدفوعات: من جدول payments مع معلومات المريض
  • المصروفات: من جدول expenses
  • الأرصدة: من جدول daily_balances

حساب الرصيد الجاري:

يتم ترتيب المعاملات زمنياً ويتم حساب رصيد جاري:

  • المدفوعات وإضافات الرصيد تزيد الرصيد
  • المصروفات والمسحوبات تقلل الرصيد
  • كل معاملة تعرض الرصيد بعد تلك المعاملة

الترقيم:

  • افتراضي: 10 معاملات لكل صفحة
  • قابل للتعديل عبر معامل limit
  • عناصر التحكم في الترقيم تعرض الصفحة الحالية، إجمالي الصفحات، وأعداد السجلات

معالجة الأخطاء

من جانب العميل:

  • التحقق من النموذج قبل الإرسال
  • مؤشرات التحميل أثناء استدعاءات API
  • رسائل النجاح/الخطأ المعروضة في النوافذ
  • تحديث لوحة القيادة التلقائي بعد العمليات الناجحة
  • حوارات التأكيد للإجراءات المدمرة (الحذف)

من جانب الخادم:

  • التحقق من المصادقة على جميع نقاط النهاية (401 إذا لم يكن مصرحاً)
  • التحقق من المدخلات مع رسائل خطأ تفصيلية
  • سلامة معاملات قاعدة البيانات
  • رسائل الخطأ المُرجعة بتنسيق JSON
  • رموز حالة HTTP مناسبة (200، 400، 401، 404، 500)
