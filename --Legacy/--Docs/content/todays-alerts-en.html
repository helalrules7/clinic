Component Structure

The Today's Alerts component consists of a header section and a dynamic list of alerts.

Header Section

The header includes:

  • Title: "Today's Alerts" with bell icon
  • Manage Alerts Button: Links to /doctor/alerts page for managing all alerts
  • Card Controls: Move up/down buttons and drag handle for reordering

Alerts List

Each alert is displayed as a list item containing:

  • Bell Icon: Warning-colored bell icon indicating alert type
  • Alert Message: The alert content/message (can be HTML)
  • Time: Alert time in 12-hour format (e.g., "01:00 PM")
  • Patient Name: Patient name if alert is linked to a patient
  • View Patient Button: Quick link to patient profile (if patient linked)

Empty State

When no alerts are scheduled for today:

  • Icon: Bell with slash icon
  • Message: "No alerts for today"
  • Styling: Centered, muted text for visual clarity

How It Works

The Today's Alerts component fetches and displays alerts for the current day using the alerts API.

JavaScript Function

loadTodayAlerts() function:

  • API Call: GET /api/alerts/today
  • Response Handling: Processes JSON response and renders alerts
  • Error Handling: Displays error message if API call fails
  • Auto-Load: Called automatically on page load

Backend API

AlertController::getTodayAlerts() method:

  • Model Method: Calls AlertModel::getTodayAlerts($doctorId)
  • Filtering: Filters alerts by today's date, active status, and not dismissed
  • Patient Data: Includes patient information if alert is linked to a patient
  • Response: Returns JSON with success status and alerts array

Database Query

AlertModel::getTodayAlerts() query:

  • Date Filter: alert_date = CURDATE()
  • Status Filter: is_active = 1 AND is_dismissed = 0
  • Joins: LEFT JOIN with patients and appointments tables
  • Ordering: Ordered by alert_date and alert_time ASC

Alert Features

Today's Alerts includes several features for effective alert management.

Time Display

Alerts show their scheduled time in 12-hour format (AM/PM), making it easy to see when each alert should be triggered.

Patient Integration

Alerts can be linked to specific patients, and when linked, display patient name and provide a quick link to the patient profile.

HTML Content

Alert messages support HTML content, allowing for rich formatting and links within alert messages.

Quick Management

The "Manage Alerts" button provides quick access to the full alerts management page where you can create, edit, delete, and configure all alerts.
