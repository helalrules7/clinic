Theme Switch

The theme switch allows you to toggle between light and dark modes with automatic preference saving.

Theme Switch Features:
  • Instant theme switching between light and dark modes
  • Automatic preference saving to user settings table in database
  • Local storage caching for quick theme updates
  • Persistent theme across browser sessions
  • Real-time theme application without page reload

Database Storage

Your theme preference is automatically saved to the user_settings table in the database, ensuring your preference is preserved across all devices and sessions.

  • Theme value stored as 'light' or 'dark'
  • Linked to your user account
  • Synced across all your devices

Local Storage

For faster theme loading, your preference is also cached in the browser's local storage, allowing instant theme application without waiting for database queries.

  • Stored as localStorage.getItem('theme')
  • Immediate theme application on page load
  • Fallback to database if local storage is empty

Synchronization

The system intelligently synchronizes between local storage and database:

  • On theme change: Updates both local storage and database
  • On page load: Checks local storage first, then database
  • Background sync ensures consistency

Quick Updates

Local storage enables instant theme switching without server requests, providing a smooth and responsive user experience.

  • No page reload required
  • Instant visual feedback
  • Seamless theme transition
How It Works:
  1. User clicks theme switch: The theme toggle button is clicked
  2. Immediate update: Theme is applied instantly using local storage
  3. Background save: Preference is saved to database in the background
  4. Persistence: Theme preference persists across sessions and devices
