نظرة عامة على تنبيهات اليوم

مكون تنبيهات اليوم يعرض جميع التنبيهات النشطة المجدولة لليوم الحالي. يوفر نظرة سريعة على التذكيرات المهمة والمواعيد والإشعارات التي تحتاج إلى انتباهك اليوم.

عرض توضيحي مرئي لواجهة تنبيهات اليوم

تنبيهات يومية

يعرض جميع التنبيهات المجدولة لليوم التي تكون نشطة وغير مرفوضة، مما يساعدك على متابعة المهام والتذكيرات المهمة.

روابط المرضى

التنبيهات يمكن ربطها بمرضى محددين، مما يوفر وصولاً سريعاً إلى ملفات تعريف المرضى بنقرة واحدة.

إدارة التنبيهات

زر وصول سريع إلى صفحة إدارة التنبيهات حيث يمكنك إنشاء وتحرير وإدارة جميع تنبيهاتك.

بنية المكون

مكون تنبيهات اليوم يتكون من قسم رأس وقائمة ديناميكية من التنبيهات.

قسم الرأس

الرأس يتضمن:

  • العنوان: "تنبيهات اليوم" مع أيقونة جرس
  • زر إدارة التنبيهات: يربط بصفحة /doctor/alerts لإدارة جميع التنبيهات
  • أزرار التحكم: أزرار نقل لأعلى/أسفل ومقبض سحب لإعادة الترتيب

قائمة التنبيهات

كل تنبيه يتم عرضه كعنصر قائمة يحتوي على:

  • أيقونة الجرس: أيقونة جرس بلون تحذيري يشير إلى نوع التنبيه
  • رسالة التنبيه: محتوى/رسالة التنبيه (يمكن أن يكون HTML)
  • الوقت: وقت التنبيه بتنسيق 12 ساعة (مثلاً "01:00 PM")
  • اسم المريض: اسم المريض إذا كان التنبيه مربوطاً بمريض
  • زر عرض المريض: رابط سريع لملف تعريف المريض (إذا كان مربوطاً بمريض)

الحالة الفارغة

عندما لا توجد تنبيهات مجدولة لليوم:

  • الأيقونة: جرس مع خط مائل
  • الرسالة: "لا توجد تنبيهات لليوم"
  • التنسيق: نص مركزي، باهت للوضوح البصري

كيف يعمل

مكون تنبيهات اليوم يجلب ويعرض التنبيهات لليوم الحالي باستخدام API التنبيهات.

دالة JavaScript

دالة loadTodayAlerts():

  • استدعاء API: GET /api/alerts/today
  • معالجة الاستجابة: يعالج استجابة JSON ويعرض التنبيهات
  • معالجة الأخطاء: يعرض رسالة خطأ إذا فشل استدعاء API
  • تحميل تلقائي: يتم استدعاؤه تلقائياً عند تحميل الصفحة

API الخلفي

طريقة AlertController::getTodayAlerts():

  • طريقة النموذج: تستدعي AlertModel::getTodayAlerts($doctorId)
  • الفلترة: يفلتر التنبيهات حسب تاريخ اليوم، الحالة النشطة، وغير المرفوضة
  • بيانات المريض: يتضمن معلومات المريض إذا كان التنبيه مربوطاً بمريض
  • الاستجابة: يُرجع JSON مع حالة النجاح ومصفوفة التنبيهات

استعلام قاعدة البيانات

استعلام AlertModel::getTodayAlerts():

  • فلتر التاريخ: alert_date = CURDATE()
  • فلتر الحالة: is_active = 1 AND is_dismissed = 0
  • الربط: LEFT JOIN مع جداول patients و appointments
  • الترتيب: مرتب حسب alert_date و alert_time ASC

ميزات التنبيه

تنبيهات اليوم تتضمن عدة ميزات لإدارة فعالة للتنبيهات.

عرض الوقت

التنبيهات تظهر وقتها المجدول بتنسيق 12 ساعة (AM/PM)، مما يسهل رؤية متى يجب تفعيل كل تنبيه.

تكامل المريض

التنبيهات يمكن ربطها بمرضى محددين، وعند الربط، تعرض اسم المريض وتوفر رابطاً سريعاً لملف تعريف المريض.

محتوى HTML

رسائل التنبيه تدعم محتوى HTML، مما يسمح بتنسيق غني وروابط داخل رسائل التنبيه.

إدارة سريعة

زر "إدارة التنبيهات" يوفر وصولاً سريعاً إلى صفحة إدارة التنبيهات الكاملة حيث يمكنك إنشاء وتحرير وحذف وتكوين جميع تنبيهاتك.
