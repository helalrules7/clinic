Main Functionality

The Side Bar provides comprehensive navigation and access to all core features of the application.

Navigation Structure:

The Side Bar is organized into distinct sections: branding at the top, user profile section, main navigation links, and footer information. Each navigation item includes a clear icon and descriptive text for easy identification.

Dashboard Access

Quick navigation to the main dashboard for an overview of appointments, statistics, and key metrics.

Calendar & Scheduling

Direct access to calendar views, appointment scheduling, and time management features.

Patient Management

Navigate to patient records, profiles, medical history, and patient-related operations.

Discussions & Communication

Access forum discussions, messaging, and communication features.

Drugs Database

Quick access to medication database, prescriptions, and drug information.

Financial Management

Navigate to billing, payments, financial reports, and accounting features.

Reports & Analytics

Access comprehensive reports, statistics, and analytical data.

Medical Storage

Organized storage for medical prescriptions, glasses prescriptions, and patient media with expandable sub-items.

Alerts & Notifications

Quick access to alerts, reminders, and important notifications.

Notes & Documentation

Access personal notes, documentation, and record-keeping features.

Mobile Responsiveness

The Side Bar is fully responsive and adapts seamlessly to mobile devices, ensuring optimal usability across all screen sizes.

Adaptive Design:

The Side Bar automatically adjusts its layout and behavior based on screen size. On mobile devices, the sidebar may collapse into a hamburger menu, slide in as an overlay, or transform into a bottom navigation bar, maintaining full access to all core functionalities while optimizing screen space.

Collapsible Menu

On smaller screens, the sidebar can collapse into a compact hamburger menu icon, saving valuable screen space while maintaining quick access to navigation.

Slide-Over Panel

On mobile devices, the sidebar can appear as a slide-over panel that appears from the side when activated, providing full navigation without taking up permanent screen space.

Bottom Navigation

For mobile interfaces, the sidebar may transform into a bottom navigation bar with the most frequently used items, providing thumb-friendly access to core features.

Touch-Optimized

All navigation items are optimized for touch interaction, with appropriately sized tap targets and clear visual feedback for mobile users.

User Profile Link

The user profile section provides quick access to profile information and settings with an interactive hover expansion feature.

Profile Section Features:
  • Profile Picture: Displays the user's profile image in a circular format, providing visual identification
  • User Information: Shows the user's name and role (e.g., "Doctor", "Secretary", "Admin") clearly below the profile picture
  • Quick Access: The entire profile section serves as a clickable link to the user's profile page or profile settings
  • Hover Expansion: When you hover over the profile section, it expands to reveal additional information or quick access options

Profile Image

The circular profile image provides visual identification and serves as a prominent element in the sidebar, making it easy to identify the current user at a glance.

Hover Expand

When you hover your mouse over the profile section, it smoothly expands to show additional details, quick actions, or a dropdown menu with profile-related options.

Quick Actions

The expanded profile section may reveal quick actions such as "Edit Profile", "Change Password", "View Settings", or other profile-related shortcuts.

Direct Link

Clicking on the profile section or the "Profile" navigation item below provides direct access to the full profile page where you can view and edit all profile information.

Auto Icon Change Based on Style

System icons automatically adapt to the current theme (light or dark) to ensure optimal visibility and visual consistency.

Theme-Based Icon Adaptation:

All system icons in the Side Bar automatically change their appearance based on the active theme. In dark mode, icons appear as white or light-colored outlines for visibility against dark backgrounds. In light mode, icons appear as dark or black outlines for visibility against light backgrounds. This ensures optimal contrast and readability regardless of the selected theme.

Dark Mode Icons

In dark mode, all navigation icons are displayed as white or light-colored outlines, providing excellent contrast against the dark sidebar background for clear visibility.

Light Mode Icons

In light mode, all navigation icons are displayed as dark or black outlines, ensuring clear visibility against the light sidebar background.

Automatic Switching

Icon colors change automatically when you switch between light and dark themes, ensuring consistent visual appearance without manual intervention.

Optimal Contrast

The automatic icon color adaptation ensures optimal contrast ratios for accessibility and readability in both light and dark themes.

How It Works:
  • Theme Detection: The system detects the current theme setting (stored in user settings and local storage)
  • Icon Rendering: Icons are rendered with appropriate colors based on the active theme
  • CSS Variables: Icon colors are controlled through CSS variables that change based on the theme attribute
  • Instant Update: When you change the theme, all icons update instantly to match the new theme
  • Consistent Experience: All icons throughout the application maintain visual consistency with the selected theme

Additional Features

The Side Bar includes several additional features to enhance navigation and user experience.

Active Item Highlighting

The currently active navigation item is highlighted with a distinct background color (e.g., blue), making it clear which section you're currently viewing.

Expandable Sub-Items

Some navigation items like "Medical Storage" have expandable sub-items that can be toggled to show or hide related sections (e.g., Medical Prescriptions, Glasses Prescriptions, Patients Media).

Logout Option

A prominent "Logout" option is available at the bottom of the navigation list, displayed in red to indicate its importance as a system exit action.

Version Information

The footer displays the application version and copyright information, providing transparency about the software version in use.
