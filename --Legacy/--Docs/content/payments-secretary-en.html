Payments & Daily Balance Management - Secretary View

Complete financial management interface for secretaries to track payments, manage daily balances, record expenses, and search transactions with powerful filtering and export capabilities.

Payments Balance Expenses

Dashboard Overview

The Payments & Daily Balance Management dashboard provides secretaries with a comprehensive view of the clinic's daily financial activities. It includes summary cards, payment type breakdowns, transaction logs, and detailed payment records.

Opening Balance

The amount of cash available at the start of the day. Set once per day when opening the clinic.

Total Received

Sum of all incoming payments from patient bookings, follow-ups, consultations, and procedures.

Total Expenses

Total amount paid out for clinic expenses including utilities, medical supplies, salaries, and maintenance.

Current Balance

Real-time cash on hand calculated as: Opening Balance + Total Received - Total Expenses.

Payment Types Summary

Breakdown by payment type: New Booking, Re-examination, Medical Consultation, Medical Procedure with totals in EGP.

Financial Transactions Log

Complete chronological log of all financial transactions (payments, expenses, balance adjustments) with pagination and filtering.

Payment Records

Detailed table of all patient payments with search, filtering by type and payment method, and quick actions.

Managing Daily Balance

The balance management system allows secretaries to record opening cash, add additional funds, and record withdrawals throughout the day.

Registering Balance

Use the "Register Balance" button to input opening cash or add funds during the day. The system supports three types of balance entries:

1
Opening Balance
Set the initial cash amount at the start of the day. This is typically done once per day when opening the clinic.
2
Additional Balance
Add emergency funds or petty cash top-ups during the day. Useful for replenishing cash when needed.
3
Withdrawal
Record cash taken out for bank deposits or other purposes. This reduces the current balance.
Keyboard Shortcuts: Press R or ر on your keyboard to quickly open the Register Balance modal from anywhere on the page.

Search Functionality

Powerful search capabilities allow you to quickly find payments by patient name, phone number, or payment ID with real-time results as you type.

Global Payment Search

Search Capabilities:

  • By Patient Name: Search using full name or partial name
  • By Phone Number: Search using complete or partial phone number
  • By Payment ID: Search using specific payment number

Features:

  • Real-time Search: Results appear automatically as you type (type-ahead functionality)
  • Clear Button: Quick clear button (X) to reset search
  • Focus Shortcut: Press Ctrl+F to focus on search input
  • Empty State: Helpful guidance when no search term is entered
  • No Results State: Clear message when no matches are found
Keyboard Shortcut: Press F or ب to open the search modal quickly. Press Esc to close any modal.

Financial Transactions Log

Every financial action is logged automatically. Review, filter, and export your complete transaction history with powerful filtering options.

Transaction Filtering

Date Filter

Filter transactions by specific dates. View today's transactions or search historical data by selecting a date.

Transaction Type

View only Payments, Expenses, or Balance adjustments. Or view all transactions together for a complete overview.

Export to Excel

Download your filtered report as an Excel file for accounting, tax preparation, or record keeping purposes.

Transaction Display:

  • Date & Time: When the transaction occurred
  • Type: Payment, Expense, or Balance with color-coded badges
  • Description: Detailed description of the transaction
  • Amount: Transaction amount with + (income) or - (expense) prefix

Payment Records

View and manage all patient payments with detailed information, multiple filtering options, and quick actions for viewing and printing receipts.

Payment Table Features

The payments table displays all payments received today with the following information:

  • Date & Time: When the payment was received
  • Patient: Patient name and phone number with avatar icon
  • Amount: Payment amount in EGP (displayed in green)
  • Type: Payment type badge (New Booking, Re-examination, Medical Consultation, Medical Procedure)
  • Payment Method: Method badge (Cash, Card, Transfer, Wallet)
  • Description: Additional notes or description
  • Actions: View details and Print receipt buttons

Filtering Options:

  • Quick Search: Search box to filter by patient name, phone, or payment ID in real-time
  • Type Filter: Filter by payment type (All, New Booking, Re-examination, Medical Consultation, Medical Procedure)
  • Payment Method Filter: Filter by payment method (All, Cash, Card, Transfer)

Payment Actions:

View Details
Opens payment details page with complete information, patient data, and related payments
Print Receipt
Generates and opens printable payment receipt in a new window

Payment Details

View comprehensive payment information including payment details, patient information, associated appointment (if any), and related payments for the same patient.

Payment Information Card

Payment Details:

Technical details about the Secretary Payments & Daily Balance Management implementation, including API endpoints, database structure, JavaScript functions, and workflow algorithms.

API Endpoints

The Secretary Payments system uses the same API endpoints as the Doctor Financial Management:

POST /api/daily-balance

Create daily balance entry (opening, additional, or withdrawal)

POST /api/expenses

Create new expense entry

GET /api/financial-transactions

Get paginated financial transactions with filters

GET /api/financial-transactions/export

Export transactions to Excel/CSV

GET /secretary/payments

Main payments page for secretaries

GET /secretary/payments/{id}

View payment details page

GET /secretary/payments/{id}/receipt

Generate and display printable payment receipt

GET /secretary/expenses/{id}

View expense details page

Search Implementation

Search Mechanism:

  • Real-time Search: Results appear automatically as user types (type-ahead)
  • Debouncing: Search requests are debounced to reduce API calls
  • Search Fields: Searches in patient name, phone number, and payment ID
  • Results Display: Shows matching payments with patient info, amount, type, and quick actions

Search States:

  • Initial State: Shows search icon and helpful text
  • Loading State: Shows spinner and "Searching..." message
  • Results State: Displays list of matching payments
  • No Results State: Shows message and suggestion to try different terms

Modal Behavior:

  • Search input is automatically focused when modal opens
  • Search is cleared when modal is closed
  • Modal can be closed with Esc key or Close button

Filtering System

Transaction Log Filters:

  • Date Filter: Date picker to filter by specific date
  • Type Filter: Dropdown to filter by transaction type (All, Payments, Expenses, Balance)
  • Filters are applied immediately on change
  • Pagination resets when filters change

Payment Records Filters:

  • Quick Search: Real-time text search in patient name, phone, or payment ID
  • Type Filter: Dropdown to filter by payment type
  • Method Filter: Dropdown to filter by payment method
  • All filters work together (AND logic)
  • Clear search button (X) resets search input

Error Handling

Client-Side:

  • Form validation before submission
  • Loading indicators during API calls
  • Success/error messages displayed in modals
  • Automatic dashboard refresh after successful operations
  • Empty state messages for tables with no data

Server-Side:

  • Authentication check on all endpoints (401 if unauthorized)
  • Input validation with detailed error messages
  • Database transaction safety
  • Error messages returned in JSON format
  • Proper HTTP status codes (200, 400, 401, 404, 500)
