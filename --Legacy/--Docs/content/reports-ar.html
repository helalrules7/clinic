التقارير الطبية

نظام تقارير شامل للأطباء لتحليل المواعيد والمرضى والإيرادات والوصفات الطبية مع خيارات تصفية قوية وتحليلات مرئية وإمكانيات تصدير.

التقارير التحليلات التصدير

نظرة عامة على التقارير

توفر صفحة التقارير الطبية للأطباء رؤى شاملة حول أداء ممارستهم. تتضمن خيارات تصفية قوية وإحصائيات ملخصة وجداول بيانات تفصيلية وتحليلات مرئية مع رسوم Chart.js.

صفحة التقارير الرئيسية مع الفلاتر وبطاقات الملخص وأزرار الإجراءات

تقارير المواعيد

تتبع إحصائيات المواعيد بما في ذلك إجمالي المواعيد والمكتملة والفائتة ونسبة الإنجاز بمرور الوقت.

تقارير المرضى

تحليل تسجيلات المرضى الجدد وتوزيع الجنس والديموغرافيا للمرضى لفهم أفضل لممارستك.

تقارير الإيرادات

مراقبة الإيرادات اليومية وإجمالي المعاملات والخصومات وقيم المعاملات المتوسطة للتحليل المالي.

الوصفات الطبية

عرض تحليلات الوصفات الطبية بما في ذلك إجمالي الوصفات والمواعيد مع الوصفات والأدوية الأكثر استخداماً.

وصفات النظارات

تتبع وصفات النظارات وتوزيع أنواع العدسات وأنماط الوصفات للخدمات البصرية.

فلاتر التقارير

نظام تصفية قوي يسمح لك بتخصيص التقارير حسب نطاق التاريخ ونوع التقرير. توفر أزرار نطاق التاريخ السريع وصولاً فورياً لفترات زمنية شائعة.

السلوك:

  • النقر على زر نطاق تاريخ سريع يحدث تلقائياً حقول "من تاريخ" و"إلى تاريخ"
  • يتم إرسال النموذج تلقائياً لتحديث التقرير
  • يتم تمييز الزر النشط بخلفية زرقاء
  • تغييرات التاريخ اليدوية تزيل الحالة النشطة من الأزرار السريعة

منتقي نوع التقرير

قائمة منسدلة مخصصة لنوع التقرير - انقر للتكبير

قائمة منسدلة مخصصة: قائمة منسدلة جميلة تحل محل عنصر HTML select القياسي:

  • تقارير المواعيد: عرض إحصائيات المواعيد (أيقونة: calendar-check)
  • تقارير المرضى: عرض المرضى الجدد والعائدين (أيقونة: people)
  • تقارير الإيرادات: عرض بيانات الإيرادات المالية (أيقونة: cash-coin)
  • الوصفات الطبية: عرض تحليلات الوصفات الطبية (أيقونة: prescription)
  • وصفات النظارات: عرض إحصائيات وصفات النظارات (أيقونة: eyeglasses)

الميزات:

  • يعرض كل خيار أيقونة وعنوان ووصف
  • الخيار المحدد مميز بخلفية زرقاء
  • دعم التنقل بلوحة المفاتيح (مفاتيح الأسهم، Enter، Escape)
  • النقر خارج القائمة لإغلاقها
  • إرسال النموذج تلقائياً عند تغيير النوع

اختيار التاريخ اليدوي

حقول التاريخ:

  • من تاريخ: تاريخ البداية لفترة التقرير (منتقي تاريخ)
  • إلى تاريخ: تاريخ النهاية لفترة التقرير (منتقي تاريخ)

السلوك:

  • تغيير أي حقل تاريخ يرسل النموذج تلقائياً
  • التحقق من التاريخ يضمن أن تاريخ البداية قبل تاريخ النهاية
  • يتم إلغاء تنشيط أزرار التاريخ السريعة عند تغيير التواريخ يدوياً

إحصائيات الملخص

يعرض كل نوع تقرير إحصائيات ملخصة ذات صلة بتنسيق البطاقات، مما يوفر رؤى سريعة في لمحة.

ملخص المواعيد

أربعة مقاييس رئيسية معروضة في بطاقات الإحصائيات:

إجمالي المواعيد

مجموع جميع المواعيد في نطاق التاريخ المحدد

مكتملة

عدد المواعيد بحالة "مكتملة"

فائتة

عدد المواعيد بحالة غير "مكتملة"

نسبة الإنجاز

النسبة المئوية: (المكتملة / إجمالي المواعيد) × 100

ملخص الإيرادات

المقاييس المالية لتقارير الإيرادات:

  • إجمالي الإيرادات: مجموع جميع مبالغ المدفوعات بالجنيه المصري
  • إجمالي المعاملات: عدد جميع معاملات المدفوعات
  • متوسط المعاملة: إجمالي الإيرادات / إجمالي المعاملات
  • إجمالي الخصومات: مجموع جميع مبالغ الخصومات المطبقة

ملخص المرضى

مقاييس ديموغرافيا المرضى:

  • إجمالي المرضى الجدد: عدد المرضى المنشأين في نطاق التاريخ
  • المرضى الذكور: عدد المرضى الذكور
  • المرضى الإناث: عدد المرضى الإناث
  • نسبة الذكور: (الذكور / إجمالي المرضى الجدد) × 100

ملخص الوصفات

الوصفات الطبية:

  • إجمالي الوصفات: عدد سجلات الوصفات المميزة
  • المواعيد مع الوصفات: عدد المواعيد التي تحتوي على وصفات
  • المرضى: عدد المرضى المميزين مع وصفات
  • المتوسط لكل موعد: إجمالي الوصفات / المواعيد مع الوصفات

وصفات النظارات:

  • إجمالي الوصفات: عدد سجلات وصفات النظارات المميزة
  • المواعيد مع الوصفات: عدد المواعيد مع وصفات النظارات
  • المرضى: عدد المرضى المميزين مع وصفات النظارات
  • مع نوع العدسة: عدد الوصفات التي تحتوي على نوع عدسة محدد

بيانات التقرير التفصيلية

جدول شامل يعرض التفصيل اليومي لجميع بيانات التقرير مع إمكانيات الترقيم والفرز والتصفية.

هيكل الجدول

جدول بيانات التقرير التفصيلي - انقر للتكبير

أعمدة الجدول حسب نوع التقرير:

تقارير المواعيد:

  • التاريخ: تاريخ الموعد (مُنسق كـ "شهر يوم، سنة")
  • إجمالي المواعيد: العدد الإجمالي للمواعيد في ذلك التاريخ
  • مكتملة: عدد المواعيد المكتملة (شارة خضراء)
  • فائتة: عدد المواعيد الفائتة (شارة حمراء)

تقارير الإيرادات:

  • التاريخ: تاريخ الدفع
  • الإيرادات اليومية: إجمالي الإيرادات لذلك اليوم بالجنيه المصري (عريض)
  • إجمالي المعاملات: عدد معاملات المدفوعات
  • الخصومات: إجمالي مبلغ الخصم بالجنيه المصري

تقارير المرضى:

  • التاريخ: تاريخ إنشاء المريض
  • المرضى الجدد: عدد المرضى الجدد المسجلين
  • المرضى الذكور: عدد المرضى الذكور (شارة زرقاء)
  • المرضى الإناث: عدد المرضى الإناث (شارة معلومات)

تقارير الوصفات الطبية:

  • التاريخ: تاريخ الموعد
  • إجمالي الوصفات: عدد سجلات الوصفات
  • المواعيد: عدد المواعيد مع الوصفات
  • المرضى: عدد المرضى المميزين
  • قائمة الأدوية: قائمة الأدوية الموصوفة مفصولة بفواصل (مقطوعة إلى 50 حرفاً)

تقارير وصفات النظارات:

  • التاريخ: تاريخ الموعد
  • إجمالي الوصفات: عدد سجلات وصفات النظارات
  • المواعيد: عدد المواعيد مع وصفات النظارات
  • المرضى: عدد المرضى المميزين
  • مع نوع العدسة: عدد الوصفات مع نوع عدسة محدد

خيارات الترقيم والعرض

قائمة منسدلة العرض: التحكم في عدد الصفوف المعروضة لكل صفحة:

  • 10 صفوف لكل صفحة
  • 20 صفاً لكل صفحة (افتراضي)
  • 50 صفاً لكل صفحة
  • 100 صف لكل صفحة
  • جميع الصفوف (بدون ترقيم)

عناصر التحكم في الترقيم:

  • أزرار السابق/التالي للتنقل
  • أرقام الصفحات مع علامات الحذف لمجموعات البيانات الكبيرة
  • الصفحة الحالية مميزة
  • تمرير سلس إلى الجدول عند تغيير الصفحة

الترقيم من جانب العميل: يتم التعامل مع جميع الترقيم من جانب العميل باستخدام JavaScript، مما يوفر تغييرات صفحة فورية دون طلبات الخادم.

التحليلات المرئية

توفر الرسوم البيانية التفاعلية المدعومة بـ Chart.js تمثيلاً مرئياً لبيانات التقرير، مما يجعل الاتجاهات والأنماط سهلة التحديد.

أنواع الرسوم البيانية

التحليلات المرئية مع الرسوم البيانية الخطية والحلقية - انقر للتكبير

رسوم تقارير المواعيد:

اتجاه المواعيد (رسم خطي)

يعرض الاتجاهات اليومية لإجمالي المواعيد (أزرق، منطقة مملوءة)، المكتملة (خط أخضر)، والفائتة (خط أحمر) بمرور الوقت

حالة المواعيد (رسم حلقي)

تفصيل مرئي للمواعيد المكتملة مقابل الفائتة مع النسب المئوية

رسوم تقارير الإيرادات:

اتجاه الإيرادات (رسم خطي)

الإيرادات اليومية (أخضر، منطقة مملوءة) والخصومات (خط أحمر) بمرور الوقت

الإيرادات مقابل الخصومات (رسم حلقي)

مقارنة مرئية لإجمالي الإيرادات مقابل إجمالي الخصومات

رسوم تقارير المرضى:

اتجاه المرضى الجدد (رسم خطي)

يعرض المرضى الجدد (أزرق، منطقة مملوءة)، المرضى الذكور (خط معلومات)، والمرضى الإناث (خط تحذير)

توزيع الجنس (رسم حلقي)

تفصيل مرئي للذكور مقابل الإناث مع النسب المئوية

رسوم تقارير الوصفات:

  • الوصفات الطبية: رسم اتجاه يوضح إجمالي الوصفات والمواعيد مع الوصفات والمرضى. رسم حلقي للأدوية الأكثر استخداماً يوضح الأدوية الأكثر استخداماً.
  • وصفات النظارات: رسم اتجاه يوضح إجمالي الوصفات والمواعيد والمرضى ومع نوع العدسة. رسم حلقي لتوزيع نوع العدسة يوضح تفصيل نوع العدسة.

ميزات الرسم البياني:

  • دعم الثيم: تتكيف الرسوم البيانية تلقائياً مع الثيم الفاتح/الداكن
  • تلميحات تفاعلية: مرر فوق نقاط البيانات لرؤية القيم التفصيلية
  • متجاوب: تغير الرسوم البيانية حجمها تلقائياً بناءً على حجم الحاوية
  • الأسطورة: أسطورة ملونة تشرح كل سلسلة بيانات
  • جاهز للتصدير: الرسوم البيانية مُضمنة في تصديرات PDF

وظيفة التصدير

تصدير التقارير بتنسيقات متعددة للمشاركة أو الأرشفة أو مزيد من التحليل في التطبيقات الخارجية.

تصدير CSV

الميزات:

  • تصدير جميع بيانات التقرير (وليس الصفحة الحالية فقط) إلى تنسيق CSV
  • متوافق مع Excel وGoogle Sheets وتطبيقات جداول البيانات الأخرى
  • يتضمن جميع الأعمدة ذات الصلة بنوع التقرير المحدد
  • تسمية الملف: بناءً على نوع التقرير ونطاق التاريخ

الاستخدام: انقر زر "تصدير CSV" لتحميل ملف CSV فوراً.

تصدير PDF

تقرير PDF الشامل يتضمن:

1
رأس التقرير
عنوان نوع التقرير ونطاق التاريخ وطابع وقت الإنشاء
2
إحصائيات الملخص
بطاقات الملخص المُلتقطة كصور مع جميع المقاييس
3
التحليلات المرئية
جميع الرسوم البيانية (الخطية والحلقية) المُلتقطة كصور عالية الدقة
4
الجدول التفصيلي
جدول بيانات كامل مع جميع الصفوف (غير مرقم)، رؤوس متكررة على كل صفحة
5
التذييل
اسم العيادة واسم الطبيب وأرقام الصفحات على كل صفحة

عملية إنشاء PDF:

  • يستخدم مكتبة jsPDF لإنشاء PDF
  • يستخدم html2canvas لالتقاط الرسوم البيانية وبطاقات الملخص كصور
  • يتعامل تلقائياً مع فواصل الصفحات للجداول الطويلة
  • يخفي عناصر التحكم في واجهة المستخدم (الأزرار، القوائم المنسدلة) أثناء التصدير
  • يعرض حالة التحميل أثناء الإنشاء
  • تسمية الملف: {report_type}_report_{start_date}_to_{end_date}.pdf

الاستخدام: انقر زر "تصدير PDF" (يظهر فقط عند وجود بيانات التقرير). يعرض الزر "جاري إنشاء PDF..." أثناء العملية.

التنفيذ التقني

التفاصيل التقنية حول تنفيذ التقارير الطبية، بما في ذلك نقاط نهاية API واستعلامات قاعدة البيانات ووظائف JavaScript وعرض الرسوم البيانية ووظيفة التصدير.

نقاط نهاية API

GET /doctor/reports

صفحة التقارير الرئيسية مع التصفية وعرض البيانات

معاملات الاستعلام:
  • type - نوع التقرير (appointments, patients, revenue, medical_prescriptions, glasses_prescriptions)
  • start_date - تاريخ البداية (YYYY-MM-DD)
  • end_date - تاريخ النهاية (YYYY-MM-DD)
GET /doctor/reports/export

تصدير بيانات التقرير إلى تنسيق CSV

معاملات الاستعلام:
  • type - نوع التقرير
  • start_date - تاريخ البداية
  • end_date - تاريخ النهاية
  • format - تنسيق التصدير (csv)

استعلامات قاعدة البيانات

طرق إنشاء التقرير: يستخدم كل نوع تقرير استعلام SQL محدد في DoctorController.php:

تقرير المواعيد
الجداول: appointments يجمع حسب DATE(date)، يعد إجمالي، مكتمل (status='Completed')، وفائت (status != 'Completed')
تقرير المرضى
الجداول: patients, appointments يجمع حسب DATE(created_at)، يعد المرضى الجدد والذكور والإناث
تقرير الإيرادات
الجداول: payments, appointments يجمع حسب DATE(created_at)، يجمع amount (daily_revenue)، يعد المعاملات، يجمع discount_amount
تقرير الوصفات الطبية
الجداول: prescriptions, appointments يجمع حسب DATE(date)، يعد الوصفات المميزة والمواعيد والمرضى وGROUP_CONCAT أسماء الأدوية
تقرير وصفات النظارات
الجداول: glasses_prescriptions, appointments يجمع حسب DATE(date)، يعد الوصفات المميزة والمواعيد والمرضى ومع نوع العدسة

نمط الاستعلام المشترك:

  • جميع الاستعلامات تصفي حسب نطاق التاريخ باستخدام BETWEEN ? AND ?
  • تقرير المواعيد يستثني اليوم: DATE(date) < CURDATE()
  • النتائج مجمعة حسب التاريخ ومرتبة تصاعدياً
  • يستخدم دوال التجميع: COUNT، SUM، COUNT(DISTINCT)، GROUP_CONCAT

التنسيق لصفحة التقارير بما في ذلك القائمة المنسدلة المخصصة وبطاقات الإحصائيات والجدول وحاويات الرسوم البيانية
@app/Views/doctor/assets/js/reports.js
JavaScript لأزرار نطاق التاريخ والقائمة المنسدلة المخصصة وتهيئة الرسم البياني والترقيم وتصدير PDF
@app/Controllers/DoctorController.php
طرق المتحكم:
  • reports() - يعرض صفحة التقارير مع البيانات
  • exportDoctorReport() - يتعامل مع تصدير CSV
  • generateDoctorReport() - يوجه إلى مولد تقرير محدد
  • generateDoctorAppointmentsReport() - استعلام SQL للمواعيد
  • generateDoctorPatientsReport() - استعلام SQL للمرضى
  • generateDoctorRevenueReport() - استعلام SQL للإيرادات
  • generateDoctorMedicalPrescriptionsReport() - استعلام SQL للوصفات الطبية
  • generateDoctorGlassesPrescriptionsReport() - استعلام SQL لوصفات النظارات
  • getTopMedications() - يحصل على الأدوية الأكثر استخداماً للوصفات الطبية
  • getGlassesLensTypeStats() - يحصل على إحصائيات نوع العدسة
@index.php
يحدد المسارات:
  • GET /doctor/reports - صفحة التقارير الرئيسية
  • GET /doctor/reports/export - نقطة نهاية تصدير CSV

تكامل Chart.js

المكتبة: Chart.js v4.4.0 (محمّل من CDN)

أنواع الرسوم البيانية المستخدمة:

  • الرسوم البيانية الخطية: لتصور الاتجاهات (المواعيد، الإيرادات، المرضى، الوصفات بمرور الوقت)
  • الرسوم البيانية الحلقية: لتفصيلات الحالة/التوزيع (مكتمل/فائت، إيرادات/خصومات، جنس، أدوية، أنواع عدسات)

تكامل الثيم:

  • تكتشف الرسوم البيانية الثيم تلقائياً عبر getCurrentThemeColors()
  • مستمع تغيير الثيم يحدث جميع الرسوم البيانية عند النقر على تبديل الثيم
  • تتكيف الألوان للنص وخطوط الشبكة والتلميحات والخلفيات
  • يستخدم MutationObserver لاكتشاف تغييرات الفئة على documentElement

إعداد بيانات الرسم البياني:

  • يتم تمرير البيانات من PHP عبر كائن JavaScript window.REPORTS_CONFIG
  • يتم تنسيق التواريخ باستخدام toLocaleDateString() للعرض
  • مجموعات بيانات متعددة لكل رسم بياني للمقارنة (مثل، إجمالي مقابل مكتمل مقابل فائت)
  • الألوان تستخدم لوحة محددة مسبقاً مع شفافية ألفا للمناطق المملوءة

تنفيذ تصدير PDF

المكتبات:

  • jsPDF: v2.5.1 - مكتبة إنشاء PDF
  • html2canvas: v1.4.1 - تحويل HTML إلى صورة للرسوم البيانية والبطاقات

عملية التصدير:

1
إخفاء عناصر التحكم
إخفاء جميع الأزرار والقوائم المنسدلة وعناصر التحكم في واجهة المستخدم
2
التقاط الملخص
استخدام html2canvas لالتقاط بطاقات إحصائيات الملخص
3
التقاط الرسوم البيانية
التقاط كل canvas للرسم البياني كصورة عالية الدقة
4
بناء الجدول
بناء جدول PDF يدوياً مع جميع البيانات (غير مرقم)، تكرار الرؤوس على كل صفحة
5
إضافة التذييل
إضافة اسم العيادة واسم الطبيب وأرقام الصفحات لجميع الصفحات
6
حفظ واستعادة
حفظ ملف PDF واستعادة عناصر التحكم المخفية في واجهة المستخدم

الميزات:

  • فواصل صفحات تلقائية للمحتوى الطويل
  • التقاط صورة عالية الدقة (scale: 2)
  • تنسيق مناسب للتواريخ والأرقام والعملة
  • معالجة الأخطاء مع رسائل سهلة للمستخدم
  • حالة التحميل أثناء الإنشاء

معالجة الأخطاء

من جانب العميل:

  • التحقق من نطاق التاريخ (تاريخ البداية يجب أن يكون قبل تاريخ النهاية)
  • رسالة حالة فارغة عندما لا يتم العثور على بيانات للفترة المحددة
  • معالجة أخطاء تهيئة الرسم البياني
  • معالجة أخطاء تصدير PDF مع تنبيهات المستخدم
  • معالجة حالات الحافة للترقيم (بيانات فارغة، صفحة واحدة، إلخ)

من جانب الخادم:

  • التحقق من المصادقة (يجب أن يكون الطبيب مسجلاً دخولاً)
  • معالجة أخطاء استعلام SQL مع كتل try-catch
  • معالجة أخطاء تصدير CSV مع إعادة توجيه إلى صفحة التقارير
  • نطاق تاريخ افتراضي إذا كانت المعاملات مفقودة
  • نوع تقرير افتراضي إذا تم توفير نوع غير صالح
