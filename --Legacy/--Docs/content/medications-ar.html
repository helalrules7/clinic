نافذة تفاصيل الوصفة

فتح بطاقة وصفة يفتح نافذة تفصيلية تعرض جميع وصفات الأدوية لذلك المريض، منظمة حسب الموعد مع أقسام أكورديون قابلة للتوسيع.

هيكل النافذة

رأس النافذة:

  • العنوان: "{اسم المريض} - وصفات الأدوية"
  • زر الإغلاق (X) في الزاوية العلوية اليمنى

أكورديون المواعيد:

يُعرض كل موعد مع وصفات كعنصر أكورديون:

1
رأس الموعد
يعرض معرف الموعد والتاريخ والوقت ونوع الزيارة وعدد الوصفات. يتضمن أيقونة التوسيع/الطي (chevron)
2
أزرار الإجراءات
أزرار "عرض الموعد" (أخضر) و"طباعة الوصفة" (أزرق) لكل موعد
3
قائمة الوصفات
عند التوسيع، يعرض جميع الأدوية الموصوفة في ذلك الموعد مع التفاصيل الكاملة

تفاصيل الدواء:

يعرض كل دواء في الموعد الموسع:

  • اسم الدواء: اسم الدواء الكامل (مثل "CIDAMEX 250 MG 20 TABS.")
  • رمز Rx: رمز "℞" أحمر يشير إلى الوصفة
  • الجرعة: جرعة الدواء إن وجدت
  • التكرار: عدد مرات تناول الدواء
  • المدة: مدة تناول الدواء
  • طريقة الاستخدام: طريقة الإعطاء (مثل "موضعي"، "فموي")
  • تعليمات خاصة: ملاحظات أو تعليمات إضافية إن وُجدت

تذييل النافذة:

  • زر عرض المريض: يفتح صفحة تفاصيل المريض في تبويب جديد
  • زر الإغلاق: يغلق النافذة

سلوك الأكورديون:

  • الموعد الأول (الأحدث) موسع افتراضياً
  • النقر على رأس الموعد يبدل التوسيع/الطي
  • يمكن توسيع موعد واحد فقط في كل مرة (أكورديون Bootstrap)
  • أيقونة chevron تدور للإشارة إلى الحالة (لأسفل = مطوي، لأعلى = موسع)

الترقيم وزر تحميل المزيد

يستخدم المعرض ترقيم تمرير لا نهائي مع زر "تحميل المزيد" لتحميل بطاقات وصفات إضافية حسب الحاجة.

زر تحميل المزيد

الميزات:

  • التحميل الأولي: يتم تحميل أول 12 بطاقة وصفة تلقائياً
  • تحميل المزيد: يظهر الزر عندما تتوفر وصفات إضافية
  • حالة التحميل: يستبدل المؤشر الدوار الزر أثناء التحميل
  • الإخفاء التلقائي: يخفي الزر عندما يتم تحميل جميع الوصفات

تصميم الزر:

  • مركز بين خطوط أفقية للفصل البصري
  • زر كبير وبارز مع أيقونة سهم لأسفل
  • لون أزرق أساسي ليتطابق مع الثيم
  • حالة معطلة أثناء التحميل لمنع النقرات المتعددة

تفاصيل الترقيم:

  • لكل صفحة: 12 بطاقة وصفة لكل صفحة
  • تتبع الصفحة: يتم تتبع الصفحة الحالية داخلياً
  • يوجد المزيد: يشير الخادم إلى ما إذا كانت هناك صفحات إضافية متاحة
  • إعادة التعيين عند التصفية: يتم إعادة تعيين الترقيم عند تطبيق أو مسح فلتر المريض

الحالة الفارغة

عندما لا يتم العثور على وصفات أدوية، يتم عرض رسالة حالة فارغة ودية لإعلام المستخدم.

عرض الحالة الفارغة

متى يُعرض:

  • لا توجد وصفات أدوية في النظام
  • فلتر المريض لا يعيد نتائج
  • تم تحميل جميع الوصفات ولم يتبق أي منها

محتوى الحالة الفارغة:

  • أيقونة كبسولة كبيرة (لون خافت)
  • العنوان: "لم يتم العثور على وصفات أدوية"
  • الرسالة: "لا توجد وصفات أدوية متاحة في هذا الوقت."

التنفيذ التقني

التفاصيل التقنية حول تنفيذ وصفات الأدوية، بما في ذلك نقاط نهاية API واستعلامات قاعدة البيانات ووظائف JavaScript وخوارزميات سير العمل.

نقاط نهاية API

GET /doctor/medications

صفحة معرض وصفات الأدوية الرئيسية

GET /api/medications/prescriptions

الحصول على وصفات الأدوية المرقمة مجمعة حسب المريض

معاملات الاستعلام:
  • page - رقم الصفحة (افتراضي: 1)
  • patient_id - فلتر اختياري حسب معرف المريض
الاستجابة:
  • success - منطقي يشير إلى النجاح
  • data - مصفوفة من كائنات وصفات المريض
  • pagination - بيانات وصفية للترقيم (current_page, total_pages, total, per_page, has_more)
GET /api/medications/prescriptions/patient

الحصول على جميع وصفات الأدوية لمريض محدد، مجمعة حسب الموعد

معاملات الاستعلام:
  • patient_id - معرف المريض المطلوب
الاستجابة:
  • success - منطقي يشير إلى النجاح
  • data - مصفوفة من كائنات المواعيد، كل منها يحتوي على مصفوفة وصفات
GET /api/patients/search

البحث عن المرضى بالاسم للإكمال التلقائي (يُستخدم بواسطة فلتر المريض)

معاملات الاستعلام:
  • q - استعلام البحث (الحد الأدنى حرفين)
  • limit - الحد الأقصى للنتائج (افتراضي: 10)

استعلامات قاعدة البيانات

استعلام المعرض الرئيسي:

getMedicationsPrescriptions()
الجداول: prescriptions, appointments, patients يجمع الوصفات حسب patient_id، يعد المواعيد المميزة لكل مريض، يحصل على تاريخ آخر وصفة، ويتضمن تفاصيل آخر وصفة للصورة المصغرة

استعلام وصفات المريض:

getPatientMedicationsPrescriptions()
الجداول: appointments, prescriptions يحصل على المواعيد المميزة مع الوصفات لمريض، ثم يجلب تفاصيل الوصفة الكاملة لكل موعد، مرتبة حسب التاريخ DESC

ميزات الاستعلام:

  • يستخدم GROUP BY لتجميع الوصفات حسب المريض
  • يستخدم COUNT(DISTINCT appointment_id) لعد المواعيد، وليس الوصفات
  • يستخدم MAX(created_at) للحصول على تاريخ آخر وصفة
  • يدعم بند WHERE اختياري لتصفية المريض
  • يرتب النتائج حسب تاريخ آخر وصفة (DESC)
  • الترقيم باستخدام LIMIT و OFFSET

وظائف JavaScript الرئيسية

الملف: @app/Views/doctor/assets/js/medications.js

الوظائف الرئيسية:

loadPrescriptions()
يحمل بطاقات الوصفات من API مع الترقيم، يتعامل مع حالات التحميل، ويعرض البطاقات في المعرض
renderPrescriptionCards(patients)
ينشئ ويعرض عناصر بطاقة الوصفة لكل مريض مع الصورة المصغرة والشارة والطبقة العلوية
setupPatientSearch()
يعد بحث الإكمال التلقائي مع مستمعي الإدخال والتنقل بلوحة المفاتيح ومعالجات النقر
searchPatients(query)
يجلب نتائج بحث المريض من API ويعرض القائمة المنسدلة للإكمال التلقائي
displayAutocomplete(patients)
يعرض القائمة المنسدلة للإكمال التلقائي مع نتائج المرضى، يتعامل مع أحداث النقر والتمرير
navigateAutocomplete(direction)
يتعامل مع التنقل بلوحة المفاتيح (السهم لأعلى/لأسفل) عبر نتائج الإكمال التلقائي
selectPatient(patientId, patientName)
يطبق فلتر المريض، يحدث واجهة المستخدم، ويعيد تحميل الوصفات للمريض المحدد
clearFilter()
يزيل فلتر المريض، يمسح واجهة المستخدم، ويعيد تحميل جميع الوصفات
openPrescriptionView(patientId, patientName)
يفتح نافذة معاينة الوصفة، يحمل وصفات المريض، ويعرض قائمة الأكورديون
renderPrescriptionList(appointments, patientId)
يعرض قائمة أكورديون للمواعيد مع الوصفات، بما في ذلك تفاصيل الأدوية
formatDate(dateString)
يُنسق سلسلة التاريخ إلى تنسيق اللغة العربية (مثل "10 ديسمبر، ٢٠٢٥")
formatTime(timeString)
يُنسق سلسلة الوقت إلى تنسيق HH:MM
escapeHtml(text)
يهرب أحرف HTML لمنع هجمات XSS في أسماء الأدوية والملاحظات

إدارة الحالة:

  • currentPage - يتتبع صفحة الترقيم الحالية
  • isLoading - يمنع استدعاءات API متعددة متزامنة
  • hasMore - يشير إلى ما إذا كانت هناك صفحات إضافية متاحة
  • selectedPatientId - معرف المريض المصفى حالياً
  • selectedPatientName - اسم المريض المصفى حالياً
  • autocompleteItems - مصفوفة نتائج بحث الإكمال التلقائي
  • selectedAutocompleteIndex - عنصر الإكمال التلقائي المميز حالياً

معالجة الأخطاء

من جانب العميل:

  • مؤشرات التحميل أثناء استدعاءات API
  • عرض الحالة الفارغة عندما لا يتم العثور على نتائج
  • معالجة الأخطاء في وعود fetch مع تسجيل وحدة التحكم
  • بحث متأخر لمنع استدعاءات API المفرطة
  • التحقق من الإدخال (الحد الأدنى حرفين للبحث)
  • حماية XSS عبر دالة escapeHtml()

من جانب الخادم:

  • التحقق من المصادقة (مطلوب دور طبيب أو مدير)
  • التحقق من الإدخال (يجب أن يكون patient_id عدداً صحيحاً)
  • معالجة أخطاء استعلام SQL مع كتل try-catch
  • استجابات خطأ JSON مع رموز حالة HTTP مناسبة
  • معالجة النتائج الفارغة (تُرجع مصفوفة فارغة، وليس خطأ)
