Doctor's Calendar Overview

The Doctor's Calendar is a comprehensive appointment management system that allows doctors to view, manage, and schedule patient appointments efficiently. It provides a day-by-day view of appointments with real-time updates, filtering options, and seamless patient management integration.

Patient Management

Integrated patient search with autocomplete and the ability to add new patients directly from the appointment modal.

Page Controls

The Doctor's Calendar includes various controls for navigation, filtering, and appointment management.

Auto-Refresh Toggle

Location: Top-left, next to "Calendar" title

Function: Enables/disables automatic calendar updates every 60 seconds

Behavior: When enabled, calendar data refreshes automatically without manual intervention. Updates pause when modals are open to prevent data loss.

JavaScript: toggleCalendarAutoRefresh(checked) in calendar.js

Go to Date Button

Location: Top-right control area

Function: Opens a popover with date picker to navigate to a specific date

Behavior: Clicking the button shows a date picker tooltip. Selecting a date and clicking "Go to Date" navigates the calendar to that date.

Validation: Prevents selecting dates before today (based on Egypt timezone)

Add Appointment Button

Location: Top-right, green button

Function: Opens the "Add New Appointment" modal

Behavior: Opens modal with current calendar date pre-selected. Allows adding appointments for the currently viewed date.

JavaScript: openAddAppointmentModal(null, currentDate)

Today Button

Location: Top-right, navigation button group

Function: Quickly returns calendar view to today's date

Behavior: Resets currentDate to today and reloads calendar

Previous Day Button

Location: Top-right, left arrow in navigation group

Function: Navigates to the previous day

Behavior: Decrements currentDate by 24 hours and reloads calendar

Next Day Button

Location: Top-right, right arrow in navigation group

Function: Navigates to the next day

Behavior: Increments currentDate by 24 hours and reloads calendar

Filter Controls

Time-based filters help doctors focus on specific appointment periods or availability status.

Time Range Filters

Available Filters:

  • "2:00 PM - 6:00 PM": Shows appointments in afternoon hours
  • "6:00 PM - 10:45 PM": Shows appointments in evening hours

Function: Filters calendar to show only appointments within selected time range

JavaScript: applyTimeFilter(filter) with data-filter attribute

Available Only Filter

Function: Shows only available time slots (no appointments)

Use Case: Quickly identify open slots for scheduling new appointments

Visual: Highlights available slots with green styling and "+" icon

Appointments Only Filter

Function: Shows only booked appointments (hides available slots)

Use Case: Focus on scheduled appointments without distraction from empty slots

Visual: Displays only appointment cards with patient information

Clear Filters Button

Function: Removes all active filters and shows complete calendar view

Behavior: Resets filter state and reloads full calendar data

Calendar Structure

The calendar displays appointments in a two-column layout with time slots and appointment details.

Click to view full size

Visual demonstration of the calendar structure

Time Column (Left)

Structure: Vertical list of time slots in 15-minute intervals

Format: Displays time in 12-hour format (e.g., "02:00 PM", "02:15 PM")

Range: Covers working hours (typically 2:00 PM to 10:45 PM)

Purpose: Provides time reference for each appointment slot

Appointments Column (Right)

Structure: Corresponding appointment cards or available slots for each time

Booked Appointments: Display as colored cards with:

  • Patient name
  • Doctor name
  • Visit type (New, Follow Up, Procedure)
  • Time range (start - end)
  • Progress bar (for active appointments)
  • Action buttons (View, Edit, Delete)
  • Notes preview

Available Slots: Display as green dashed boxes with "+ Available - [Time]" and clickable to add appointment

Date Display

Location: Card header above calendar

Format: "Day, Month Day, Year" (e.g., "Sunday, December 14, 2025")

Update: Changes automatically when navigating between dates

Live Status Indicator

Location: Top-right of calendar card

Components:

  • "Live" Badge: Green badge indicating real-time updates
  • Last Updated: Timestamp showing last refresh time (e.g., "Last updated: 02:34:40 PM")

Update Frequency: Updates every 60 seconds when auto-refresh is enabled

How to Add Appointment

The appointment creation process includes patient selection, date/time selection, and appointment details configuration.

Click to view full size

Visual demonstration of the Add Appointment modal

Step 1: Select Patient

Patient Search Field: Type patient name or phone number

Autocomplete: As you type (minimum 2 characters), system searches and displays matching patients

Search Results: Click on a patient from results to select them

API Endpoint: /api/patients/search?q={query}

JavaScript: searchPatients() with 300ms debounce

Step 2: Select Date

Date Field: Pre-filled with current calendar date

Validation: Cannot select dates before today (Egypt timezone)

Time Slot Loading: Changing date automatically loads available time slots for that date

JavaScript: loadAvailableTimeSlots() triggered on date change

Step 3: Select Time Slot

Time Dropdown: Custom select menu showing available time slots

Data Source: Fetched from /api/calendar?doctor_id={id}&date={date}

Format: 15-minute intervals (e.g., "02:00 PM", "02:15 PM")

Quick Add: Clicking "+ Available" slots in calendar opens modal with that time pre-selected

Step 4: Fill Appointment Details

Visit Type: Select from dropdown (New Patient, Follow Up, Procedure)

Source: Select booking source (Walk-in, Phone)

Notes: Optional textarea for additional appointment notes

Step 5: Save Appointment

Submit: Click "Save Appointment" button

Validation: Form validates required fields (patient, date, time, visit type)

API Call: POST to /api/appointments with appointment data

Success: Modal closes, calendar refreshes, success notification shown

JavaScript: handleAddAppointment(e) handles form submission

Autocomplete Patient Name

The patient search field provides real-time autocomplete functionality to quickly find and select patients.

How It Works

Trigger: User types in patient search field

Minimum Characters: Search triggers after 2 characters are typed

Debounce: 300ms delay prevents excessive API calls while typing

JavaScript: document.getElementById('patientSearch').addEventListener('input', debounce(searchPatients, 300))

Backend Search

API Endpoint: GET /api/patients/search?q={query}

Search Fields: Searches in patient first name, last name, and phone number

Response: Returns array of matching patients with:

  • Patient ID
  • First name and last name
  • Phone number
  • Age (if available)

Results Display

Container: #patientSearchResults div below search field

Format: Each result shows:

  • Patient full name (bold)
  • Phone number and age (smaller text)

Selection: Clicking a result calls selectPatient(patientId, patientName) which:

  • Sets #selectedPatientId hidden field
  • Fills search field with patient name
  • Clears search results

JavaScript: displayPatientSearchResults(patients) renders results

Empty State

No Results: Displays "No patients found" message

Less Than 2 Characters: Search results container is cleared

Preselected Patient: Search is disabled if patient is pre-selected (from URL parameter)

Add New Patient from Appointment Modal

The system allows adding new patients directly from the appointment creation modal, with automatic selection in the appointment form.

Accessing Add Patient

Button Location: Next to patient search field (person-plus icon button)

Button ID: #newPatientBtn

Behavior: Clicking button:

  • Closes current "Add Appointment" modal
  • Opens "Add New Patient" modal after 300ms delay

JavaScript: Event listener on #newPatientBtn click

Patient Form Fields

Required Fields:

  • First Name
  • Last Name
  • Phone Number
  • Gender (Male/Female)

Optional Fields:

  • Age (years) - auto-calculates date of birth if provided
  • Date of Birth - alternative to age
  • Address

Keyboard Shortcut: Ctrl+S to submit form

Submitting Patient Form

API Endpoint: POST /api/patients

Request Format: FormData with patient information

Response: Returns created patient object with ID

JavaScript: submitPatientForm() handles submission

Auto-Selection Process

After Patient Creation:

  1. Patient modal closes after 1.5 seconds
  2. Appointment modal reopens after 300ms
  3. selectNewPatient(patientData) is called with new patient data
  4. Patient search field is filled with full name
  5. Patient ID is set in hidden field
  6. Success message shows "New Patient Added" with patient info
  7. Visit type is automatically set to "New"

JavaScript Function: selectNewPatient(patientData) in calendar.js

Search Refresh

Automatic Refresh: After auto-selection, patient search is refreshed after 1 second to ensure new patient appears in search results

Purpose: Validates that patient was successfully added to database

Error Handling

Validation Errors: Form validation shows field-specific error messages

Server Errors: Error message displayed in modal alert

Auto-Selection Failure: If patient data is invalid, warning notification shown and user must search manually

Technical Implementation

Key JavaScript functions and API endpoints that power the calendar functionality.

Key JavaScript Functions

  • loadCalendar() - Loads calendar data for current date
  • openAddAppointmentModal() - Opens appointment creation modal
  • searchPatients() - Searches patients with autocomplete
  • selectPatient() - Selects patient from search results
  • loadAvailableTimeSlots() - Loads available time slots for date
  • handleAddAppointment() - Handles appointment form submission
  • selectNewPatient() - Auto-selects newly added patient
  • quickAddAppointment() - Quick add from available slot click

API Endpoints

  • GET /api/calendar?doctor_id={id}&date={date} - Get calendar data
  • GET /api/patients/search?q={query} - Search patients
  • POST /api/patients - Create new patient
  • POST /api/appointments - Create appointment
  • GET /api/appointments/{id} - Get appointment details
  • PUT /api/appointments/{id} - Update appointment
  • DELETE /api/appointments/{id} - Delete appointment

Auto-Refresh Mechanism

Interval: 60 seconds (60000ms)

Function: setInterval() calls refreshCalendarData()

Condition: Only refreshes if no modals are open

Check: Verifies modal state before refreshing to prevent data loss

Data Flow

  1. User opens calendar page
  2. loadCalendar() fetches appointments for current date
  3. Calendar renders appointments and available slots
  4. User clicks "Add Appointment" or available slot
  5. Modal opens with date pre-filled
  6. User searches/selects patient or adds new patient
  7. Time slots load based on selected date
  8. Form submitted, appointment created
  9. Calendar refreshes to show new appointment
