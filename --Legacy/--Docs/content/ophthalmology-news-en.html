Ophthalmology News Overview

The Ophthalmology News component provides real-time access to the latest research, clinical updates, and news from leading ophthalmology journals and medical news sources. It automatically aggregates content from multiple RSS feeds and displays breaking news prominently.

RSS Feed Aggregation

Automatically fetches and aggregates news from multiple trusted ophthalmology sources including BJO, Nature Eye, MedPage Today, and more.

Breaking News Detection

Intelligently identifies breaking news using keyword detection (breaking, urgent, alert, critical, emergency) and displays them prominently.

Auto-Update System

Content is automatically updated every 20 minutes using a caching system to ensure fresh news while minimizing server load.

How It Works

The Ophthalmology News system is powered by the API Controller, which handles RSS feed fetching, content processing, and caching.

API Endpoint:

The news system is accessed through /api/ophthalmology-news endpoint in ApiController.php, specifically the getOphthalmologyNews() method.

RSS Feed Fetching

The system fetches RSS feeds from multiple sources:

  • Research Sources: BJO (British Journal of Ophthalmology), Nature Eye
  • Clinical Sources: MedPage Today, Retina Specialist, Retina Today
  • News Sources: Medical News Today, Healio

Each feed is fetched using cURL with proper timeout handling and error management.

Content Processing

The system processes multiple RSS formats:

  • RSS 2.0: Standard RSS format with channel and item elements
  • RSS 1.0 (RDF): RDF-based RSS format with namespaces
  • Atom: Atom feed format with entry elements

XML parsing handles different namespaces and formats automatically, extracting title, link, description, and publication date.

Content Filtering

Articles are filtered and sorted:

  • Time Filter: Only articles from the last 3 months (90 days) are included
  • Breaking News: Articles with breaking keywords are prioritized
  • Category Filter: Optional filtering by category (research, clinical, news, or all)
  • Sorting: Breaking news first, then by date (newest first)
  • Limit: Maximum of 15 articles displayed

Saving and Updating Content

The system uses a file-based caching mechanism to store and update news content efficiently.

Cache File Storage

News articles are cached in a JSON file:

  • Location: storage/ophthalmology_news_cache.json
  • Format: JSON with timestamp and articles array
  • Structure: 
    {
  "timestamp": 1234567890,
  "articles": [
    {
      "title": "Article Title",
      "link": "https://...",
      "description": "...",
      "pubDate": "...",
      "source": "BJO",
      "source_icon": "📄",
      "category": "research",
      "is_breaking": false
    }
  ]
}

Cache Duration

The cache system works as follows:

  • Cache Duration: 20 minutes (1200 seconds)
  • Cache Check: On each API request, the system checks if cache exists and is still valid
  • Cache Hit: If cache is valid, articles are returned immediately without fetching RSS feeds
  • Cache Miss: If cache is expired or missing, RSS feeds are fetched and cache is updated

Automatic Updates

The update process:

  • Trigger: API request when cache is expired or missing
  • Process: Fetch all RSS feeds → Parse XML → Filter articles → Sort by breaking/news date → Limit to 15
  • Save: Updated articles array with current timestamp saved to cache file
  • Fallback: If fetching fails, old cache is used even if expired to ensure content availability
Cache Management:

The cache file is automatically created and updated by the API controller. No manual intervention is required. The system ensures that news content is always available, even if RSS feeds are temporarily unavailable, by using cached data as a fallback.

Key Features

The Ophthalmology News component includes several features designed to keep doctors informed.

Breaking News Indicator

Breaking news articles are automatically detected and displayed with a prominent "BREAKING" badge, ensuring urgent updates are immediately visible.

Horizontal Ticker

News articles are displayed in a horizontal scrolling ticker format, allowing multiple headlines to be visible at once while maintaining a compact design.

Clickable Articles

Each news item is clickable and opens the full article in a new tab, allowing doctors to read complete articles from the original source.

Theme Support

The news ticker automatically adapts to light and dark themes, ensuring optimal readability in all viewing conditions.
