Roles Overview

The Roaya Clinic Management System implements a Role-Based Access Control (RBAC) system with three distinct user roles, each designed to handle specific responsibilities within the clinic workflow.

Doctor Role

The primary medical professional role with comprehensive access to patient care, medical records, prescriptions, and clinical operations.

  • Full patient management
  • Medical consultations & examinations
  • Prescription management
  • Clinical reports & statistics
Learn More

Administrator Role

System administrator with full access to system configuration, user management, backups, and administrative functions.

  • User & role management
  • System configuration
  • Backup & restore
  • System monitoring
Learn More

Secretary Role

Administrative staff role focused on appointment scheduling, patient registration, payment processing, and front-office operations.

  • Booking management
  • Patient registration
  • Payment processing
  • Invoice management
Learn More

Access Control & Security

The system implements robust security measures to ensure proper access control and data protection.

Authentication

  • Username-based login system
  • Secure password hashing
  • Session management
  • Automatic session timeout

Authorization

  • Role-based access control (RBAC)
  • Route-level permissions
  • Feature-level restrictions
  • View As mode (Admin only)

Security Features

  • CSRF token protection
  • Input validation & sanitization
  • SQL injection prevention
  • XSS protection
