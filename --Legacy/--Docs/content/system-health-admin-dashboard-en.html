System Health Overview

The System Health component provides real-time monitoring of critical system infrastructure including database connectivity, storage space, PHP version, and required extensions. It helps administrators quickly identify system issues and ensure optimal performance.

PHP & Extensions

Displays PHP version and checks for required extensions, ensuring system compatibility and functionality.

Component Structure

The System Health component consists of multiple health check items displayed in a card.

Header Section

The header includes:

  • Title: "System Health" with heartbeat icon
  • Styling: Card header with border-bottom separator

Health Items

Each health check item contains:

  • Icon: Relevant icon for the health metric (database, storage, PHP)
  • Label: Name of the health metric
  • Status Badge: Color-coded badge showing status (success, warning, danger)
  • Details: Additional information (for storage: progress bar and usage text)

Health Metrics

Detailed explanation of each health metric displayed in the component.

Database Status

Check Method: Executes SELECT 1 query to test connection

Status Display:

  • Connected: Green badge if query succeeds
  • Error: Red badge with error message if query fails

Purpose: Ensures database connectivity is working properly

Storage Space

Check Method: Uses PHP disk_free_space() and disk_total_space()

Metrics Displayed:

  • Used Space: Formatted bytes (e.g., "15.51 GB")
  • Total Space: Formatted bytes (e.g., "968.99 GB")
  • Usage Percentage: Calculated and displayed as badge
  • Progress Bar: Visual representation of storage usage

Color Coding:

  • Green: < 80% usage (healthy)
  • Yellow: 80-90% usage (warning)
  • Red: > 90% usage (critical)

PHP Version

Check Method: Uses PHP constant PHP_VERSION

Display: Shows current PHP version (e.g., "8.2.28")

Badge Color: Info (cyan) badge

Purpose: Helps verify PHP version compatibility

Required Extensions

Check Method: Uses PHP extension_loaded() function

Extensions Checked:

  • pdo: PHP Data Objects extension
  • pdo_mysql: PDO MySQL driver
  • json: JSON encoding/decoding
  • mbstring: Multibyte string functions

Status Display:

  • Loaded: Green badge if extension is available
  • Missing: Red badge if extension is not loaded

How It Works

The System Health component performs real-time checks and displays results with color-coded status indicators.

Backend Processing

AdminController::getSystemHealth() method:

  • Database Check: Tries $pdo->query('SELECT 1'), catches exceptions
  • Storage Check: Calculates free/total/used space from storage directory
  • PHP Version: Gets PHP_VERSION constant
  • Extensions Check: Loops through required extensions, checks with extension_loaded()
  • Formatting: Uses formatBytes() helper for storage display
  • Returns: Array with 'database', 'storage', 'php_version', 'extensions' keys

Frontend Rendering

The dashboard template renders health metrics:

  • Health Items: Each metric uses health-item class
  • Status Badges: Dynamic badge colors based on status
  • Progress Bar: Bootstrap progress bar for storage usage
  • Conditional Styling: Badge colors change based on thresholds
  • Responsive: Adapts to different screen sizes

Color Coding

Status badge colors:

  • Success (Green): Database connected, storage < 80%, extensions loaded
  • Warning (Yellow): Storage 80-90% usage
  • Danger (Red): Database error, storage > 90%, extensions missing
  • Info (Cyan): PHP version display

Key Features

The System Health component includes several features for effective system monitoring.

Real-Time Checks

All health metrics are checked in real-time on each page load, ensuring current system status is always displayed.

Visual Alerts

Color-coded badges and progress bars provide immediate visual feedback about system health status.

Detailed Information

Each metric provides detailed information (storage amounts, PHP version, extension status) for comprehensive monitoring.
