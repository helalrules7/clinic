Quick Overview

Stats Cards display essential metrics in an easy-to-read format, providing instant insights into key performance indicators.

Visual Trends

Each card includes a mini line chart showing trends over time, helping doctors understand data patterns at a glance.

Color-Coded

Cards use color coding to indicate positive (green), negative (red), or neutral trends, making it easy to identify areas that need attention.

Available Stats Cards

The Doctor Dashboard includes several types of stats cards, each displaying different key metrics.

Total Appointments Today

Displays the total number of appointments scheduled for the current day, providing a quick overview of the day's workload.

  • Shows real-time count of today's appointments
  • Includes calendar icon for visual identification
  • Updates automatically throughout the day

Completed Appointments

Tracks the number of appointments that have been successfully completed, along with completion percentage and trend visualization.

  • Shows total completed appointments
  • Displays completion percentage (e.g., 95.8%)
  • Includes green trend line chart showing progress

Missed Appointments

Monitors appointments that were not attended, helping doctors identify patterns and improve scheduling efficiency.

  • Shows count of missed appointments
  • Displays missed percentage (e.g., 4.2%)
  • Includes red/pink trend line chart for visibility

New Patients

Tracks the number of new patients registered, with trend indicators showing whether the number is increasing or decreasing.

  • Shows total new patients count
  • Displays percentage change with arrow indicator (↑ or ▼)
  • Includes yellow/orange trend line chart
  • Helps track patient growth over time

Prescriptions Described

Monitors the number of prescriptions written, providing insights into prescription activity and workload.

  • Shows total prescriptions count
  • Displays percentage change with trend indicator
  • Includes blue trend line chart
  • Helps track prescription patterns

Key Features

Stats Cards include several features designed to enhance usability and provide comprehensive information.

Real-Time Updates

All stats cards update in real-time as data changes, ensuring doctors always have access to the latest information.

Theme Support

Stats cards automatically adapt to the selected theme (light or dark), ensuring optimal readability and visual consistency.

Trend Visualization

Mini line charts at the bottom of each card provide visual representation of data trends, making it easy to spot patterns and changes.

Percentage Indicators

Cards display percentage values and change indicators (↑ or ▼) to show trends and comparisons, helping doctors understand relative performance.
