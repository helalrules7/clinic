Quick Actions Overview

Quick Actions provides instant access to the most frequently used features and functions in the Doctor Dashboard. The component displays colorful, iOS-style cards arranged horizontally, allowing doctors to quickly navigate to essential functions with a single tap or click.

How It Works

Quick Actions is implemented using JavaScript for scroll management and CSS for responsive design and touch optimization.

Horizontal Scroll Management

The component uses JavaScript to manage horizontal scrolling:

  • Scroll Amount: Each navigation click scrolls by 160px (card width + gap)
  • Navigation Arrows: Left and right arrows appear on hover to navigate through cards
  • Fade Indicators: Gradient fades appear on edges when more content is available
  • Auto-Hide Arrows: Arrows hide when at the start or end of the scroll

Touch Gesture Support

Mobile touch gestures are fully supported:

  • Swipe Detection: Touch start, move, and end events track swipe gestures
  • Horizontal Swipe: Swiping left/right scrolls the card grid horizontally
  • Swipe Threshold: Minimum 50px swipe distance required to trigger scroll
  • RTL Support: Swipe direction is automatically adjusted for RTL languages
  • Passive Listeners: Touch events use passive listeners for better performance

Mouse Wheel Support

Desktop users can scroll using mouse wheel:

  • Horizontal Scroll: Mouse wheel scrolls horizontally when over the Quick Actions area
  • Vertical Prevention: Vertical scrolling is prevented when horizontal scroll is detected
  • Smooth Behavior: Smooth scrolling animation for better user experience

Touch Responsiveness on Mobile

Quick Actions is fully optimized for mobile devices with comprehensive touch support and responsive design.

Swipe Gestures

Touch swipe gestures enable natural navigation:

  • Touch Start: Records initial touch position (X and Y coordinates)
  • Touch Move: Tracks finger movement to determine swipe direction
  • Touch End: Calculates swipe distance and direction, triggers scroll if threshold met
  • Direction Detection: Distinguishes between horizontal and vertical swipes
  • RTL Adjustment: Swipe directions are reversed for RTL languages (Arabic)

Responsive Card Sizing

Cards automatically adjust size for different screen sizes:

  • Desktop: Larger cards (typically 140px × 140px)
  • Tablet: Medium-sized cards optimized for tablet screens
  • Mobile (≤768px): Smaller cards (110px × 110px) for better fit
  • Small Mobile (≤480px): Even smaller cards (100px × 100px) for compact screens
  • Flex Shrink: Cards use flex-shrink: 0 to prevent compression

Smooth Scrolling

Optimized scrolling behavior for touch devices:

  • Scroll Snap: scroll-snap-type: x mandatory for snap-to-card scrolling
  • Touch Scrolling: -webkit-overflow-scrolling: touch for smooth iOS scrolling
  • Hidden Scrollbar: Scrollbar is hidden for cleaner appearance
  • Smooth Behavior: scroll-behavior: smooth for animated scrolling

Touch Target Optimization

Cards are designed with optimal touch targets:

  • Minimum Size: Cards meet minimum 44px × 44px touch target guidelines
  • Spacing: Adequate gap between cards prevents accidental taps
  • Tap Feedback: Visual feedback on tap/click for better user experience
  • No Hover on Touch: Navigation arrows are hidden on touch devices (hover: none)
Mobile Optimization:

The Quick Actions component automatically detects touch devices and adjusts its behavior accordingly. Navigation arrows are hidden on touch devices since users can swipe naturally. The component uses CSS media queries and JavaScript feature detection to provide the best experience on each device type.
