البحث المتقدم

وصول سريع لوظيفة البحث الشاملة مع فلترة ذكية باستخدام عوامل & و #.

مركز الإشعارات

إشعارات وتنبيهات مباشرة مع شريط جانبي مخصص لإدارة جميع تحديثات النظام والأحداث.

تبديل الثيم

التبديل بين الثيم الفاتح والداكن مع حفظ تلقائي للتفضيلات في إعدادات المستخدم والتخزين المحلي.

الملف الشخصي

وصول سريع للملف الشخصي للمستخدم، الإعدادات، وخيارات إدارة الحساب.

شريط الإشعارات الجانبي

شريط الإشعارات الجانبي يوفر نظرة شاملة لجميع إشعارات النظام والتنبيهات.

انقر لعرض الحجم الكامل

عرض توضيحي مرئي لشريط الإشعارات الجانبي

ميزات شريط الإشعارات الجانبي:
  • تحديثات إشعارات مباشرة
  • إعلانات تحديثات النظام
  • تنبيهات المرضى والمواعيد
  • إشعارات الأنشطة والأحداث

زر تحديد الكل كمقروء

زر علامة الاختيار () يسمح لك بتحديد جميع الإشعارات كمقروءة دفعة واحدة، مما يزيل شارة الإشعارات ويحدث حالة الإشعارات.

زر حذف الكل

زر أيقونة سلة المهملات () يتيح لك حذف جميع الإشعارات من الشريط الجانبي، مما يوفر طريقة سريعة لمسح قائمة الإشعارات.

زر الإغلاق

زر X () يغلق شريط الإشعارات الجانبي، ويعيدك إلى عرض لوحة التحكم الرئيسية.

عرض جميع الإشعارات

زر "عرض جميع الإشعارات" يفتح عرضاً شاملاً يعرض جميع الإشعارات مع معلومات مفصلة، الطوابع الزمنية، وخيارات الإجراءات.

انقر لعرض الحجم الكامل

عرض شامل لجميع الإشعارات

تبديل الثيم

مبدل الثيم يسمح لك بالتبديل بين الوضع الفاتح والداكن مع حفظ تلقائي للتفضيلات.

ميزات تبديل الثيم:
  • تبديل فوري للثيم بين الوضع الفاتح والداكن
  • حفظ تلقائي للتفضيلات في جدول إعدادات المستخدم في قاعدة البيانات
  • تخزين مؤقت محلي لتحديثات الثيم السريعة
  • ثبات الثيم عبر جلسات المتصفح
  • تطبيق الثيم مباشرة دون إعادة تحميل الصفحة

التخزين في قاعدة البيانات

تفضيل الثيم الخاص بك يتم حفظه تلقائياً في جدول user_settings في قاعدة البيانات، مما يضمن الحفاظ على تفضيلك عبر جميع الأجهزة والجلسات.

  • قيمة الثيم مخزنة كـ 'light' أو 'dark'
  • مرتبطة بحساب المستخدم الخاص بك
  • متزامنة عبر جميع أجهزتك

التخزين المحلي

لتحميل أسرع للثيم، يتم أيضاً تخزين تفضيلك مؤقتاً في التخزين المحلي للمتصفح، مما يسمح بتطبيق الثيم فوراً دون انتظار استعلامات قاعدة البيانات.

  • مخزن كـ localStorage.getItem('theme')
  • تطبيق الثيم فوراً عند تحميل الصفحة
  • الرجوع إلى قاعدة البيانات إذا كان التخزين المحلي فارغاً

المزامنة

النظام يزامن بذكاء بين التخزين المحلي وقاعدة البيانات:

  • عند تغيير الثيم: تحديث كل من التخزين المحلي وقاعدة البيانات
  • عند تحميل الصفحة: فحص التخزين المحلي أولاً، ثم قاعدة البيانات
  • المزامنة في الخلفية تضمن الاتساق

تحديثات سريعة

التخزين المحلي يتيح تبديل الثيم فوراً دون طلبات الخادم، مما يوفر تجربة مستخدم سلسة وسريعة الاستجابة.

  • لا حاجة لإعادة تحميل الصفحة
  • ردود فعل بصرية فورية
  • انتقال سلس للثيم
كيف يعمل:
  1. المستخدم ينقر على مبدل الثيم: يتم النقر على زر تبديل الثيم
  2. تحديث فوري: يتم تطبيق الثيم فوراً باستخدام التخزين المحلي
  3. حفظ في الخلفية: يتم حفظ التفضيل في قاعدة البيانات في الخلفية
  4. الثبات: تفضيل الثيم يبقى عبر الجلسات والأجهزة
