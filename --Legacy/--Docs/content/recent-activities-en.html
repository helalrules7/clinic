Recent Activities Overview

The Recent Activities component displays a chronological timeline of system events and user actions, providing doctors with a comprehensive view of recent activities in the clinic management system. It tracks appointments, prescriptions, patient records, and other important events.

Activity Timeline

User Attribution

Each activity shows the user who performed the action, making it easy to track who did what and when.

Activity Types

The system tracks various types of activities and events.

Medication Activities

Track medication-related actions:

  • Medication prescription issued
  • Medication deleted
  • Medication updated

Appointment Activities

Monitor appointment-related events:

  • Appointment booked
  • Status changed (Booked → Completed, etc.)
  • Appointment rescheduled

File Activities

Track file and media uploads:

  • Files uploaded (images, documents)
  • Media attached to patient records
  • File deletions

Prescription Activities

Monitor prescription-related actions:

  • Medical prescriptions issued
  • Glasses prescriptions created
  • Prescription modifications

View All Modal

The "View All" button opens a comprehensive modal displaying all activities with advanced filtering and pagination capabilities.

Filter Activities

The modal includes a powerful filter system:

  • Search Input: Filter activities by event summary, patient name, or phone number
  • Real-Time Filtering: Filter updates as you type with debouncing for performance
  • Text Highlighting: Matching text is highlighted in yellow for easy identification
  • Clear Filter: Button to quickly reset the filter and show all activities

Pagination

Activities are paginated for better performance:

  • Per Page Selection: Choose how many activities to display (10, 25, 50, 100 per page)
  • Page Navigation: Navigate between pages using pagination controls
  • Total Count: Display total number of activities matching the filter
  • Client-Side Filtering: All activities are loaded once, then filtered client-side for instant results

Data Loading

The modal uses efficient data loading:

  • Initial Load: Loads up to 1000 activities when modal opens
  • Client-Side Processing: Filtering and pagination happen in the browser for instant response
  • API Endpoint: Uses /api/recent-activity endpoint from ApiController
  • Caching: Activities are cached in memory during modal session
Modal Features:

The "View All" modal provides a comprehensive view of all system activities. It includes a search/filter input at the top, pagination controls, and displays activities in a scrollable list. Each activity shows the event description, associated user, timestamp, and relevant action links. The modal uses a glassmorphism design with backdrop blur for a modern appearance.

How It Works

Recent Activities is powered by the API Controller and uses JavaScript for modal management and client-side filtering.

API Endpoint

The system uses ApiController::getRecentActivity():

  • Endpoint: /api/recent-activity
  • Authentication: Requires user authentication
  • Pagination: Supports page and per_page parameters
  • Search: Supports search parameter for filtering
  • Data Source: Queries timeline_events table joined with patients and appointments

Search and Filter

The API supports server-side filtering:

  • Search Fields: Event summary, patient first name, last name, full name, phone
  • SQL LIKE: Uses SQL LIKE queries with wildcards for flexible matching
  • Client-Side Filter: Modal also performs client-side filtering for instant results
  • Debouncing: Filter input uses debouncing to reduce API calls

Modal Management

JavaScript handles modal functionality:

  • Modal Open: Loads activities when modal is shown
  • Data Loading: Fetches up to 1000 activities on first open
  • Filter Application: Applies filter to loaded activities client-side
  • Pagination: Handles pagination of filtered results
  • Text Highlighting: Highlights matching text in search results
