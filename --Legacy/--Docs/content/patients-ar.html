المرضى إدارة تصفية

نظرة عامة على صفحة المرضى

توفر صفحة المرضى واجهة شاملة لإدارة سجلات المرضى، بما في ذلك عرض الإحصائيات والبحث والتصفية وإضافة مرضى جدد وتعديل السجلات الحالية وتنفيذ إجراءات متعددة متعلقة بالمريض.

بطاقات الإحصائيات

أربع بطاقات إحصائية تعرض إجمالي المرضى وإجمالي الزيارات والزيارات الأخيرة (آخر 7 أيام) والمرضى الجدد هذا الشهر (آخر 30 يومًا).

بحث متقدم

وظيفة بحث سريع مع إكمال تلقائي، البحث عن طريق اسم المريض أو رقم الهاتف أو الرقم القومي. يتم عرض النتائج في نافذة منبثقة مع إجراءات المريض.

فلاتر متعددة

تصفية المرضى حسب الطبيب والجنس والفئة العمرية وتاريخ آخر زيارة. يمكن دمج الفلاتر ومسحها بسهولة.

بطاقات الإحصائيات

أربع بطاقات إحصائية توفر نظرة سريعة على بيانات المرضى في أعلى الصفحة.

إجمالي المرضى

التسمية: "TOTAL PATIENTS"

القيمة: العدد الإجمالي لجميع المرضى في النظام

الوصف: "الكل" - يشير إلى أن هذا عدد تراكمي

الأيقونة: أيقونة شخصين (مستخدمين)

مصدر البيانات: العدد من جدول patients

إجمالي الزيارات

التسمية: "TOTAL VISITS"

القيمة: العدد الإجمالي لجميع المواعيد

الوصف: "جميع المواعيد" - عدد المواعيد التراكمي

الأيقونة: أيقونة تقويم مع علامة صح

مصدر البيانات: العدد من جدول appointments

الزيارات الأخيرة

التسمية: "RECENT VISITS"

القيمة: عدد المواعيد في آخر 7 أيام

الوصف: "آخر 7 أيام" - مؤشر النطاق الزمني

الأيقونة: أيقونة تقويم

مصدر البيانات: العدد المصفى من جدول appointments حيث date >= DATE_SUB(NOW(), INTERVAL 7 DAY)

جدد هذا الشهر

التسمية: "NEW THIS MONTH"

القيمة: عدد المرضى الذين تم إنشاؤهم في آخر 30 يومًا

الوصف: "آخر 30 يومًا" - مؤشر النطاق الزمني

الأيقونة: مستخدم مع أيقونة زائد

مصدر البيانات: العدد المصفى من جدول patients حيث created_at >= DATE_SUB(NOW(), INTERVAL 30 DAY)

نظام التصفية

تتضمن صفحة المرضى خيارات تصفية متعددة لمساعدتك في العثور على سجلات مرضى محددة بسرعة.

تصفية حسب الطبيب

الموقع: فوق جدول المرضى

الخيارات: زر "جميع الأطباء" بالإضافة إلى أزرار الأطباء الفردية

الوظيفة: تصفية المرضى حسب الطبيب الذي أنشأ سجلهم

التنفيذ: filterByDoctor(doctorId) في patients.js

مصدر البيانات: حقل created_by_doctor_id في سجلات المرضى

البصري: يتم تمييز الفلتر النشط، ويظهر "عرض المرضى لـ: [اسم الطبيب]" أدناه

تصفية حسب الجنس

الموقع: رأس عمود الجنس مع أيقونة تصفية

الخيارات: ذكر، أنثى، أو مسح الفلتر

الوظيفة: تصفية المرضى حسب الجنس (ذكر/أنثى)

التنفيذ: applyGenderFilter(gender) في patients.js

النافذة: تفتح نافذة منبثقة مع أزرار اختيار لتحديد الجنس

البصري: تصبح أيقونة الفلتر نشطة عند تطبيق الفلتر

تصفية حسب النطاق العمري

الموقع: رأس عمود العمر مع أيقونة تصفية

الخيارات: حقول إدخال الحد الأدنى والحد الأقصى للعمر

الوظيفة: تصفية المرضى ضمن نطاق عمري محدد

التنفيذ: applyAgeFilter(min, max) في patients.js

الحساب: يتم حساب العمر من حقل dob (تاريخ الميلاد)

النافذة: تفتح نافذة منبثقة مع مدخلات أرقام للحد الأدنى/الأقصى للعمر

تصفية حسب آخر زيارة

الموقع: رأس عمود آخر زيارة مع أيقونة تصفية

الخيارات: محددات التاريخ من وإلى

الوظيفة: تصفية المرضى حسب تاريخ آخر موعد لهم

التنفيذ: applyLastVisitFilter(from, to) في patients.js

مصدر البيانات: حقل last_visit (أقصى تاريخ موعد لكل مريض)

النافذة: تفتح نافذة منبثقة مع محدد نطاق التاريخ

مسح جميع المرشحات

الموقع: منطقة التصفية، زر "مسح الفلاتر"

الوظيفة: يزيل جميع الفلاتر النشطة ويعيد التعيين لعرض جميع المرضى

التنفيذ: clearAllFilters() في patients.js

السلوك: يعيد تعيين جميع حالات الفلترة ويعيد عرض الجدول مع جميع المرضى

عرض توضيحي للفلاتر الذكية (الجنس، العمر، آخر زيارة)

الوظيفة: بحث فوري أثناء الكتابة (مع تأخير)

عناصر لكل صفحة

الموقع: أعلى يمين الجدول، قائمة منسدلة "عرض:"

الخيارات: 10، 20، 30، 50، الكل

الافتراضي: 20 عنصرًا لكل صفحة

الوظيفة: يتحكم في عدد المرضى المعروضين في الصفحة الواحدة

التنفيذ: changeItemsPerPage(count) في patients.js

أعمدة الجدول

الأعمدة:

  • اسم المريض: صورة رمزية مع الأحرف الأولى، الاسم الكامل، معرف المريض
  • الهاتف: الهاتف الأساسي والبديل مع إجراءات الاتصال/واتساب
  • الجنس: شارة مع أيقونة الجنس (ذكر/أنثى)
  • العمر: محسوب من تاريخ الميلاد
  • الطبيب: اسم الطبيب الذي أنشأ سجل المريض
  • آخر زيارة: تاريخ أحدث موعد
  • إجمالي الزيارات: عدد جميع المواعيد
  • الإجراءات: أزرار عرض، تعديل، حجز، وحذف

الترتيب

الموقع: رؤوس الأعمدة مع أيقونات ترتيب

الوظيفة: انقر فوق رأس العمود للترتيب تصاعديًا/تنازليًا

الأعمدة القابلة للترتيب: الاسم، الهاتف، العمر، آخر زيارة، إجمالي الزيارات

التنفيذ: sortPatients(sortBy, sortOrder) في patients.js

الحالة: مخزنة في paginationState.sortBy و paginationState.sortOrder

ترقيم الصفحات

الموقع: أسفل الجدول

العرض: "عرض X إلى Y من Z مريضًا"

التنقل: أزرار السابق/التالي وأرقام الصفحات

التنفيذ: renderPaginationNav() و goToPage(page) في patients.js

الحالة: paginationState.currentPage يتتبع الصفحة الحالية

قسم المعلومات الأساسية

الحقول:

  • الاسم الأول *: حقل نصي مطلوب
  • اسم العائلة *: حقل نصي مطلوب

التنفيذ التقني

الملفات والدوال وهياكل قاعدة البيانات الرئيسية التي تشغل صفحة المرضى.

الملفات الرئيسية

  • View: app/Views/doctor/patient.php - صفحة ملف المريض
  • View: app/Views/doctor/patients.php - صفحة قائمة المرضى
  • JavaScript: app/Views/doctor/assets/js/patients.js - منطق جانب العميل
  • Controller: app/Controllers/DoctorController.php - منطق الواجهة الخلفية
  • API Controller: app/Controllers/ApiController.php - نقاط نهاية API

دوال JavaScript الرئيسية

  • initializePagination() - ييتم تهيئة الترحيل ببيانات PHP
  • renderPatientsTable() - يعرض جدول المرضى ببيانات الصفحة الحالية
  • filterByDoctor(doctorId) - يفلتر المرضى حسب الطبيب
  • applyGenderFilter(gender) - يفلتر المرضى حسب الجنس
  • applyAgeFilter(min, max) - يفلتر المرضى حسب النطاق العمري
  • applyLastVisitFilter(from, to) - يفلتر المرضى حسب تاريخ آخر زيارة
  • filterPatientsLocally(query) - تصفية البحث المحلي
  • searchPatients(query) - بحث المرضى المستند إلى API
  • openAddPatientModal() - يفتح نافذة إضافة مريض
  • editPatient(patientId) - يفتح نافذة تعديل المريض
  • deletePatient(patientId, name) - يحذف المريض مع التأكيد
  • bookAppointment(patientId) - يعيد التوجيه إلى التقويم مع المريض
  • viewPatient(patientId) - يفتح صفحة ملف المريض

نقاط النهاية API

  • GET /doctor/patients - يعرض صفحة قائمة المرضى
  • GET /doctor/patients/{id} - يعرض صفحة ملف المريض
  • GET /api/doctor/patients - يجلب جميع المرضى (JSON)
  • GET /api/doctor/patients/{id} - يجلب مريضًا واحدًا (JSON)
  • POST /api/doctor/patients - ينشئ مريضًا جديدًا
  • PUT /api/doctor/patients/{id} - يحدث بيانات المريض
  • DELETE /api/doctor/patients/{id} - يحذف المريض
  • GET /api/doctor/search-patients?q={query} - يبحث عن المرضى

جداول قاعدة البيانات

  • patients: سجلات المرضى الرئيسية (الاسم، الهاتف، تاريخ الميلاد، الخ)
  • appointments: مواعيد المرضى (تستخدم لعدد الزيارات وتاريخ آخر زيارة)
  • timeline_events: الجدول الزمني لنشاط المريض
  • users: معلومات الطبيب
  • doctors: بيانات خاصة بالطبيب

طرق المتحكم

  • DoctorController::patients() - يعرض صفحة قائمة المرضى
  • DoctorController::showPatient($id) - يعرض صفحة ملف المريض
  • DoctorController::getAllPatients() - يجلب جميع المرضى مع الإحصائيات
  • DoctorController::getPatient($id) - يجلب مريضًا واحدًا
  • DoctorController::updatePatient($id) - يحدث سجل المريض
  • DoctorController::deletePatient($id) - يحذف سجل المريض
  • ApiController::searchPatients() - يبحث عن المرضى عبر API
