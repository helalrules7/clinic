نظرة عامة على المواعيد القادمة

مكون المواعيد القادمة يعرض قائمة بالمواعيد المجدولة المحجوزة أو المسجلة، مما يوفر للأطباء نظرة واضحة على جدولهم القادم. كل موعد يظهر معلومات المريض، تفاصيل الوقت، الحالة، ويتضمن شريط تقدم مباشر يشير إلى الوقت المتبقي حتى الموعد.

انقر لعرض الحجم الكامل

عرض توضيحي مرئي لواجهة المواعيد القادمة

قائمة المواعيد

يعرض المواعيد القادمة مرتبة حسب التاريخ والوقت، مع عرض فقط المواعيد بحالة "محجوز" أو "تم التسجيل".

تقدم مباشر

كل موعد يتضمن شريط تقدم يتحدث مباشرة، مما يظهر الوقت المتبقي حتى بدء الموعد.

إجراءات سريعة

روابط مباشرة لعرض تفاصيل الموعد أو الوصول لملف المريض بنقرة واحدة.

بنية المكون

مكون المواعيد القادمة يتكون من عدة عناصر رئيسية تعمل معاً لتوفير واجهة إدارة مواعيد شاملة.

قسم الرأس

الرأس يتضمن:

  • العنوان: "المواعيد القادمة" مع أيقونة تقويم
  • زر عرض الكل: يربط بصفحة التقويم الكاملة (/doctor/calendar)

بطاقة الموعد

كل موعد معروض كبطاقة تحتوي على:

  • اسم المريض: رابط قابل للنقر لملف المريض
  • نطاق الوقت: وقت البداية والنهاية (مثلاً "14:00 - 14:15")
  • التاريخ: تاريخ الموعد بتنسيق DD/MM/YYYY
  • شارة الحالة: مؤشر مرئي (محجوز، تم التسجيل)
  • نوع الزيارة: نوع الزيارة (جديد، متابعة، إجراء)
  • شريط التقدم: عد تنازلي مباشر للموعد

أزرار الإجراءات

زران إجراء لكل موعد:

  • زر الموعد: يفتح صفحة تفاصيل الموعد (/doctor/appointments/{id})
  • زر المريض: يفتح صفحة ملف المريض (/doctor/patients/{patient_id})

شريط التقدم

مكون شريط التقدم يتضمن:

  • تأثير الزجاج: تصميم glassmorphism حديث مع تأثير ضبابي
  • تحديثات مباشرة: يتحدث كل ثانية لإظهار الوقت المتبقي
  • ملء مرئي: ملء التقدم يشير إلى الوقت المنقضي/المتبقي
  • عرض الوقت: يظهر الوقت المتبقي بتنسيق HH:MM
  • عرض مشروط: يظهر فقط للمواعيد غير المكتملة وغير المعاد جدولتها

الترقيم

ضوابط الترقيم للتنقل عبر عدة مواعيد:

  • تنقل الصفحات: أزرار السابق/التالي وأرقام الصفحات
  • الحد الافتراضي: 4 مواعيد لكل صفحة
  • إخفاء تلقائي: مخفي عندما تكون هناك صفحة واحدة فقط

كيف يعمل

مكون المواعيد القادمة يعمل من خلال API Controller ويستخدم JavaScript للعرض الديناميكي والتحديثات المباشرة.

نقطة نهاية API:

المكون يستخدم نقطة النهاية /api/upcoming-appointments في ApiController.php، تحديداً طريقة getUpcomingAppointments().

جلب البيانات

نقطة نهاية API:

  • المصادقة: يتطلب مصادقة المستخدم
  • معرف الطبيب: يسترجع تلقائياً معرف الطبيب من المستخدم المصادق عليه
  • فلتر التاريخ: يجلب فقط المواعيد من اليوم فصاعداً (date >= today)
  • فلتر الحالة: يتضمن فقط المواعيد بحالة "محجوز" أو "تم التسجيل"
  • الترتيب: يرتب حسب التاريخ (تصاعدي) ثم وقت البداية (تصاعدي)
  • الترقيم: يدعم معاملات page و per_page

عملية العرض

JavaScript يتعامل مع العرض:

  • التحميل الأولي: loadUpcomingAppointments() يجلب البيانات عند تحميل الصفحة
  • معالجة البيانات: ينسق التواريخ والأوقات للعرض
  • إنشاء HTML: renderUpcomingAppointments() ينشئ بطاقات المواعيد
  • تهيئة التلميحات: تلميحات Bootstrap للعناصر التفاعلية
  • تهيئة شريط التقدم: يعد شريط التقدم المباشر

تحديثات مباشرة

نظام شريط التقدم:

  • التهيئة: initializeAppointmentProgressBars() يجد جميع حاويات التقدم
  • دالة التحديث: updateAppointmentProgressBar() يحسب الوقت المتبقي
  • الفترة: يتحدث كل ثانية (1000ms) باستخدام setInterval
  • حساب الوقت: يحسب الوقت بين الآن ووقت بدء الموعد
  • ملء التقدم: يحدث نسبة العرض بناءً على الوقت المنقضي
  • عرض النص: يظهر الوقت المتبقي بتنسيق "HH:MM"

نظام شريط التقدم

شريط التقدم هو مكون متطور يوفر ردود فعل مرئية مباشرة حول المواعيد القادمة.

حساب الوقت

النظام يحسب الوقت المتبقي:

  • الوقت الحالي: يحصل على التاريخ والوقت الحالي
  • بداية الموعد: يجمع تاريخ الموعد ووقت البداية
  • فرق الوقت: يحسب الميلي ثانية بين الآن وبداية الموعد
  • المدة: يفترض مدة موعد 15 دقيقة (900 ثانية)
  • نسبة التقدم: يحسب كم من الوقت انقضى

التصميم المرئي

شريط التقدم يستخدم glassmorphism:

  • تأثير الزجاج: خلفية شبه شفافة مع ضبابية
  • ملء متدرج: تدرج متحرك يملأ مع تقدم الوقت
  • تراكب النص: الوقت المتبقي معروض فوق شريط التقدم
  • متجاوب: يتكيف مع عرض الحاوية

منطق العرض

شريط التقدم معروض بشكل مشروط:

  • يظهر لـ: المواعيد بحالة "محجوز" أو "تم التسجيل"
  • مخفي لـ: المواعيد المكتملة أو المعاد جدولتها
  • إخفاء تلقائي: يخفي عندما يكون وقت الموعد قد مضى
حالات شريط التقدم:

شريط التقدم يظهر حالات مختلفة بناءً على الوقت:

  • قبل الموعد: يظهر الوقت المتبقي حتى البداية
  • أثناء الموعد: يظهر الوقت المتبقي حتى النهاية
  • بعد الموعد: يخفي تلقائياً أو يظهر الإكمال

الميزات الرئيسية

مكون المواعيد القادمة يتضمن عدة ميزات مصممة لمساعدة الأطباء في إدارة جدولهم بفعالية.

عرض زمني

المواعيد مرتبة حسب التاريخ والوقت، مما يضمن ظهور المواعيد الأكثر إلحاحاً أولاً.

تنقل سريع

روابط مباشرة لتفاصيل الموعد وملفات المرضى للوصول السريع للمعلومات ذات الصلة.

دعم الثيم

المكون يتكيف تلقائياً مع الثيمات الفاتحة والداكنة، مما يضمن قابلية قراءة مثلى في جميع ظروف العرض.

تصميم متجاوب

تخطيط متجاوب بالكامل يعمل بسلاسة على سطح المكتب، الجهاز اللوحي، والأجهزة المحمولة.
