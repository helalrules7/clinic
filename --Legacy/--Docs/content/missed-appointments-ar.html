نظرة عامة على المواعيد الفائتة

مكون المواعيد الفائتة يعرض جميع المواعيد من الأيام السابقة التي لم يتم إكمالها. يساعد هذا الأطباء على تتبع المواعيد التي تحتاج إلى متابعة أو إعادة جدولة أو تحديد كمكتملة.

انقر لعرض الحجم الكامل

عرض توضيحي مرئي لواجهة المواعيد الفائتة

تتبع الفائتة

يحدد تلقائياً المواعيد من الأيام السابقة التي لديها حالة غير 'Completed' أو 'Cancelled'، مما يساعدك على تتبع المتابعات.

الترقيم

يدعم الترقيم مع عناصر قابلة للتخصيص لكل صفحة (5، 10، 20، 50)، مما يسهل التنقل عبر قوائم كبيرة من المواعيد الفائتة.

إجراءات سريعة

يوفر أزرار إجراءات سريعة لتحديد المواعيد كمكتملة، عرض تفاصيل الموعد، أو الوصول إلى ملفات تعريف المرضى.

بنية المكون

مكون المواعيد الفائتة يتكون من رأس مع أزرار تحكم وقائمة مرقمة من المواعيد.

قسم الرأس

الرأس يتضمن:

  • العنوان: "المواعيد الفائتة" مع أيقونة مثلث تحذير
  • منتقي لكل صفحة: قائمة منسدلة لاختيار العناصر لكل صفحة (5، 10، 20، 50)
  • أزرار التحكم: أزرار نقل لأعلى/أسفل ومقبض سحب لإعادة الترتيب

قائمة المواعيد

كل موعد يتم عرضه كعنصر قائمة يحتوي على:

  • اسم المريض: الاسم الكامل بالأزرق، رابط قابل للنقر لملف تعريف المريض
  • النطاق الزمني: وقت البداية والنهاية (مثلاً "17:15 - 17:30")
  • التاريخ: تاريخ الموعد بتنسيق DD/MM/YYYY
  • شارة الحالة: يظهر حالة الموعد (مثلاً "Booked")
  • نوع الزيارة: يظهر نوع الزيارة (مثلاً "New"، "FollowUp")
  • أزرار الإجراءات: تحديد كمكتمل، عرض الموعد، عرض المريض

الترقيم

أزرار التحكم في الترقيم تتضمن:

  • السابق/التالي: أسهم التنقل للانتقال بين الصفحات
  • أرقام الصفحات: أرقام صفحات قابلة للنقر مع تمييز الصفحة الحالية
  • نقاط: يظهر "..." عندما تكون هناك صفحات كثيرة
  • إجمالي الصفحات: يعرض العدد الإجمالي للصفحات المتاحة

كيف يعمل

مكون المواعيد الفائتة يجلب المواعيد من الأيام السابقة التي لم يتم إكمالها.

دوال JavaScript

دوال رئيسية في dashboard.js:

  • loadMissedAppointments(page, limit): يجلب المواعيد من API
  • renderMissedAppointments(appointments): يعرض قائمة المواعيد
  • renderMissedPagination(pagination): يعرض أزرار التحكم في الترقيم
  • loadMissedAppointmentsPage(page): يحمل صفحة محددة
  • markMissedAppointmentCompleted(id): يعرض نافذة تأكيد الإكمال
  • confirmMissedAppointmentCompleted(id): يحدث حالة الموعد

API الخلفي

طريقة ApiController::getMissedAppointments():

  • الترقيم: يدعم معاملات page و per_page
  • فلتر التاريخ: WHERE date < CURDATE()
  • فلتر الحالة: status != 'Completed' AND status != 'Cancelled'
  • الترتيب: مرتب حسب date DESC، start_time DESC
  • الربط: JOIN مع جدول patients لمعلومات المريض
  • الاستجابة: يُرجع JSON مع مصفوفة items ومعلومات الترقيم

استعلام قاعدة البيانات

بنية الاستعلام:

  • الجدول: appointments مربوط مع patients
  • شرط التاريخ: a.date < CURDATE() (الأيام السابقة فقط)
  • شرط الحالة: يستثني حالات 'Completed' و 'Cancelled'
  • الحقول: يختار حقول الموعد بالإضافة إلى first_name، last_name، phone للمريض
  • الترقيم: يستخدم LIMIT و OFFSET لجلب البيانات بكفاءة

أزرار الإجراءات

كل موعد فائت يتضمن أزرار إجراءات للإدارة السريعة.

تحديد كمكتمل

زر "تحديد كمكتمل":

  • الدالة: markMissedAppointmentCompleted(appointmentId)
  • النافذة: يعرض نافذة تأكيد قبل التحديث
  • استدعاء API: PUT /api/appointments/{id} مع status: 'Completed'
  • التحديث: يحدث حالة الموعد في قاعدة البيانات
  • التحديث: يعيد تحميل قائمة المواعيد الفائتة بعد التحديث

عرض الموعد

زر "الموعد":

  • الرابط: /doctor/appointments/{id}
  • الغرض: ينتقل إلى صفحة تفاصيل الموعد الكاملة
  • الأيقونة: أيقونة تقويم للوضوح البصري

عرض المريض

زر "عرض المريض":

  • الرابط: /doctor/patients/{patient_id}
  • الغرض: ينتقل إلى صفحة ملف تعريف المريض
  • الأيقونة: أيقونة شخص للوضوح البصري

الميزات الرئيسية

مكون المواعيد الفائتة يتضمن عدة ميزات لإدارة فعالة للمواعيد.

الترقيم

يدعم الترقيم مع عناصر قابلة للتكوين لكل صفحة (5، 10، 20، 50)، مما يسهل التنقل عبر قوائم كبيرة بكفاءة.

اكتشاف تلقائي

يحدد تلقائياً المواعيد الفائتة بناءً على التاريخ (الأيام السابقة) والحالة (غير Completed أو Cancelled).

تحديث الحالة

يسمح بتحديد المواعيد الفائتة كمكتملة مع نافذة تأكيد لمنع التحديثات العرضية.

تنقل سريع

يوفر روابط سريعة إلى تفاصيل الموعد وملفات تعريف المرضى لإدارة سير عمل فعالة.
