نظرة عامة على أخبار طب العيون

مكون أخبار طب العيون يوفر وصولاً مباشراً لأحدث الأبحاث، التحديثات السريرية، والأخبار من المجلات الرائدة في طب العيون ومصادر الأخبار الطبية. يجمع تلقائياً المحتوى من عدة مصادر RSS ويعرض الأخبار العاجلة بشكل بارز.

انقر لعرض الحجم الكامل

عرض توضيحي مرئي لواجهة أخبار طب العيون

تجمع مصادر RSS

يجلب تلقائياً ويجمع الأخبار من عدة مصادر موثوقة لطب العيون بما في ذلك BJO، Nature Eye، MedPage Today، والمزيد.

اكتشاف الأخبار العاجلة

يتعرف بذكاء على الأخبار العاجلة باستخدام اكتشاف الكلمات المفتاحية (breaking، urgent، alert، critical، emergency) ويعرضها بشكل بارز.

نظام التحديث التلقائي

المحتوى يتحدث تلقائياً كل 20 دقيقة باستخدام نظام تخزين مؤقت لضمان أخبار جديدة مع تقليل عبء الخادم.

كيف يعمل

نظام أخبار طب العيون يعمل من خلال API Controller، الذي يتعامل مع جلب مصادر RSS، معالجة المحتوى، والتخزين المؤقت.

نقطة نهاية API:

نظام الأخبار يتم الوصول إليه من خلال نقطة النهاية /api/ophthalmology-news في ApiController.php، تحديداً طريقة getOphthalmologyNews().

جلب مصادر RSS

النظام يجلب مصادر RSS من عدة مصادر:

  • مصادر البحث: BJO (المجلة البريطانية لطب العيون)، Nature Eye
  • مصادر سريرية: MedPage Today، Retina Specialist، Retina Today
  • مصادر الأخبار: Medical News Today، Healio

كل مصدر يتم جلبه باستخدام cURL مع معالجة مناسبة للوقت المحدد وإدارة الأخطاء.

معالجة المحتوى

النظام يعالج عدة تنسيقات RSS:

  • RSS 2.0: تنسيق RSS القياسي مع عناصر channel و item
  • RSS 1.0 (RDF): تنسيق RSS قائم على RDF مع namespaces
  • Atom: تنسيق Atom feed مع عناصر entry

تحليل XML يتعامل تلقائياً مع namespaces وتنسيقات مختلفة، استخراج العنوان، الرابط، الوصف، وتاريخ النشر.

فلترة المحتوى

المقالات يتم فلترتها وترتيبها:

  • فلتر الوقت: فقط المقالات من آخر 3 أشهر (90 يوم) يتم تضمينها
  • الأخبار العاجلة: المقالات مع كلمات مفتاحية عاجلة تحصل على أولوية
  • فلتر الفئة: فلترة اختيارية حسب الفئة (بحث، سريري، أخبار، أو الكل)
  • الترتيب: الأخبار العاجلة أولاً، ثم حسب التاريخ (الأحدث أولاً)
  • الحد: حد أقصى 15 مقالة معروضة

حفظ وتحديث المحتوى

النظام يستخدم آلية تخزين مؤقت قائمة على الملفات لتخزين وتحديث محتوى الأخبار بكفاءة.

تخزين ملف التخزين المؤقت

مقالات الأخبار يتم تخزينها مؤقتاً في ملف JSON:

  • الموقع: storage/ophthalmology_news_cache.json
  • التنسيق: JSON مع timestamp ومصفوفة articles
  • البنية: 
    {
  "timestamp": 1234567890,
  "articles": [
    {
      "title": "عنوان المقال",
      "link": "https://...",
      "description": "...",
      "pubDate": "...",
      "source": "BJO",
      "source_icon": "📄",
      "category": "research",
      "is_breaking": false
    }
  ]
}

مدة التخزين المؤقت

نظام التخزين المؤقت يعمل كالتالي:

  • مدة التخزين المؤقت: 20 دقيقة (1200 ثانية)
  • فحص التخزين المؤقت: في كل طلب API، النظام يفحص إذا كان التخزين المؤقت موجوداً ولا يزال صالحاً
  • ضربة التخزين المؤقت: إذا كان التخزين المؤقت صالحاً، المقالات تُعاد فوراً دون جلب مصادر RSS
  • فشل التخزين المؤقت: إذا كان التخزين المؤقت منتهي الصلاحية أو مفقوداً، مصادر RSS يتم جلبها والتخزين المؤقت يتم تحديثه

تحديثات تلقائية

عملية التحديث:

  • المشغل: طلب API عندما يكون التخزين المؤقت منتهي الصلاحية أو مفقوداً
  • العملية: جلب جميع مصادر RSS → تحليل XML → فلترة المقالات → ترتيب حسب عاجل/تاريخ الأخبار → حد إلى 15
  • الحفظ: مصفوفة المقالات المحدثة مع timestamp الحالي يتم حفظها في ملف التخزين المؤقت
  • الاحتياطي: إذا فشل الجلب، التخزين المؤقت القديم يُستخدم حتى لو كان منتهي الصلاحية لضمان توفر المحتوى
إدارة التخزين المؤقت:

ملف التخزين المؤقت يتم إنشاؤه وتحديثه تلقائياً بواسطة API controller. لا حاجة لتدخل يدوي. النظام يضمن أن محتوى الأخبار متاح دائماً، حتى لو كانت مصادر RSS غير متاحة مؤقتاً، باستخدام البيانات المخزنة مؤقتاً كاحتياطي.

الميزات الرئيسية

مكون أخبار طب العيون يتضمن عدة ميزات مصممة لإبقاء الأطباء على اطلاع.

مؤشر الأخبار العاجلة

مقالات الأخبار العاجلة يتم اكتشافها تلقائياً وعرضها مع شارة "BREAKING" بارزة، مما يضمن أن التحديثات العاجلة مرئية فوراً.

شريط تمرير أفقي

مقالات الأخبار معروضة في تنسيق شريط تمرير أفقي، مما يسمح بعرض عدة عناوين في نفس الوقت مع الحفاظ على تصميم مضغوط.

مقالات قابلة للنقر

كل عنصر أخبار قابل للنقر ويفتح المقال الكامل في تبويب جديد، مما يسمح للأطباء بقراءة المقالات الكاملة من المصدر الأصلي.

دعم الثيم

شريط الأخبار يتكيف تلقائياً مع الثيمات الفاتحة والداكنة، مما يضمن قابلية قراءة مثلى في جميع ظروف العرض.
