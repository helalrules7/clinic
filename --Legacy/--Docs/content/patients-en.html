Statistics Cards

Four statistics cards provide quick overview of patient data at the top of the page.

Total Patients

Label: "TOTAL PATIENTS"

Value: Total count of all patients in the system

Description: "All Time" - indicates this is a cumulative count

Icon: Two people icon (users)

Data Source: Count from patients table

Total Visits

Label: "TOTAL VISITS"

Value: Total count of all appointments

Description: "All Appointments" - cumulative appointment count

Icon: Calendar with checkmark icon

Data Source: Count from appointments table

Recent Visits

Label: "RECENT VISITS"

Value: Count of appointments in the last 7 days

Description: "Last 7 Days" - time range indicator

Icon: Calendar icon

Data Source: Filtered count from appointments table where date >= DATE_SUB(NOW(), INTERVAL 7 DAY)

New This Month

Label: "NEW THIS MONTH"

Value: Count of patients created in the last 30 days

Description: "Last 30 Days" - time range indicator

Icon: User with plus icon

Data Source: Filtered count from patients table where created_at >= DATE_SUB(NOW(), INTERVAL 30 DAY)

Filtering System

The Patients page includes multiple filtering options to help you find specific patient records quickly.

Filter by Doctor

Location: Above the patients table

Options: "All Doctors" button plus individual doctor buttons

Function: Filters patients by the doctor who created their record

Implementation: filterByDoctor(doctorId) in patients.js

Data Source: created_by_doctor_id field in patient records

Visual: Active filter highlighted, shows "Showing patients for: [Doctor Name]" below

Filter by Gender

Location: Gender column header with filter icon

Options: Male, Female, or Clear filter

Function: Filters patients by gender (Male/Female)

Implementation: applyGenderFilter(gender) in patients.js

Modal: Opens popup with radio buttons for gender selection

Visual: Filter icon becomes active when filter is applied

Filter by Age Range

Location: Age column header with filter icon

Options: Min Age and Max Age input fields

Function: Filters patients within specified age range

Implementation: applyAgeFilter(min, max) in patients.js

Calculation: Age calculated from dob (date of birth) field

Modal: Opens popup with number inputs for min/max age

Filter by Last Visit

Location: Last Visit column header with filter icon

Options: From Date and To Date pickers

Function: Filters patients by their last appointment date

Implementation: applyLastVisitFilter(from, to) in patients.js

Data Source: last_visit field (MAX appointment date per patient)

Modal: Opens popup with date range picker

Clear All Filters

Location: Filter area, "Clear Filters" button

Function: Removes all active filters and resets to show all patients

Implementation: clearAllFilters() in patients.js

Behavior: Resets all filter states and re-renders table with all patients

Visual demonstration of smart filters (Gender, Age, Last Visit)

Patients Table

The main table displays patient records with pagination, sorting, and action buttons.

Quick Search

Location: Top-left of table

Function: Real-time search as you type (debounced)

Search Fields: Patient name, phone number, alternative phone, national ID

Minimum Characters: 2 characters required

Implementation: filterPatientsLocally(query) in patients.js

Debounce: 300ms delay to prevent excessive filtering

Items Per Page

Location: Top-right of table, "View:" dropdown

Options: 10, 20, 30, 50, All

Default: 20 items per page

Function: Controls how many patients are displayed per page

Implementation: changeItemsPerPage(count) in patients.js

State: Stored in paginationState.itemsPerPage

Table Columns

Columns:

  • Patient Name: Avatar with initials, full name, patient ID
  • Phone: Primary and alternative phone with call/WhatsApp actions
  • Gender: Badge with gender icon (Male/Female)
  • Age: Calculated from date of birth
  • Doctor: Name of doctor who created the patient record
  • Last Visit: Date of most recent appointment
  • Total Visits: Count of all appointments
  • Actions: View, Edit, Book Appointment, Delete buttons

Sorting

Location: Column headers with sort icons

Function: Click column header to sort ascending/descending

Sortable Columns: Name, Phone, Age, Last Visit, Total Visits

Implementation: sortPatients(sortBy, sortOrder) in patients.js

State: Stored in paginationState.sortBy and paginationState.sortOrder

Pagination

Location: Bottom of table

Display: "Showing X to Y of Z patients"

Navigation: Previous/Next buttons and page numbers

Implementation: renderPaginationNav() and goToPage(page) in patients.js

State: paginationState.currentPage tracks current page

Technical Implementation

Key files, functions, and database structures that power the Patients page.

Key Files

  • View: app/Views/doctor/patient.php - Patient profile page
  • View: app/Views/doctor/patients.php - Patients list page
  • JavaScript: app/Views/doctor/assets/js/patients.js - Client-side logic
  • Controller: app/Controllers/DoctorController.php - Backend logic
  • API Controller: app/Controllers/ApiController.php - API endpoints

Key JavaScript Functions

  • initializePagination() - Initializes pagination with PHP data
  • renderPatientsTable() - Renders patient table with current page data
  • filterByDoctor(doctorId) - Filters patients by doctor
  • applyGenderFilter(gender) - Filters patients by gender
  • applyAgeFilter(min, max) - Filters patients by age range
  • applyLastVisitFilter(from, to) - Filters patients by last visit date
  • filterPatientsLocally(query) - Local search filtering
  • searchPatients(query) - API-based patient search
  • openAddPatientModal() - Opens add patient modal
  • editPatient(patientId) - Opens edit patient modal
  • deletePatient(patientId, name) - Deletes patient with confirmation
  • bookAppointment(patientId) - Redirects to calendar with patient
  • viewPatient(patientId) - Opens patient profile page

API Endpoints

  • GET /doctor/patients - Shows patients list page
  • GET /doctor/patients/{id} - Shows patient profile page
  • GET /api/doctor/patients - Gets all patients (JSON)
  • GET /api/doctor/patients/{id} - Gets single patient (JSON)
  • POST /api/doctor/patients - Creates new patient
  • PUT /api/doctor/patients/{id} - Updates patient
  • DELETE /api/doctor/patients/{id} - Deletes patient
  • GET /api/doctor/search-patients?q={query} - Searches patients

Database Tables

  • patients: Main patient records (id, first_name, last_name, phone, dob, gender, address, national_id, created_at, etc.)
  • appointments: Patient appointments (used for visit counts and last visit date)
  • timeline_events: Patient activity timeline (used to determine created_by_doctor_id)
  • users: Doctor information (joined for doctor names)
  • doctors: Doctor-specific data (joined for display names)

Controller Methods

  • DoctorController::patients() - Renders patients list page
  • DoctorController::showPatient($id) - Renders patient profile page
  • DoctorController::getAllPatients() - Fetches all patients with statistics
  • DoctorController::getPatient($id) - Fetches single patient
  • DoctorController::updatePatient($id) - Updates patient record
  • DoctorController::deletePatient($id) - Deletes patient record
  • ApiController::searchPatients() - Searches patients via API

Pagination State

State Object: paginationState in patients.js

Properties:

  • currentPage - Current page number
  • itemsPerPage - Items per page (10, 20, 30, 50, 'all')
  • totalItems - Total number of filtered patients
  • allPatients - All patients from PHP
  • filteredPatients - Currently filtered/displayed patients
  • currentDoctorFilter - Active doctor filter ('all' or doctor ID)
  • currentGenderFilter - Active gender filter (null, 'Male', 'Female')
  • currentAgeFilter - Age range filter ({min, max})
  • currentLastVisitFilter - Last visit date range ({from, to})
  • sortBy - Current sort column
  • sortOrder - Current sort order ('asc' or 'desc')
