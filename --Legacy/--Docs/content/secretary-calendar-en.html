Secretary Calendar Overview

The Secretary Calendar is a comprehensive booking management system designed for secretaries to create, manage, and track patient appointments across all doctors. It provides real-time statistics, day-by-day calendar views, and integrated patient management with payment tracking.

Click to view full size

Visual demonstration of the Secretary Calendar interface

Real-Time Statistics

Four statistics cards display total bookings, pending, checked-in, and completed appointments, updating automatically with calendar data.

Multi-Doctor Support

Secretaries can book appointments for any doctor in the system, with doctor selection in the booking modal.

Payment Integration

Booking modal includes payment fields (amount paid, visit cost) with automatic calculation of remaining balance.

Header Section

The header includes page title, auto-refresh toggle, navigation controls, and keyboard shortcuts.

Page Title

Text: "إدارة الحجوزات" (Booking Management) with calendar icon

Description: "إنشاء وإدارة مواعيد المرضى" (Create and manage patient appointments)

Auto-Refresh Toggle

Function: Enables/disables automatic calendar updates every 60 seconds

Location: Next to page title

JavaScript: toggleBookingsAutoRefresh(checked)

Keyboard Shortcuts

Displayed: Below page description

Shortcuts:

  • N / Ctrl+N: New booking
  • F: Search
  • Esc: Close

New Booking Button

Location: Top-right, green button

Text: "حجز جديد" (New Booking) with calendar-plus icon

Shortcut: N or Ctrl+N

Function: Opens "Add Booking" modal

Navigation Buttons

Today Button: Returns to today's date

Previous Day: Navigates to previous day (right arrow for RTL)

Next Day: Navigates to next day (left arrow for RTL)

Statistics Cards

Four statistics cards provide quick overview of booking status for the current day.

Total Bookings (Primary Blue)

Label: "إجمالي الحجوزات" (Total Bookings)

Value: Total count of all appointments for the day

Update: Calculated from appointments.length

JavaScript: updateStatistics(appointments)

Pending (Success Green)

Label: "في الإنتظار" (Pending)

Value: Count of appointments with status "Booked"

Filter: appointments.filter(apt => apt.status === 'Booked')

Checked In (Info Purple)

Label: "تم الحضور" (Checked In)

Value: Count of appointments with status "CheckedIn"

Filter: appointments.filter(apt => apt.status === 'CheckedIn')

Completed (Warning Orange)

Label: "مكتملة" (Completed)

Value: Count of appointments with status "Completed"

Filter: appointments.filter(apt => apt.status === 'Completed')

Calendar Structure

The calendar displays appointments in a two-column layout similar to Doctor's Calendar, with additional booking management features.

Click to view full size

Visual demonstration of the calendar structure

Time Column

Structure: Vertical list of 15-minute time intervals

Format: 12-hour format (e.g., "02:00 PM", "02:15 PM")

Range: Working hours (typically 2:00 PM to 10:45 PM)

Bookings Column

Booked Appointments: Display cards with:

  • Patient name
  • Visit type (زيارة جديدة, إعادة كشف, استشارة)
  • Appointment time
  • Doctor name
  • Payment information (paid amount, remaining balance)
  • Status badge (محجوز, تم الحضور, etc.)
  • Action buttons (Confirm attendance, Edit, Delete)

Available Slots: Green dashed boxes with "+ متاح - [Time]" clickable to add booking

Live Status Indicator

Location: Top-right of calendar card

Components:

  • "مباشر" Badge: Green badge indicating real-time updates
  • Last Updated: Timestamp (e.g., "آخر تحديث: 02:36:19 م")

Add Booking Modal

The booking creation modal includes patient selection, doctor selection, payment fields, and appointment details.

Click to view full size

Visual demonstration of the Add Booking modal

Patient Selection

Search Field: "البحث عن المريض بالاسم أو رقم الهاتف..." (Search patient by name or phone)

Autocomplete: Real-time search with 300ms debounce

Add Patient Button: Person-plus icon button to add new patient

Auto-Selection: Newly added patient is automatically selected in booking form

Doctor Selection

Field: "الطبيب المعالج *" (Treating Doctor *)

Dropdown: Lists all doctors with name and specialization

Format: "د. [First Name] [Last Name] - [Specialization]"

Required: Must select a doctor to create booking

Visit Type

Options:

  • زيارة جديدة (New Visit): Default cost from settings
  • إعادة كشف (Follow Up): Repeated visit cost
  • استشارة / إجراء طبي (Consultation/Procedure): Consultation cost

Auto-Update: Changing visit type updates visit cost field

JavaScript: updateVisitCost() function

Payment Section

Payment Method: Dropdown (نقداً - Cash, هاتف - Phone)

Amount Paid: Number input for payment amount

Visit Cost: Auto-filled from visit type, editable

Remaining Balance: Calculated automatically (Visit Cost - Amount Paid)

Validation: Amount paid cannot exceed visit cost

Date and Time

Date Field: Pre-filled with current calendar date

Validation: Cannot select dates before today (Egypt timezone)

Time Dropdown: Loads available time slots for selected date and doctor

API: /api/calendar?doctor_id={id}&date={date}

Save Booking

Button: "حفظ الحجز" (Save Booking) - green button with checkmark

Validation: All required fields must be filled

API Call: POST to /api/appointments

Success: Modal closes, calendar refreshes, statistics update

Key Features

The Secretary Calendar includes several features for efficient booking management.

Add New Patient

Secretaries can add new patients directly from the booking modal. After adding, the patient is automatically selected in the booking form, streamlining the booking process.

Confirm Attendance

Action button on booked appointments allows secretaries to mark patients as "Checked In" when they arrive, updating the appointment status and statistics.

Edit Booking

Edit button opens modal to modify appointment details, including patient, doctor, time, visit type, and payment information.

Delete Booking

Delete button removes appointment permanently with confirmation modal showing appointment details and consequences.

Auto-Refresh

Calendar automatically refreshes every 60 seconds when enabled, keeping statistics and appointments up-to-date without manual refresh.

Theme Support

Full support for light and dark themes with automatic adaptation of all UI elements, statistics cards, and calendar components.
