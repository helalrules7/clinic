Recent Activities Overview

The Recent Activities component displays a chronological list of system activities and user actions tracked in the audit log. It provides administrators with visibility into system usage, user actions, and important events.

Visual demonstration of the Recent Activities interface

Chronological List

Activities are displayed in reverse chronological order (newest first), making it easy to see the most recent system events.

User Attribution

Each activity shows the user who performed the action, providing accountability and traceability.

Activity Details

Each entry includes user name, action description, and timestamp for complete activity context.

Component Structure

The Recent Activities component consists of a header and a scrollable list of activity items.

Header Section

The header includes:

  • Title: "Recent Activities" with history icon
  • Styling: Card header with border-bottom separator

Activity List

Each activity item contains:

  • Activity Icon: Circular icon with gradient background (blue-green gradient)
  • Icon Type: Changes based on action_type (sign-in for login, edit for other actions)
  • User Name: Name of the user who performed the action
  • Description: Description of the activity/action
  • Timestamp: Date and time when the activity occurred (YYYY-MM-DD HH:MM format)

Empty State

When no activities are available:

  • Icon: Inbox icon (large, 3rem)
  • Message: "No recent activities"
  • Styling: Centered, muted text

How It Works

The Recent Activities component fetches audit log entries from the database and displays them in a scrollable list.

Backend Processing

AdminController::getRecentActivities() method:

  • Query: SELECT from audit_logs table
  • Join: JOIN with users table to get user names
  • Ordering: ORDER BY created_at DESC (newest first)
  • Limit: LIMIT 20 (shows last 20 activities)
  • Returns: Array of activity records with user_name included

Frontend Rendering

The dashboard template renders activities:

  • List Container: Uses activity-list class with max-height and scroll
  • Activity Items: Each item uses activity-item class
  • Icon Display: Dynamic icon based on action_type field
  • Date Formatting: Uses date('Y-m-d H:i', strtotime()) for readable timestamps
  • HTML Escaping: Uses htmlspecialchars() for security

Database Structure

The audit_logs table stores:

  • user_id: ID of user who performed the action
  • action_type: Type of action (e.g., 'login', 'edit', 'create', 'delete')
  • description: Human-readable description of the action
  • created_at: Timestamp when the activity occurred

Activity Types

Different types of activities are tracked and displayed with appropriate icons.

Login Activities

When action_type = 'login':

  • Icon: Sign-in icon (fas fa-sign-in)
  • Description: User login events
  • Purpose: Track user access and authentication

Edit Activities

For other action types (edit, create, delete, etc.):

  • Icon: Edit icon (fas fa-edit)
  • Description: Various system actions and modifications
  • Purpose: Track data changes and system operations

Key Features

The Recent Activities component includes several features for effective activity monitoring.

Scrollable List

The activity list has a maximum height (400px) with vertical scrolling, allowing you to view many activities without taking up excessive screen space.

Hover Effects

Activity items have hover effects that highlight the item with a background color change, making it easier to read individual entries.

Theme Support

The component automatically adapts to light and dark themes, ensuring optimal readability in all viewing conditions.

Limited Display

Shows the last 20 activities to keep the list manageable while providing recent activity overview.
