Upcoming Appointments Overview

The Upcoming Appointments component displays a list of scheduled appointments that are booked or checked in, providing doctors with a clear view of their upcoming schedule. Each appointment shows patient information, time details, status, and includes a real-time progress bar indicating the time remaining until the appointment.

Component Structure

The Upcoming Appointments component consists of several key elements that work together to provide a comprehensive appointment management interface.

Header Section

The header includes:

  • Title: "Upcoming Appointments" with calendar icon
  • View All Button: Links to the full calendar page (/doctor/calendar)

Appointment Card

Each appointment is displayed as a card containing:

  • Patient Name: Clickable link to patient profile
  • Time Range: Start and end time (e.g., "14:00 - 14:15")
  • Date: Appointment date in DD/MM/YYYY format
  • Status Badge: Visual indicator (Booked, CheckedIn)
  • Visit Type: Type of visit (New, FollowUp, Procedure)
  • Progress Bar: Real-time countdown to appointment

Action Buttons

Two action buttons for each appointment:

  • Appointment Button: Opens appointment details page (/doctor/appointments/{id})
  • Patient Button: Opens patient profile page (/doctor/patients/{patient_id})

Progress Bar

The progress bar component features:

  • Glass Effect: Modern glassmorphism design with blur effect
  • Real-Time Updates: Updates every second to show remaining time
  • Visual Fill: Progress fill indicates time elapsed/remaining
  • Time Display: Shows remaining time in HH:MM format
  • Conditional Display: Only shown for non-completed, non-rescheduled appointments

Pagination

Pagination controls for navigating through multiple appointments:

  • Page Navigation: Previous/Next buttons and page numbers
  • Default Limit: 4 appointments per page
  • Auto-Hide: Hidden when there's only one page

How It Works

The Upcoming Appointments component is powered by the API Controller and uses JavaScript for dynamic rendering and real-time updates.

API Endpoint:

The component uses /api/upcoming-appointments endpoint in ApiController.php, specifically the getUpcomingAppointments() method.

Data Fetching

The API endpoint:

  • Authentication: Requires user authentication
  • Doctor ID: Automatically retrieves doctor ID from authenticated user
  • Date Filter: Only fetches appointments from today onwards (date >= today)
  • Status Filter: Only includes appointments with status "Booked" or "CheckedIn"
  • Sorting: Orders by date (ASC) then start time (ASC)
  • Pagination: Supports page and per_page parameters

Rendering Process

JavaScript handles the rendering:

  • Initial Load: loadUpcomingAppointments() fetches data on page load
  • Data Processing: Formats dates and times for display
  • HTML Generation: renderUpcomingAppointments() creates appointment cards
  • Tooltip Initialization: Bootstrap tooltips for interactive elements
  • Progress Bar Initialization: Sets up real-time progress bars

Real-Time Updates

The progress bar system:

  • Initialization: initializeAppointmentProgressBars() finds all progress containers
  • Update Function: updateAppointmentProgressBar() calculates remaining time
  • Interval: Updates every second (1000ms) using setInterval
  • Time Calculation: Calculates time between now and appointment start time
  • Progress Fill: Updates width percentage based on elapsed time
  • Text Display: Shows remaining time in "HH:MM" format

Progress Bar System

The progress bar is a sophisticated component that provides real-time visual feedback about upcoming appointments.

Time Calculation

The system calculates time remaining:

  • Current Time: Gets current date and time
  • Appointment Start: Combines appointment date and start time
  • Time Difference: Calculates milliseconds between now and appointment start
  • Duration: Assumes 15-minute appointment duration (900 seconds)
  • Progress Percentage: Calculates how much time has elapsed

Visual Design

The progress bar uses glassmorphism:

  • Glass Effect: Semi-transparent background with blur
  • Gradient Fill: Animated gradient that fills as time progresses
  • Text Overlay: Time remaining displayed over the progress bar
  • Responsive: Adapts to container width

Display Logic

The progress bar is conditionally displayed:

  • Shown For: Appointments with status "Booked" or "CheckedIn"
  • Hidden For: Completed or Rescheduled appointments
  • Auto-Hide: Hides when appointment time has passed
Progress Bar States:

The progress bar shows different states based on time:

  • Before Appointment: Shows time remaining until start
  • During Appointment: Shows time remaining until end
  • After Appointment: Automatically hides or shows completion
