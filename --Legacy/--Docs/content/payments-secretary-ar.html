إدارة المدفوعات والرصيد اليومي - واجهة السكرتير

واجهة إدارة مالية كاملة للسكرتارية لتتبع المدفوعات، إدارة الأرصدة اليومية، تسجيل المصروفات، والبحث في المعاملات مع خيارات تصفية قوية وإمكانيات التصدير.

المدفوعات الرصيد المصروفات

نظرة عامة على لوحة القيادة

توفر لوحة إدارة المدفوعات والرصيد اليومي للسكرتارية رؤية شاملة للأنشطة المالية اليومية للعيادة. تتضمن بطاقات الملخص، تفصيل أنواع المدفوعات، سجلات المعاملات، وسجلات المدفوعات التفصيلية.

الرصيد الافتتاحي

المبلغ النقدي المتوفر عند بداية اليوم. يتم تعيينه مرة واحدة يومياً عند فتح العيادة.

إجمالي المستلم

مجموع كل المدفوعات الواردة من حجوزات المرضى، المتابعات، الاستشارات، والإجراءات.

إجمالي المصروفات

إجمالي المبالغ المدفوعة لمصروفات العيادة بما في ذلك المرافق، المستلزمات الطبية، الرواتب، والصيانة.

الرصيد الحالي

النقد الفعلي المتوفر حاليًا محسوبًا كالتالي: الرصيد الافتتاحي + إجمالي المستلم - إجمالي المصروفات.

ملخص أنواع المدفوعات

تفصيل حسب نوع الدفع: حجز جديد، إعادة كشف، استشارة طبية، إجراء طبي مع الإجمالي بالجنيه المصري.

سجل المعاملات المالية

سجل زمني كامل لجميع المعاملات المالية (المدفوعات، المصروفات، تعديلات الرصيد) مع الترقيم والتصفية.

سجلات المدفوعات

جدول تفصيلي لجميع مدفوعات المرضى مع البحث والتصفية حسب النوع وطريقة الدفع والإجراءات السريعة.

إدارة الرصيد اليومي

يسمح نظام إدارة الرصيد للسكرتارية بتسجيل النقد الافتتاحي، إضافة أموال إضافية، وتسجيل المسحوبات طوال اليوم.

تسجيل الرصيد

استخدم زر "تسجيل رصيد" لإدخال النقد الافتتاحي أو إضافة أموال خلال اليوم. يدعم النظام ثلاثة أنواع من إدخالات الرصيد:

1
رصيد افتتاحي
تحديد المبلغ النقدي في بداية اليوم. يتم ذلك عادة مرة واحدة يومياً عند فتح العيادة.
2
إضافة رصيد
إضافة أموال للطوارئ أو زيادة النثرية خلال اليوم. مفيد لتجديد النقد عند الحاجة.
3
سحب من الرصيد
تسجيل النقد الذي تم سحبه للإيداع البنكي أو أغراض أخرى. هذا يقلل الرصيد الحالي.
اختصارات لوحة المفاتيح: اضغط على R أو ر في لوحة المفاتيح لفتح نافذة تسجيل الرصيد بسرعة من أي مكان في الصفحة.

تسجيل المصروفات

تتبع كل قرش يتم صرفه مع تصنيف المصروفات. يدعم النظام أنواع المصروفات السريعة والتصنيف التفصيلي لتقارير أفضل.

فاتورة مياه
فاتورة كهرباء
مستلزمات طبية

فئات المصروفات: تجميع المصروفات في فئات منطقية لتقارير أفضل:

  • مرافق عامة: المياه، الكهرباء، الإنترنت، فواتير الهاتف
  • طبية: المستلزمات الطبية، المعدات، الأدوية
  • صيانة: الإصلاحات، الصيانة، التنظيف
  • مكتبية: مستلزمات المكتب، القرطاسية، الطباعة
  • رواتب: رواتب وأجور الموظفين
  • أخرى: مصروفات متنوعة

وظيفة البحث

قدرات بحث قوية تسمح لك بالعثور بسرعة على المدفوعات حسب اسم المريض أو رقم الهاتف أو رقم الدفعة مع نتائج فورية أثناء الكتابة.

البحث الشامل في المدفوعات

قدرات البحث:

  • حسب اسم المريض: البحث باستخدام الاسم الكامل أو الجزئي
  • حسب رقم الهاتف: البحث باستخدام رقم الهاتف الكامل أو الجزئي
  • حسب رقم الدفعة: البحث باستخدام رقم الدفعة المحدد

الميزات:

  • بحث فوري: تظهر النتائج تلقائياً أثناء الكتابة (وظيفة type-ahead)
  • زر المسح: زر مسح سريع (X) لإعادة تعيين البحث
  • اختصار التركيز: اضغط Ctrl+F للتركيز على حقل البحث
  • حالة فارغة: إرشادات مفيدة عندما لا يتم إدخال مصطلح بحث
  • حالة لا توجد نتائج: رسالة واضحة عندما لا يتم العثور على تطابقات
اختصار لوحة المفاتيح: اضغط على F أو ب لفتح نافذة البحث بسرعة. اضغط Esc لإغلاق أي نافذة.

سجل المعاملات المالية

يتم تسجيل كل إجراء مالي تلقائيًا. راجع وصفي وصدّر سجل معاملاتك الكامل مع خيارات تصفية قوية.

تصفية المعاملات

فلتر التاريخ

تصفية المعاملات حسب تواريخ محددة. عرض معاملات اليوم أو البحث في البيانات التاريخية باختيار تاريخ.

نوع المعاملة

عرض المدفوعات فقط، أو المصروفات، أو تعديلات الرصيد. أو عرض جميع المعاملات معاً للحصول على نظرة عامة كاملة.

تصدير إلى Excel

تحميل تقريرك المصفى كملف Excel للمحاسبة، إعداد الضرائب، أو حفظ السجلات.

عرض المعاملة:

  • التاريخ والوقت: وقت حدوث المعاملة
  • النوع: دفع، مصروف، أو رصيد مع شارات ملونة
  • الوصف: وصف تفصيلي للمعاملة
  • المبلغ: مبلغ المعاملة مع بادئة + (دخل) أو - (مصروف)
  • الرصيد الجاري: الرصيد بعد هذه المعاملة
  • الإجراءات: زر عرض التفاصيل (أيقونة العين) للمصروفات

الترقيم: يتم ترقيم المعاملات مع 10 عناصر لكل صفحة. عناصر التحكم في التنقل تعرض الصفحة الحالية، إجمالي الصفحات، وأعداد السجلات.

سجلات المدفوعات

عرض وإدارة جميع مدفوعات المرضى مع معلومات تفصيلية وخيارات تصفية متعددة وإجراءات سريعة لعرض وطباعة الإيصالات.

ميزات جدول المدفوعات

يعرض جدول المدفوعات جميع المدفوعات المستلمة اليوم مع المعلومات التالية:

  • التاريخ والوقت: وقت استلام الدفع
  • المريض: اسم المريض ورقم الهاتف مع أيقونة الصورة الرمزية
  • المبلغ: مبلغ الدفع بالجنيه المصري (معروض باللون الأخضر)
  • النوع: شارة نوع الدفع (حجز جديد، إعادة كشف، استشارة طبية، إجراء طبي)
  • طريقة الدفع: شارة الطريقة (نقدي، بطاقة، تحويل، محفظة)
  • الوصف: ملاحظات أو وصف إضافي
  • الإجراءات: أزرار عرض التفاصيل وطباعة الإيصال

خيارات التصفية:

  • البحث السريع: صندوق بحث لتصفية حسب اسم المريض أو الهاتف أو رقم الدفعة في الوقت الفعلي
  • فلتر النوع: التصفية حسب نوع الدفع (الكل، حجز جديد، إعادة كشف، استشارة طبية، إجراء طبي)
  • فلتر طريقة الدفع: التصفية حسب طريقة الدفع (الكل، نقدي، بطاقة، تحويل)

إجراءات الدفع:

عرض التفاصيل
يفتح صفحة تفاصيل الدفع مع معلومات كاملة وبيانات المريض والمدفوعات ذات الصلة
طباعة الإيصال
ينشئ ويفتح إيصال الدفع القابل للطباعة في نافذة جديدة

تفاصيل الدفعة

عرض معلومات الدفع الشاملة بما في ذلك تفاصيل الدفع، معلومات المريض، الموعد المرتبط (إن وجد)، والمدفوعات ذات الصلة لنفس المريض.

بطاقة معلومات الدفعة

تفاصيل الدفعة:

  • رقم الدفعة: معرف فريد للدفع
  • المبلغ: مبلغ الدفع بالجنيه المصري (معروض باللون الأخضر، عريض)
  • نوع الدفعة: شارة تعرض النوع (حجز جديد، متابعة، استشارة، إجراء، أخرى)
  • طريقة الدفع: شارة تعرض الطريقة (نقدي، بطاقة، تحويل، محفظة)
  • تاريخ الدفعة: التاريخ والوقت عند استلام الدفع
  • استلمها: اسم المستخدم الذي استلم الدفع
  • الوصف: ملاحظات أو وصف إضافي (إن تم توفيره)
  • مبلغ الخصم: أي خصم مطبق (إن كان قابلاً للتطبيق، معروض بلون التحذير)
  • حالة الإعفاء: ما إذا كان الدفع معفى (إن كان قابلاً للتطبيق، معروض بلون المعلومات)

بطاقة معلومات المريض

تفاصيل المريض:

  • الاسم: الاسم الكامل للمريض
  • الهاتف: رقم الهاتف الرئيسي
  • العنوان: عنوان المريض (إن كان متوفراً)
  • الرقم القومي: رقم الهوية الوطنية (إن كان متوفراً)

إجراءات سريعة: زر "عرض ملف المريض" يربط بصفحة ملف المريض الكاملة.

الموعد المرتبط

إذا كان الدفع مرتبطاً بموعد، يتم عرض المعلومات التالية:

  • رقم الموعد: معرف فريد للموعد
  • التاريخ: تاريخ الموعد
  • الوقت: وقت البداية والنهاية
  • الطبيب: اسم الطبيب
  • نوع الزيارة: شارة تعرض نوع الزيارة
  • الحالة: شارة تعرض حالة الموعد
  • الملاحظات: ملاحظات الموعد (إن كانت متوفرة)

إجراءات سريعة: زر "عرض تفاصيل الموعد" يربط بصفحة الموعد الكاملة.

مدفوعات أخرى

يعرض مدفوعات أخرى لنفس المريض:

  • يعرض التاريخ، المبلغ، النوع، طريقة الدفع
  • كل صف له إجراءات عرض التفاصيل وطباعة الإيصال
  • يساعد في تتبع سجل مدفوعات المريض

تفاصيل المصروف

عرض معلومات المصروف الشاملة بما في ذلك تفاصيل المصروف، معلومات المنشئ، ومصروفات أخرى مسجلة في نفس اليوم.

معلومات المصروف

تفاصيل المصروف:

  • اسم المصروف: اسم المصروف (مثل "Water Bill")
  • المبلغ: مبلغ المصروف بالجنيه المصري (معروض باللون الأحمر، عريض، خط كبير)
  • الفئة: شارة فئة المصروف (مرافق عامة، طبية، صيانة، مكتبية، راتب، أخرى)
  • تاريخ الإنشاء: التاريخ والوقت عند إنشاء المصروف
  • أنشأ بواسطة: اسم المستخدم الذي أنشأ المصروف
  • الدور: شارة دور المنشئ (طبيب، سكرتارية)
  • الملاحظات: ملاحظات إضافية حول المصروف (إن تم توفيره، معروض في صندوق بخلفية فاتحة)

معلومات المنشئ

تفاصيل المنشئ:

  • الصورة الرمزية: صورة رمزية دائرية مع أيقونة المستخدم
  • الاسم: الاسم الكامل للمنشئ
  • البريد الإلكتروني: عنوان بريد المنشئ الإلكتروني
  • شارة الدور: شارة الدور (طبيب، سكرتارية)

مصروفات أخرى في نفس اليوم

جدول يعرض جميع المصروفات المسجلة في نفس اليوم:

  • الوقت: وقت إنشاء المصروف
  • اسم المصروف: اسم المصروف مع تسمية "المصروف الحالي" للمصروف المعروض
  • المبلغ: مبلغ المصروف باللون الأحمر، عريض
  • الفئة: شارة الفئة
  • المنشئ: اسم المنشئ مع أيقونة المستخدم
  • الإجراءات: زر عرض التفاصيل للمصروفات الأخرى، تسمية "الحالي" للمصروف المعروض

تمييز المصروف الحالي: يتم تمييز المصروف المعروض حالياً في الجدول مع تسمية "المصروف الحالي" و"الحالي" في عمود الإجراءات.

التنفيذ التقني

التفاصيل التقنية حول تنفيذ إدارة المدفوعات والرصيد اليومي للسكرتارية، بما في ذلك نقاط نهاية API وبنية قاعدة البيانات ووظائف JavaScript وخوارزميات سير العمل.

نقاط نهاية API

يستخدم نظام مدفوعات السكرتارية نفس نقاط نهاية API الخاصة بالإدارة المالية للطبيب:

POST /api/daily-balance

إنشاء إدخال رصيد يومي (افتتاحي، إضافي، أو سحب)

POST /api/expenses

إنشاء إدخال مصروف جديد

GET /api/financial-transactions

الحصول على المعاملات المالية المرقمة مع الفلاتر

GET /api/financial-transactions/export

تصدير المعاملات إلى Excel/CSV

GET /secretary/payments

صفحة المدفوعات الرئيسية للسكرتارية

المعاملات: ?patient_id={id} - فلتر اختياري حسب المريض
GET /secretary/payments/{id}

عرض صفحة تفاصيل الدفع

GET /secretary/payments/{id}/receipt

إنشاء وعرض إيصال الدفع القابل للطباعة

GET /secretary/expenses/{id}

عرض صفحة تفاصيل المصروف

وظائف JavaScript الرئيسية

الملف: JavaScript مضمّن في @app/Views/secretary/payments.php

الوظائف الرئيسية:

loadFinancialTransactions(page)

وظائف نافذة البحث:

معالج البحث الشامل
بحث فوري أثناء كتابة المستخدم مع debouncing، يعرض النتائج ديناميكياً
عرض نتائج البحث
يعرض حالة التحميل، حالة لا توجد نتائج، وقائمة النتائج المملوءة

اختصارات لوحة المفاتيح:

  • R أو ر - فتح نافذة تسجيل الرصيد
  • E أو م - فتح نافذة تسجيل المصروف
  • F أو ب - فتح نافذة البحث
  • Ctrl+F - التركيز على حقل البحث (عند فتح نافذة البحث)
  • Esc - إغلاق أي نافذة مفتوحة

تنفيذ البحث

آلية البحث:

  • بحث فوري: تظهر النتائج تلقائياً أثناء كتابة المستخدم (type-ahead)
  • Debouncing: يتم تأخير طلبات البحث لتقليل استدعاءات API
  • حقول البحث: البحث في اسم المريض ورقم الهاتف ورقم الدفعة
  • عرض النتائج: يعرض المدفوعات المطابقة مع معلومات المريض والمبلغ والنوع والإجراءات السريعة

حالات البحث:

  • الحالة الأولية: يعرض أيقونة البحث ونص مفيد
  • حالة التحميل: يعرض spinner ورسالة "جاري البحث..."
  • حالة النتائج: يعرض قائمة المدفوعات المطابقة
  • حالة لا توجد نتائج: يعرض رسالة واقتراح لتجربة مصطلحات مختلفة

سلوك النافذة:

  • يتم التركيز تلقائياً على حقل البحث عند فتح النافذة
  • يتم مسح البحث عند إغلاق النافذة
  • يمكن إغلاق النافذة بمفتاح Esc أو زر الإغلاق

نظام التصفية

فلاتر سجل المعاملات:

  • فلتر التاريخ: منتقي تاريخ للتصفية حسب تاريخ محدد
  • فلتر النوع: قائمة منسدلة للتصفية حسب نوع المعاملة (الكل، المدفوعات، المصروفات، الرصيد)
  • يتم تطبيق الفلاتر فوراً عند التغيير
  • يتم إعادة تعيين الترقيم عند تغيير الفلاتر

فلاتر سجلات المدفوعات:

  • البحث السريع: بحث نصي فوري في اسم المريض أو الهاتف أو رقم الدفعة
  • فلتر النوع: قائمة منسدلة للتصفية حسب نوع الدفع
  • فلتر الطريقة: قائمة منسدلة للتصفية حسب طريقة الدفع
  • تعمل جميع الفلاتر معاً (منطق AND)
  • زر مسح البحث (X) يعيد تعيين حقل البحث

معالجة الأخطاء

من جانب العميل:

  • التحقق من النموذج قبل الإرسال
  • مؤشرات التحميل أثناء استدعاءات API
  • رسائل النجاح/الخطأ المعروضة في النوافذ
  • تحديث لوحة القيادة التلقائي بعد العمليات الناجحة
  • رسائل الحالة الفارغة للجداول بدون بيانات

من جانب الخادم:

  • التحقق من المصادقة على جميع نقاط النهاية (401 إذا لم يكن مصرحاً)
  • التحقق من المدخلات مع رسائل خطأ تفصيلية
  • سلامة معاملات قاعدة البيانات
  • رسائل الخطأ المُرجعة بتنسيق JSON
  • رموز حالة HTTP مناسبة (200، 400، 401، 404، 500)
