نظرة عامة على حالة النظام

مكون حالة النظام يوفر مراقبة مباشرة للبنية التحتية الحرجة للنظام بما في ذلك اتصال قاعدة البيانات ومساحة التخزين وإصدار PHP والملحقات المطلوبة. يساعد المسؤولين على تحديد مشاكل النظام بسرعة وضمان أداء مثلى.

انقر لعرض الحجم الكامل

عرض توضيحي مرئي لواجهة حالة النظام

حالة قاعدة البيانات

يراقب اتصال قاعدة البيانات ويعرض حالة الاتصال مباشرة، مما يساعد في تحديد مشاكل قاعدة البيانات فوراً.

مراقبة التخزين

يتتبع استخدام مساحة القرص مع شريط تقدم مرئي ومؤشر نسبة مئوية، مما ينبه عندما يكون التخزين منخفضاً.

PHP والملحقات

يعرض إصدار PHP ويفحص الملحقات المطلوبة، مما يضمن توافق النظام والوظائف.

بنية المكون

مكون حالة النظام يتكون من عدة عناصر فحص صحة معروضة في بطاقة.

قسم الرأس

الرأس يتضمن:

  • العنوان: "حالة النظام" مع أيقونة نبضات القلب
  • التنسيق: رأس بطاقة مع فاصل border-bottom

عناصر الصحة

كل عنصر فحص صحة يحتوي على:

  • الأيقونة: أيقونة ذات صلة بمقياس الصحة (قاعدة البيانات، التخزين، PHP)
  • التسمية: اسم مقياس الصحة
  • شارة الحالة: شارة مشفرة بالألوان تظهر الحالة (success، warning، danger)
  • التفاصيل: معلومات إضافية (للتخزين: شريط تقدم ونص الاستخدام)

مقاييس الصحة

شرح مفصل لكل مقياس صحة معروض في المكون.

حالة قاعدة البيانات

طريقة الفحص: ينفذ استعلام SELECT 1 لاختبار الاتصال

عرض الحالة:

  • متصل: شارة خضراء إذا نجح الاستعلام
  • خطأ: شارة حمراء مع رسالة خطأ إذا فشل الاستعلام

الغرض: يضمن أن اتصال قاعدة البيانات يعمل بشكل صحيح

مساحة التخزين

طريقة الفحص: يستخدم PHP disk_free_space() و disk_total_space()

المقاييس المعروضة:

  • المساحة المستخدمة: بايت منسقة (مثلاً "15.51 GB")
  • المساحة الإجمالية: بايت منسقة (مثلاً "968.99 GB")
  • نسبة الاستخدام: محسوبة ومعروضة كشارة
  • شريط التقدم: تمثيل مرئي لاستخدام التخزين

التشفير بالألوان:

  • أخضر: < 80% استخدام (صحي)
  • أصفر: 80-90% استخدام (تحذير)
  • أحمر: > 90% استخدام (حرج)

إصدار PHP

طريقة الفحص: يستخدم ثابت PHP PHP_VERSION

العرض: يظهر إصدار PHP الحالي (مثلاً "8.2.28")

لون الشارة: شارة Info (سماوي)

الغرض: يساعد في التحقق من توافق إصدار PHP

الملحقات المطلوبة

طريقة الفحص: يستخدم دالة PHP extension_loaded()

الملحقات المفحوصة:

  • pdo: ملحق PHP Data Objects
  • pdo_mysql: برنامج تشغيل PDO MySQL
  • json: ترميز/فك ترميز JSON
  • mbstring: دوال سلسلة متعددة البايت

عرض الحالة:

  • مُحمَّل: شارة خضراء إذا كان الملحق متاحاً
  • مفقود: شارة حمراء إذا لم يتم تحميل الملحق

كيف يعمل

مكون حالة النظام ينفذ فحوصات مباشرة ويعرض النتائج مع مؤشرات حالة مشفرة بالألوان.

المعالجة الخلفية

طريقة AdminController::getSystemHealth():

  • فحص قاعدة البيانات: يحاول $pdo->query('SELECT 1')، يلتقط الاستثناءات
  • فحص التخزين: يحسب المساحة الحرة/الإجمالية/المستخدمة من مجلد storage
  • إصدار PHP: يحصل على ثابت PHP_VERSION
  • فحص الملحقات: يتكرر عبر الملحقات المطلوبة، يفحص باستخدام extension_loaded()
  • التنسيق: يستخدم مساعد formatBytes() لعرض التخزين
  • الإرجاع: مصفوفة مع مفاتيح 'database'، 'storage'، 'php_version'، 'extensions'

العرض الأمامي

قالب لوحة التحكم يعرض مقاييس الصحة:

  • عناصر الصحة: كل مقياس يستخدم فئة health-item
  • شارات الحالة: ألوان شارات ديناميكية بناءً على الحالة
  • شريط التقدم: شريط تقدم Bootstrap لاستخدام التخزين
  • تنسيق شرطي: ألوان الشارات تتغير بناءً على العتبات
  • متجاوب: يتكيف مع أحجام الشاشات المختلفة

التشفير بالألوان

ألوان شارات الحالة:

  • Success (أخضر): قاعدة البيانات متصلة، التخزين < 80%، الملحقات محملة
  • Warning (أصفر): استخدام التخزين 80-90%
  • Danger (أحمر): خطأ قاعدة البيانات، التخزين > 90%، الملحقات مفقودة
  • Info (سماوي): عرض إصدار PHP

الميزات الرئيسية

مكون حالة النظام يتضمن عدة ميزات لمراقبة فعالة للنظام.

فحوصات مباشرة

جميع مقاييس الصحة يتم فحصها مباشرة عند كل تحميل للصفحة، مما يضمن عرض حالة النظام الحالية دائماً.

تنبيهات مرئية

شارات مشفرة بالألوان وأشرطة التقدم توفر ملاحظات بصرية فورية حول حالة صحة النظام.

معلومات مفصلة

كل مقياس يوفر معلومات مفصلة (مبالغ التخزين، إصدار PHP، حالة الملحق) لمراقبة شاملة.

دعم الثيم

المكون يتكيف تلقائياً مع الثيمات الفاتحة والداكنة، مما يضمن قابلية قراءة مثلى في جميع ظروف العرض.
