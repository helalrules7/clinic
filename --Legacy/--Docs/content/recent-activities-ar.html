الأنشطة الأخيرة

تتبع أحداث النظام وإجراءات المستخدم

أنشطة الخط الزمني تاريخ

نظرة عامة على الأنشطة الأخيرة

مكون الأنشطة الأخيرة يعرض خط زمني زمني لأحداث النظام وإجراءات المستخدم، مما يوفر للأطباء نظرة شاملة للأنشطة الأخيرة في نظام إدارة العيادة. يتتبع المواعيد، الوصفات، سجلات المرضى، وأحداث مهمة أخرى.

انقر لعرض الحجم الكامل

عرض توضيحي مرئي لواجهة الأنشطة الأخيرة

الخط الزمني للأنشطة

يعرض الأنشطة بترتيب زمني مع مؤشرات خط زمني مرئية، مما يظهر أحدث الأحداث أولاً.

نسبة المستخدم

كل نشاط يظهر المستخدم الذي قام بالإجراء، مما يجعل من السهل تتبع من فعل ماذا ومتى.

روابط المواعيد

الأنشطة المتعلقة بالمواعيد تتضمن روابط "عرض الموعد" للوصول السريع إلى تفاصيل الموعد.

أنواع الأنشطة

النظام يتتبع أنواع مختلفة من الأنشطة والأحداث.

أنشطة الأدوية

تتبع الإجراءات المتعلقة بالأدوية:

  • إصدار وصفة دواء
  • حذف دواء
  • تحديث دواء

أنشطة المواعيد

مراقبة الأحداث المتعلقة بالمواعيد:

  • حجز موعد
  • تغيير الحالة (محجوز → مكتمل، إلخ)
  • إعادة جدولة موعد

أنشطة الملفات

تتبع رفع الملفات والوسائط:

  • رفع ملفات (صور، مستندات)
  • إرفاق وسائط بسجلات المرضى
  • حذف ملفات

أنشطة الوصفات

مراقبة الإجراءات المتعلقة بالوصفات:

  • إصدار وصفات طبية
  • إنشاء وصفات نظارات
  • تعديلات الوصفات

نافذة عرض الكل

زر "عرض الكل" يفتح نافذة شاملة تعرض جميع الأنشطة مع قدرات فلترة وترقيم متقدمة.

انقر لعرض الحجم الكامل

عرض توضيحي مرئي لواجهة نافذة جميع الأنشطة

فلترة الأنشطة

النافذة تتضمن نظام فلترة قوي:

  • إدخال البحث: فلترة الأنشطة حسب ملخص الحدث، اسم المريض، أو رقم الهاتف
  • فلترة مباشرة: الفلترة تتحدث أثناء الكتابة مع debouncing للأداء
  • تمييز النص: النص المطابق يتم تمييزه بالأصفر للتعريف السهل
  • مسح الفلتر: زر لمسح الفلتر بسرعة وعرض جميع الأنشطة

الترقيم

الأنشطة مرقمة لأداء أفضل:

  • اختيار لكل صفحة: اختر عدد الأنشطة للعرض (10، 25، 50، 100 لكل صفحة)
  • تنقل الصفحات: التنقل بين الصفحات باستخدام ضوابط الترقيم
  • العدد الإجمالي: عرض العدد الإجمالي للأنشطة المطابقة للفلتر
  • فلترة من جانب العميل: جميع الأنشطة يتم تحميلها مرة واحدة، ثم فلترتها من جانب العميل لنتائج فورية

تحميل البيانات

النافذة تستخدم تحميل بيانات فعال:

  • التحميل الأولي: يحمل حتى 1000 نشاط عند فتح النافذة
  • المعالجة من جانب العميل: الفلترة والترقيم تحدث في المتصفح لاستجابة فورية
  • نقطة نهاية API: يستخدم نقطة النهاية /api/recent-activity من ApiController
  • التخزين المؤقت: الأنشطة يتم تخزينها مؤقتاً في الذاكرة أثناء جلسة النافذة
ميزات النافذة:

نافذة "عرض الكل" توفر نظرة شاملة لجميع أنشطة النظام. تتضمن إدخال بحث/فلتر في الأعلى، ضوابط الترقيم، وتعرض الأنشطة في قائمة قابلة للتمرير. كل نشاط يظهر وصف الحدث، المستخدم المرتبط، الطابع الزمني، وروابط الإجراءات ذات الصلة. النافذة تستخدم تصميم glassmorphism مع backdrop blur لمظهر حديث.

كيف يعمل

الأنشطة الأخيرة تعمل من خلال API Controller وتستخدم JavaScript لإدارة النافذة والفلترة من جانب العميل.

نقطة نهاية API

النظام يستخدم ApiController::getRecentActivity():

  • نقطة النهاية: /api/recent-activity
  • المصادقة: يتطلب مصادقة المستخدم
  • الترقيم: يدعم معاملات page و per_page
  • البحث: يدعم معامل search للفلترة
  • مصدر البيانات: يستعلم جدول timeline_events مع join مع patients و appointments

البحث والفلترة

API يدعم الفلترة من جانب الخادم:

  • حقول البحث: ملخص الحدث، اسم المريض الأول، اسم العائلة، الاسم الكامل، الهاتف
  • SQL LIKE: يستخدم استعلامات SQL LIKE مع wildcards للمطابقة المرنة
  • فلتر من جانب العميل: النافذة أيضاً تقوم بفلترة من جانب العميل لنتائج فورية
  • Debouncing: إدخال الفلتر يستخدم debouncing لتقليل طلبات API

إدارة النافذة

JavaScript يتعامل مع وظائف النافذة:

  • فتح النافذة: يحمل الأنشطة عند عرض النافذة
  • تحميل البيانات: يجلب حتى 1000 نشاط عند الفتح الأول
  • تطبيق الفلتر: يطبق الفلتر على الأنشطة المحملة من جانب العميل
  • الترقيم: يتعامل مع ترقيم النتائج المفلترة
  • تمييز النص: يميز النص المطابق في نتائج البحث

الميزات الرئيسية

الأنشطة الأخيرة تتضمن عدة ميزات لتتبع شامل للأنشطة.

عرض زمني

الأنشطة معروضة بترتيب زمني عكسي (الأحدث أولاً)، مما يجعل من السهل رؤية أحدث الأحداث.

روابط سريعة

الأنشطة المتعلقة بالمواعيد تتضمن روابط "عرض الموعد" التي تنتقل مباشرة إلى تفاصيل الموعد.

دعم الثيم

المكون يتكيف تلقائياً مع الثيمات الفاتحة والداكنة، مما يضمن قابلية قراءة مثلى في جميع ظروف العرض.

تصميم متجاوب

النافذة وقائمة الأنشطة متجاوبة بالكامل، تعمل بسلاسة على سطح المكتب، الجهاز اللوحي، والأجهزة المحمولة.
