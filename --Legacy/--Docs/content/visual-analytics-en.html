Visual Analytics Overview

The Visual Analytics component provides interactive charts that visualize appointment trends and patient statistics over time. It uses Chart.js library to render dynamic line charts that automatically adapt to light and dark themes, providing comprehensive insights into clinic performance.

Interactive Charts

Dynamic line charts that visualize data trends over the last 30 days, excluding today's data for accurate historical analysis.

Theme Support

Charts automatically adapt to light and dark themes, ensuring optimal readability and visual consistency.

Real-Time Updates

Charts are updated automatically when theme changes, and data is fetched fresh on each page load.

Appointments Trend Chart

The Appointments Trend chart displays the daily appointment statistics over the last 30 days, showing total appointments, completed appointments, and missed appointments.

Chart Type

Line Chart with Area Fill: A multi-line chart with three datasets:

  • Total Appointments (Blue): Shows all appointments scheduled for each day, with area fill under the line
  • Completed (Green): Shows appointments that were successfully completed
  • Missed (Red): Shows appointments that were not completed (status != 'Completed')

Data Source

The chart data is fetched from:

  • API Endpoint: GET /api/charts-data
  • Time Range: Last 30 days (excluding today)
  • Query: Groups appointments by date, counts total, completed, and missed
  • Database: appointments table filtered by date range

Visual Design

Chart styling features:

  • Total Appointments: Blue line (#007bff) with filled area underneath
  • Completed: Green line (#28a745) without fill
  • Missed: Red line (#ef4444) without fill
  • Smooth Curves: Uses tension: 0.4 for smooth line rendering
  • Theme Adaptation: Text colors and grid lines adapt to theme

Key Insights

What the chart reveals:

  • Daily Volume: Shows appointment load per day
  • Completion Rate: Visual comparison between total and completed
  • Missed Patterns: Identifies days with high missed appointment rates
  • Trend Analysis: Helps identify patterns over time

New Patients Trend Chart

The New Patients Trend chart displays the daily registration of new patients over the last 30 days, broken down by gender (Male and Female).

Chart Type

Multi-Line Chart: A line chart with three datasets:

  • Total Patients (Theme Color): Shows total new patients registered each day
  • Male (Dodger Blue #1E90FF): Shows male patients registered each day
  • Female (Hot Pink #FF1493): Shows female patients registered each day

Data Source

The chart data is fetched from:

  • API Endpoint: GET /api/charts-data
  • Time Range: Last 30 days (excluding today)
  • Query: Groups patients by creation date, counts total, male, and female
  • Database: patients table filtered by created_at date range
  • Gender Filtering: Uses gender column ('Male' or 'Female')

Visual Design

Chart styling features:

  • Total Patients: Uses theme text color (white in dark mode, black in light mode)
  • Male: Dodger Blue (#1E90FF) line
  • Female: Hot Pink (#FF1493) line
  • Smooth Curves: Uses tension: 0.4 for smooth line rendering
  • No Fill: All lines are without area fill for clarity

Key Insights

What the chart reveals:

  • Registration Patterns: Shows daily patient registration trends
  • Gender Distribution: Visual comparison between male and female registrations
  • Growth Trends: Identifies periods of high or low patient acquisition
  • Demographic Analysis: Helps understand patient demographics over time

How It Works

The Visual Analytics component uses Chart.js library for rendering and automatically updates when the theme changes.

JavaScript Functions

Key functions in dashboard.js:

  • loadChartsData(): Fetches data from API endpoint
  • renderAppointmentsChart(trendData): Renders appointments trend chart
  • renderNewPatientsTrendChart(patientsData): Renders new patients trend chart
  • updateChartsTheme(): Updates chart colors when theme changes
  • getCurrentThemeColors(): Gets theme-appropriate colors

Backend API

ApiController::getChartsData() method:

  • Time Range: Calculates last 30 days (excluding today)
  • Appointments Query: Groups by date, counts total/completed/missed
  • Patients Query: Groups by creation date, counts total/male/female
  • Response: Returns JSON with trend data, status summary, and patient data

Theme Integration

Theme change handling:

  • MutationObserver: Watches for theme class changes on document
  • Theme Toggle Listener: Listens for theme toggle button clicks
  • Auto-Update: Charts reload with new theme colors automatically
  • Color Adaptation: Text, grid, and background colors adapt to theme

Chart Features

The Visual Analytics charts include several features for enhanced data visualization.

Interactive Tooltips

Hover over data points to see exact values for each day, including total, completed, and missed appointments or patient counts.

Legend

Clickable legend allows toggling visibility of individual data series, making it easy to focus on specific metrics.

Responsive Design

Charts automatically resize to fit container width and maintain aspect ratio on all screen sizes.

Time Range
