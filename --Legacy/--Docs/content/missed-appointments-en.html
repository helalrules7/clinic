Missed Appointments Overview

The Missed Appointments component displays all appointments from previous days that were not completed. This helps doctors track appointments that need follow-up, rescheduling, or completion marking.

Missed Tracking

Pagination

Component Structure

The Missed Appointments component consists of a header with controls and a paginated list of appointments.

Header Section

The header includes:

  • Title: "Missed Appointments" with warning triangle icon
  • Per Page Selector: Dropdown to select items per page (5, 10, 20, 50)
  • Card Controls: Move up/down buttons and drag handle for reordering

Appointment List

Each appointment is displayed as a list item containing:

  • Patient Name: Full name in blue, clickable link to patient profile
  • Time Range: Start and end time (e.g., "17:15 - 17:30")
  • Date: Appointment date in DD/MM/YYYY format
  • Status Badge: Shows appointment status (e.g., "Booked")
  • Visit Type: Shows visit type (e.g., "New", "FollowUp")
  • Action Buttons: Mark Completed, View Appointment, View Patient

Pagination

Pagination controls include:

  • Previous/Next: Navigation arrows to move between pages
  • Page Numbers: Clickable page numbers with current page highlighted
  • Ellipsis: Shows "..." when there are many pages
  • Total Pages: Displays total number of pages available

How It Works

The Missed Appointments component fetches appointments from previous days that were not completed.

JavaScript Functions

Key functions in dashboard.js:

  • loadMissedAppointments(page, limit): Fetches appointments from API
  • renderMissedAppointments(appointments): Renders appointment list
  • renderMissedPagination(pagination): Renders pagination controls
  • loadMissedAppointmentsPage(page): Loads specific page
  • markMissedAppointmentCompleted(id): Shows completion modal
  • confirmMissedAppointmentCompleted(id): Updates appointment status

Backend API

ApiController::getMissedAppointments() method:

  • Pagination: Supports page and per_page parameters
  • Date Filter: WHERE date < CURDATE()
  • Status Filter: status != 'Completed' AND status != 'Cancelled'
  • Ordering: Ordered by date DESC, start_time DESC
  • Joins: JOIN with patients table for patient information
  • Response: Returns JSON with items array and pagination info

Database Query

The query structure:

  • Table: appointments joined with patients
  • Date Condition: a.date < CURDATE() (previous days only)
  • Status Condition: Excludes 'Completed' and 'Cancelled' statuses
  • Fields: Selects appointment fields plus patient first_name, last_name, phone
  • Pagination: Uses LIMIT and OFFSET for efficient data retrieval

Action Buttons

Each missed appointment includes action buttons for quick management.

Mark Completed

The "Mark Completed" button:

  • Function: markMissedAppointmentCompleted(appointmentId)
  • Modal: Shows confirmation modal before updating
  • API Call: PUT /api/appointments/{id} with status: 'Completed'
  • Update: Updates appointment status in database
  • Refresh: Reloads missed appointments list after update

View Appointment

The "Appointment" button:

  • Link: /doctor/appointments/{id}
  • Purpose: Navigates to full appointment details page
  • Icon: Calendar icon for visual clarity

View Patient

The "View Patient" button:

  • Link: /doctor/patients/{patient_id}
  • Purpose: Navigates to patient profile page
  • Icon: Person icon for visual clarity
