System Statistics Overview

The System Statistics component provides a comprehensive overview of key system metrics including total users, patients, appointments, and revenue. It displays four statistical cards with color-coded gradients, each showing primary metrics and detailed breakdowns.

Real-Time Metrics

Displays live statistics calculated from the database, providing instant insights into system performance and usage.

Color-Coded Cards

Each statistic card uses a distinct color gradient (Primary, Success, Info, Warning) for easy visual identification.

Auto-Refresh

Statistics are calculated fresh on each page load, ensuring data accuracy and up-to-date information.

Statistics Cards

The System Statistics component consists of four main cards, each displaying different metrics.

Total Users Card (Primary Blue)

Primary Metric: Total number of users in the system

Breakdown:

  • Doctors: Count of users with role 'doctor'
  • Secretaries: Count of users with role 'secretary'

Data Source: users table

Query: Counts total users, active users, doctors, and secretaries

Total Patients Card (Success Green)

Primary Metric: Total number of patients registered in the system

Breakdown:

  • Active: Count of active users (from users table, not patients)

Data Source: patients table

Query: Simple count of all patient records

Appointments Card (Info Cyan)

Primary Metric: Total appointments in the last 30 days

Breakdown:

  • Completed: Count of appointments with status 'Completed'
  • Cancelled: Count of appointments with status 'Cancelled'

Data Source: appointments table

Query: Filters appointments from last 30 days, counts by status

Revenue Card (Warning Orange)

Primary Metric: Total revenue in EGP (Egyptian Pounds) for the last 30 days

Breakdown:

  • Transactions: Total number of payment transactions
  • Discounts: Total discount amount applied

Data Source: payments table

Query: Sums amount and discount_amount, counts transactions from last 30 days

How It Works

The System Statistics component fetches data from the database and displays it in visually appealing cards.

Backend Processing

AdminController::getSystemStats() method:

  • User Statistics: Queries users table for total, active, doctors, secretaries
  • Patient Statistics: Counts all records in patients table
  • Appointment Statistics: Filters last 30 days, counts by status
  • Financial Statistics: Sums revenue and discounts from payments table (last 30 days)
  • Returns: Array with 'users', 'patients', 'appointments', 'financial' keys

Frontend Rendering

The dashboard template renders statistics:

  • Card Structure: Each card uses Bootstrap grid (col-md-3)
  • Styling: Gradient backgrounds with stat-card class
  • Icons: Font Awesome icons for visual identification
  • Formatting: Uses number_format() for readable numbers
  • Responsive: Adapts to different screen sizes (col-sm-6 on mobile)

Visual Design

Card styling features:

  • Gradient Backgrounds: Each card uses CSS gradients
  • Hover Effects: Cards lift up on hover with enhanced shadow
  • Icon Size: Large icons (2.5rem) for visual prominence
  • Typography: Large numbers (1.75rem), clear labels
  • Theme Support: Adapts to light and dark themes

Data Details

Detailed breakdown of how each statistic is calculated and displayed.

User Statistics

Calculated from users table:

  • Total Users: COUNT(*) from users table
  • Active Users: SUM(CASE WHEN is_active = 1 THEN 1 ELSE 0 END)
  • Doctors: SUM(CASE WHEN role = 'doctor' THEN 1 ELSE 0 END)
  • Secretaries: SUM(CASE WHEN role = 'secretary' THEN 1 ELSE 0 END)

Appointment Statistics

Calculated from appointments table (last 30 days):

  • Total Appointments: COUNT(*) where date >= CURDATE() - INTERVAL 30 DAY
  • Completed: SUM(CASE WHEN status = 'Completed' THEN 1 ELSE 0 END)
  • Cancelled: SUM(CASE WHEN status = 'Cancelled' THEN 1 ELSE 0 END)

Financial Statistics

Calculated from payments table (last 30 days):

  • Total Revenue: SUM(amount) from payments
  • Total Discounts: SUM(discount_amount) from payments
  • Total Transactions: COUNT(*) from payments
  • Time Range: DATE(created_at) >= CURDATE() - INTERVAL 30 DAY

Key Features

The System Statistics component includes several features for effective data visualization.

30-Day Window

Appointments and revenue statistics focus on the last 30 days, providing recent performance insights without overwhelming historical data.

Theme Support

Cards automatically adapt to light and dark themes, ensuring optimal readability and visual consistency across all viewing conditions.

Responsive Layout

Cards are arranged in a responsive grid that adapts to screen size: 4 columns on desktop, 2 columns on tablets, 1 column on mobile.

Number Formatting

All numbers are formatted using number_format() for readability, with 2 decimal places for currency values.
