نظرة عامة على المشروع

حل شامل لإدارة العيادات الطبية مصمم لتبسيط عمليات العيادة، وتحسين رعاية المرضى، وزيادة الكفاءة الإدارية.

ثلاثة أدوار رئيسية

  • الطبيب: إدارة المرضى، المواعيد، الوصفات، والفحوصات
  • السكرتير: إدارة الحجوزات، المدفوعات، وتسجيل المرضى
  • المدير: إدارة النظام، المستخدمين، والتقارير

الميزات الرئيسية

  • إدارة المرضى مع التاريخ الطبي
  • تقويم مواعيد تفاعلي
  • إدارة الوصفات الطبية (الأدوية والنظارات)
  • الإدارة المالية والتقارير
  • لوحة إحصائيات شاملة

التقنيات المستخدمة

  • الخلفية: PHP 8.2+ مع بنية MVC
  • قاعدة البيانات: MySQL 8.0+
  • الواجهة: JavaScript و CSS حديث
  • الأمان: RBAC، حماية CSRF

زيارة الموقع

دليل التثبيت

اتبع هذه الخطوات لتثبيت وإعداد النظام على الخادم الخاص بك.

1

متطلبات النظام

متطلبات الخادم:

  • PHP 8.2 أو أحدث
  • MySQL 8.0 أو أحدث
  • Apache/Nginx مع mod_rewrite
  • Composer

ملحقات PHP:

  • ext-pdo
  • ext-json
  • ext-mbstring
2

استنساخ المشروع وتثبيت التبعيات

Terminal 
# استنساخ المستودع
git clone <repository-url>
cd clinic

# تثبيت التبعيات
composer install
3

إعداد قاعدة البيانات

Terminal 
# إنشاء قاعدة البيانات
mysql -u root -p -e "CREATE DATABASE roaya CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# استيراد المخطط
mysql -u root -p roaya < sql/schema.sql

# استيراد البيانات الأولية
mysql -u root -p roaya < sql/seed.sql
4

إعدادات البيئة

أنشئ ملف .env في المجلد الرئيسي للمشروع:

.env 
# إعدادات قاعدة البيانات
DB_HOST=localhost
DB_NAME=roaya
DB_USER=root
DB_PASS=your_password

# إعدادات التطبيق
APP_ENV=local
APP_KEY=roaya-clinic-system-2024-secret-key-32
TIMEZONE=Africa/Cairo

# الأمان
SESSION_SECRET=roaya-session-secret-key-2024-32-chars
CSRF_SECRET=roaya-csrf-secret-key-2024-32-chars
5

تعيين الصلاحيات

Terminal 
# إنشاء المجلدات المطلوبة
mkdir -p storage/logs storage/uploads storage/exports
chmod -R 755 storage/

# إعادة توليد autoloader
composer dump-autoload
6

تشغيل التطبيق

Terminal 
# استخدام خادم PHP المدمج
php -S localhost:8000 router.php

# أو مع Apache/Nginx
# وجه document root إلى مجلد المشروع
روابط الوصول:
  • الصفحة الرئيسية: http://localhost:8000/
  • تسجيل الدخول: http://localhost:8000/public/login

دليل البدء السريع

ابدأ بسرعة باستخدام بيانات تسجيل الدخول الافتراضية والتنقل الأساسي.

بيانات تسجيل الدخول الافتراضية

الدور اسم المستخدم البريد الإلكتروني كلمة المرور
د. أحمد dr_ahmed dr.ahmed@roayaclinic.com password
د. فرماوي dr_faramawy dr.faramawy@roayaclinic.com password
السكرتير sec sec@roayaclinic.com password
المدير admin admin@roayaclinic.com password
ملاحظة: النظام يستخدم اسم المستخدم بدلاً من البريد الإلكتروني لتسجيل الدخول.

التنقل الأساسي

لوحة تحكم الطبيب

  • عرض قائمة المرضى والسجلات الطبية
  • إدارة تقويم المواعيد
  • إنشاء الوصفات (الأدوية والنظارات)
  • عرض التقارير والإحصائيات

لوحة تحكم السكرتير

  • تسجيل المرضى الجدد
  • إدارة الحجوزات والمواعيد
  • معالجة المدفوعات والفواتير
  • عرض تفاصيل الحجوزات

لوحة تحكم المدير

  • إدارة المستخدمين والأدوار
  • إعدادات النظام والتكوين
  • عرض سجلات النظام والنسخ الاحتياطية
  • إدارة الوسائط

هندسة النظام

فهم بنية المشروع والهندسة التقنية.

هيكل المجلدات 
clinic/
├── app/
│   ├── Config/          # ملفات الإعدادات
│   ├── Controllers/     # وحدات التحكم
│   ├── Lib/            # المكتبات الأساسية
│   ├── Models/         # نماذج البيانات
│   └── Views/          # قوالب الواجهة
│       ├── admin/      # واجهة المدير
│       ├── doctor/     # واجهة الطبيب
│       ├── secretary/  # واجهة السكرتير
│       └── print/      # قوالب الطباعة
├── public/              # نقطة الدخول
├── sql/                 # ملفات قاعدة البيانات
├── storage/             # مجلد التخزين
│   ├── logs/           # سجلات النظام
│   ├── uploads/        # الملفات المرفوعة
│   └── exports/        # التقارير المصدرة
├── vendor/              # تبعيات Composer
├── .env                 # إعدادات البيئة
└── router.php           # الراوتر المخصص

Model

يتعامل مع منطق البيانات والتفاعل مع قاعدة البيانات. موجود في app/Models/

View

مسؤول عن طبقة العرض. القوالب في app/Views/

Controller

يعالج الطلبات وينسق بين Model و View. موجود في app/Controllers/

مجموعة الأحرف: utf8mb4
