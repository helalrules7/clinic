When a new notification arrives, the system automatically plays a pleasant notification sound using the Web Audio API. The sound is a simple sine wave tone at 800 Hz frequency, lasting 0.3 seconds with a smooth fade-out effect. This audio alert ensures you're immediately aware of new notifications even if you're not looking at the screen.

What are Push Notifications?

Push notifications are browser-based alerts that can appear on your device even when the browser is closed or you're on a different website. They allow you to stay informed about important events without needing to keep the application open.

Enable Push Notifications

When you click "Enable", the browser will ask for your permission to send push notifications. Once granted, you'll receive notifications even when the browser is closed.

Remind Me Later

If you're not ready to enable push notifications, you can choose "Remind me later" to postpone the decision. The prompt will appear again in the future.

Don't Ask for This Browser

If you don't want push notifications for this browser, you can select "Don't ask for this browser" to permanently dismiss the prompt for this specific browser.

Browser Settings

You can always manage push notification permissions through your browser settings. This allows you to enable or disable notifications at any time.

Benefits of Push Notifications:
  • Stay Informed: Receive alerts about appointments, notes, and important updates even when the browser is closed
  • Never Miss Important Events: Get notified about critical patient alerts, appointment changes, and system updates
  • Improved Workflow: Respond to important notifications immediately without needing to check the application constantly
  • Flexible Control: You can disable push notifications at any time through browser settings if you prefer not to receive them

Settings Page Control:

You can control push notifications directly from the Settings page. Navigate to Settings to find the "Push Notification" section where you can enable or disable push notifications globally, and manage your subscribed browsers.

Global Toggle

The "Push Notification" toggle switch allows you to enable or disable push notifications for your account. When enabled (ON), you'll receive push notifications. When disabled (OFF), no push notifications will be sent.

Subscribed Browsers

The "Subscribed Push Notification Browsers" section displays all browsers where you've enabled push notifications. Each entry shows the browser name (or "Unknown Browser" if not identified) and the subscription endpoint URL.

Remove Subscriptions

You can remove individual browser subscriptions by clicking the delete button (trash icon) next to each browser entry. This will stop push notifications for that specific browser while keeping others active.

Centralized Management

All push notification settings are managed in one convenient location in the Settings page, making it easy to control your notification preferences alongside other account settings.

How It Works:
  • Enable/Disable: Use the toggle switch to turn push notifications on or off globally for your account
  • Browser List: View all browsers where you've subscribed to push notifications, including the Firebase Cloud Messaging (FCM) endpoint for each
  • Remove Subscriptions: Click the delete button to remove a specific browser subscription, which will stop push notifications for that browser only
  • Multiple Devices: You can have push notifications enabled on multiple browsers/devices simultaneously, and manage each one independently
