Main dashboard for patient management

Financial Statistics

Quick view of Total Patients, Active Patients, New Patients, and Total Financial Payments in the system.

Comprehensive Search

Instant search for patients using Name, Phone Number, or National ID, with direct access to files.

Payment Management

Direct access to patient payment records and billing status from the main list.

Statistics Cards

Four key indicators providing an overview of the clinic's status.

Total Patients

Value: The total number of registered patients.

Significance: Indicator of the clinic's database size.

Active Patients

Value: Number of patients with active bookings or visits.

Significance: Tracking current clinic activity.

New This Month

Value: Number of patients registered during the current month.

Significance: Measuring monthly clinic growth.

Total Payments

Value: Sum of recorded financial payments.

Significance: Quick view of financial performance.

Filtering and Search Tools

Multiple options to narrow down search results and find specific records.

Advanced search and filtering toolbar

Text Search

Search using Name, Phone Number, or National ID.

Gender

Filter the list to show only Males or Females.

Age Group

Specify a specific age range for displayed patients.

Last Visit

Display patients based on their last appointment date.

Table Actions

The table provides quick actions for each patient to facilitate the secretary's daily tasks.

Action buttons available for each record

View Details

Button: Eye icon (Blue).

Function: Navigate to the full patient profile to view medical history and past appointments.

Book Appointment

Button: Calendar icon (Green).

Function: Open a new appointment booking window for this patient directly.

Payments

Button: Card icon (Orange).

Function: Navigate to the payments page for this patient to manage invoices and collection.

Add New Patient

Register a new patient file in the system.

New patient registration form

Basic Data

Includes First Name, Last Name, and Date of Birth (or Age), which are mandatory for file creation.

Contact Information

Registering Primary Phone (required) and Alternative Phone, plus National ID and Address to ensure accurate communication.

Direct Communication

Quick communication facilities with patients via Phone or WhatsApp.

Phone Call

Click on the phone number to open the calling application directly.

WhatsApp

Dedicated icon to open a WhatsApp chat with the patient immediately without saving the number.
