# Dashboard Images

## الصور المطلوبة للتوثيق

هذا المجلد يحتوي على صور لوحة تحكم الطبيب المستخدمة في التوثيق.

### الصور الموجودة حالياً:
- ✅ `stats-cards.png` - بطاقات الإحصائيات
- ✅ `weather-widget.png` - ودجت الطقس
- ✅ `weather-forecast.png` - توقعات الطقس
- ✅ `news-widget.png` - ودجت الأخبار
- ✅ `quick-actions.png` - الإجراءات السريعة

- ❌ `notes-board.png` - لوحة الملاحظات
  - يجب أن تظهر: لوحة ملاحظات لاصقة مع ملاحظات ملونة قابلة للسحب
  - الحجم المقترح: 1200x800px
  
- ❌ `visual-analytics.png` - التحليلات المرئية
  - يجب أن تظهر: مخططات خطية لاتجاهات المواعيد والمرضى الجدد
  - الحجم المقترح: 1200x600px
  
- ❌ `today-alerts.png` - تنبيهات اليوم
  - يجب أن تظهر: قائمة التنبيهات النشطة لليوم مع روابط للمرضى
  - الحجم المقترح: 800x600px
  
- ❌ `missed-appointments.png` - المواعيد الفائتة
  - يجب أن تظهر: قائمة المواعيد الفائتة مع علامات الحالة وأزرار الإجراءات
  - الحجم المقترح: 1200x800px

## كيفية الحصول على الصور:

1. افتح لوحة تحكم الطبيب في النظام
2. انتقل إلى كل ودجت
3. التقط لقطة شاشة لكل ودجت
4. احفظ الصورة بالاسم المطلوب في هذا المجلد
